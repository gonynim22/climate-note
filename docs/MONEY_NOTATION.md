# 금액·숫자 표기 도우미 계약

v3.8c의 세 번째 개발자 제공 미니앱이다. 설계는 [v3.8c 설계](superpowers/specs/2026-09-27-v3.8c-money-notation-pocket-design.md), 실제 검증과 산출물은 [구현 기록](work/2026-09-27-v3.8c-money-notation-pocket.md)을 따른다.

## 계산 기준 (출처 확인일 2026-09-27)

- 모든 모드의 절댓값 상한은 1경(10¹⁶) 미만이다. 정수는 `int`, 환산은 `Decimal`만 쓴다. 반올림은 절댓값 기준 `ROUND_HALF_UP`이며 표시할 때만 적용한다. 원본 값과 표의 정확한 값은 바꾸지 않는다.
- 입력은 앞뒤 공백만 제거한다. 쉼표는 없거나 올바른 세 자리 묶음이어야 한다. 부호는 `-`와 `−`만 받는다. 전각 숫자, 내부 공백, 문자는 거부한다. 소수는 단위 환산에서만 6자리까지 받는다. 잘못된 값은 보정하지 않고 오류를 표시하며 결과·복사·기록을 무효화한다.
- **금액 표기**
  - 근거는 「행정업무의 운영 및 혁신에 관한 규정 시행규칙」 제2조다. 금액은 아라비아 숫자로 쓰되 숫자 다음에 괄호를 하고 한글로 적는다. 예: `금113,560원(금일십일만삼천오백육십원)`.
  - 1원 이상 1경 미만의 정수만 받는다. 모든 자리에 '일'을 적고(일십·일백·일천·일만), 0인 자리와 묶음은 생략한다.
  - 금액 한글은 변조 방지 관례에 따라 공백 없이 붙여 쓴다([국립국어원 답변](https://korean.go.kr/front/onlineQna/onlineQnaView.do?mn_id=&qna_seq=312190&pageIndex=1)).
- **큰 수 읽기**
  - 억·만 표기는 한글 맞춤법 제44항 예시(`12억 3456만 7898`)처럼 묶음 안에 쉼표를 넣지 않는다.
  - 한글 읽기는 만 단위로 띄어 쓴다. 십·백·천 앞의 '일'과 만 묶음의 '일'은 생략하고(`만`, `십일만`), `일억`·`일조`는 유지한다. 0은 `영`, 음수는 `마이너스`다.
  - 단위(최대 8자)는 아라비아 표기에 붙이고 한글 읽기에는 띄운다(제43항).
  - 만 단위까지·억 단위(소수 1자리) 표시는 반올림 값으로 표기와 읽기를 함께 만든다. 값이 바뀌면 `약`과 원래 값을 표시한다.
- **단위 환산**
  - 원, 천원(10³), 백만원(10⁶), 억원(10⁸), 조원(10¹²)은 고정 배수다. 다섯 단위의 정확한 값을 표(행 22px, 결과 단위 행 강조)에 보여 준다.
  - 결과 단위 값만 소수 자릿수(자동=최대 6자리, 0~3자리)로 표시할 때 반올림한다.
- 복사 형식 중 큰 수 읽기의 **숫자만**과 단위 환산의 **전체 단위 목록**은 스프레드시트 호환을 위해 음수 부호로 ASCII `-`를 쓴다. 화면(주 결과·표·보조 줄)은 `−`(U+2212)를 그대로 쓴다.
- 제외: 계약서·영수증 관용 형식(`일금 …원정`), 버림·올림, 환율, 세금·수수료 계산.

## UI와 상태

- 날짜·시간 계산기와 같은 독립 창이다. 내용 480×620px(그림자 포함 528×668px), 108px 어두운 왼쪽 메뉴(머리글 `도구`: 금액 표기/큰 수 읽기/단위 환산)를 쓰며 스크롤 영역이 없다.
- 오른쪽 열은 모드 페이지 → 복사 미리보기 → 오류 → 결과 카드 → 복사 형식·복사·기록 → 최근 12개 → 상태 순서다.
- 작업 영역 높이가 620px 미만이면 날짜·시간 계산기와 같은 압축 규칙을 쓰고, 근거 상자는 첫 줄만 남긴다.
- 결과 카드 주 결과는 34/30/26/22/18/15/13px 중 폭에 맞는 가장 큰 크기로 맞추고 최소 높이는 그 글꼴의 줄 높이(기본 43px, 압축 32px)를 따른다. 보조(상세) 줄은 마우스로 선택할 수 없으며, 금액 표기 모드에서는 화면에 표시되는 공문서 한글에만 조·억·만 뒤에 폭 없는 공백(U+200B)을 넣어 줄바꿈 위치를 추가하지만, 매우 좁은 작업 영역에서는 묶음 안에서도 줄바꿈될 수 있다. 복사 문자열과 최근 기록에는 U+200B가 들어가지 않는다. 압축 상태에서도 근거 상자는 첫 줄만 남긴 채 계속 보이며 복사 미리보기는 24px(평소 28px)다.
- 모드별 입력과 복사 형식 선택을 실행 중 기억한다. 최근 12개는 Enter 또는 `기록`으로 추가하고 같은 입력은 맨 앞으로 옮긴다. 복원은 모드와 값을 되돌리며 다른 모드 입력을 지우지 않는다.
- Esc는 창을 숨기고, 열린 목록의 Esc는 목록만 닫는다. 제목 드래그로 이동한다.
- 메인이 단일 창을 소유한다.
  - 일정 편집 저장 성공 후에만 연다.
  - 잠금·트레이·보스 키·사이드바 숨김·메인 숨김·초기화 직전에는 창과 소유 목록을 숨긴다. 잠금 중에는 비활성화한다.
  - 초기화 성공 신호와 정상 종료 때만 폐기한다.
  - 화면이 바뀌면 작업 영역으로 보정한다. 숨긴 창을 자동으로 다시 표시하지 않는다.
- DB v17·Export v2·salt·기존 설정 키·바로가기 6슬롯에는 변화가 없다. 네트워크와 외부 로더를 쓰지 않는다.

## 구현과 검증

- `money_notation.py`: Qt/DB 없는 입력 검증·공문서 금액·억·만 표기·한글 읽기·반올림·환산.
- `ui_money_notation.py`: 창, 입력 검증 표시, 복사·최근 기록, 소유 목록.
- `tests/test_money_notation.py`
  - 규정 예시와 경계값을 확인한다.
  - 별도 참조 구현과 결정적 난수 2만 건을 대조한다.
  - 입력 거부, 반올림 경계, `Decimal` 정확도를 확인한다.
- `tests/test_ui_money_notation.py`: 실제 입력·복사 형식·최근 기록·키보드·세 모드×세 상태×세 작업 영역의 스크롤 없는 배치를 확인한다.
- `tests/test_money_notation_integration.py`: 주머니 실행·독립 세션·수명·저장 실패·초기화 성공/실패·종료·DB/Export/salt 불변을 확인한다.
