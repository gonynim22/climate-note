# 작업 기록: v4.6 명절 테마 시안 (Claude Design)

작성일: 2026-11-01 / 상태: 시안 게시 완료 · 사용자 검토 대기

## 목표와 범위

- 목표: 명절 당일에 기후노트를 띄우면 분위기가 자동으로 바뀌는 테마의 두 방향(A·B)을 비교한다.
- 대상 날짜(사용자 확정): 새해 첫날·설날·추석·한글날·기독탄신일. 대체공휴일 포함.
- 변경 대상: Claude Design 캔버스, `output/design/holiday-theme-20261101/project/`의 `.dc.html` 원본, 이 작업 기록.
- 데이터 영향: 없음. 앱 소스·DB·salt·설정을 읽거나 바꾸지 않았다. 일정·메모·D-Day는 합성 예시다.
- 제외 범위: Qt 구현, 설정 키, 크게 보기, 빌드·배포.

## 결정과 진행

- 날짜는 `holidays.py` 자료만 쓴다. 이름에 명절 이름이 들어 있으면 같은 명절로 본다(`대체공휴일(설날)`, `개천절·추석`).
- A안 "살짝 얹기": 머리줄 남색·D-Day 커버색·메모 색을 그대로 두고 가장자리 장식과 작은 움직임만 더한다.
- B안 "옷 갈아입기": 머리줄·오늘 칸·D-Day 커버를 명절 색으로 바꾸고 스티키 머리띠를 명절 무늬로 바꾸며 인사말 한 줄을 더한다.
- 두 안 모두 일정 3색·메모 글·사용자 저장 색을 바꾸지 않는다(표시 전용 전제).
- 크리스마스 머리줄 눈 내림은 사용자 예시를 반영했다. 움직임은 머리줄과 위젯 장식에만 두고 `prefers-reduced-motion`·Tweaks의 `motion`으로 끈다.
- D-Day 숫자는 업로드한 Pretendard ExtraBold, 본문은 맑은 고딕이다.

## 사용자 결정 (2026-11-01)

- **B안 "옷 갈아입기"를 채택**했다.
- 대상은 다음 12개로 확정했다. 대체공휴일은 포함한다. 음력 공휴일(설날·부처님오신날·추석)도 `holidays.py` 자료를 쓰므로 유지한다(한때 설날·추석을 뺐다가 다시 넣었다).
  - 신정(자료 이름 `1월1일`), 설날, 삼일절, 어린이날, 부처님오신날, 현충일, 제헌절, 광복절, 추석, 개천절, 한글날, 기독탄신일
- 현충일은 추모일이므로 B안 안에서도 차분하게 둔다(조기·국화, 움직임 없음).
- 노동절(5/1)을 더해 **13개**로 확정했다.
- **보이는 기간(사용자 결정)**: 첫날 3일 전부터 당일까지 보이고 다음 날 사라진다. 여러 날 공휴일은 마지막 날(대체공휴일 포함)까지로 해석했다(제안). 이 해석이면 한글날 10/10(일) 공백 문제도 사라진다.
- **겹침 규칙(사용자 위임으로 확정)**: ① 진행 중(첫날~마지막 날)인 공휴일 ② 없으면 첫날이 더 가까운 공휴일 ③ 그래도 같으면 연휴가 긴 쪽(남는 동률은 목록 순서). `holidays.py` 2026-11-01~2028-12-25 전수 확인 결과 겹침은 3곳이다.
  - 2027-05-02~03: 노동절(진행) vs 어린이날(예고) → 노동절. 5/4부터 어린이날.
  - 2028-04-29~05-01: 노동절 vs 부처님오신날 → 노동절. 5/2는 부처님오신날 당일, 5/3~5/5는 어린이날.
  - 2028-09-30~10-05: 추석 vs 개천절 → 추석. 10/3 `개천절·추석`은 연휴가 긴 추석이며, 2028년 개천절 테마는 나오지 않는다.
  - 이름 없는 `대체공휴일`·`임시공휴일`은 2025년 4건뿐이라 이미 지났다. 앞으로 자료가 이름 없이 오면 어디에 붙일지 다시 정한다.
- **집중(포모도로) 위젯**: 실제 크기(241×126, 펼친 상태)와 `tomato.png`를 그대로 쓰고, B안에서 카드 바탕만 공휴일 색으로 바꾼다. 진행 고리·퍼센트의 토마토 빨강은 유지한다. 토마토는 공휴일마다 모자를 쓴다.
  - 신정 고깔모자 · 설날 조바위(색동 띠) · 삼일절 태극 머리띠 · 노동절 안전모 · 어린이날 프로펠러 모자 · 부처님오신날 연꽃 · 현충일 모자 없이 흰 국화 · 제헌절 갓 · 광복절 무궁화 화관 · 추석 토끼 귀 · 개천절 구름 · 한글날 'ㅎ' 모자 · 기독탄신일 산타 모자
  - 한글날은 처음에 익선관으로 그렸으나 검은 귀처럼 보여 'ㅎ' 모양으로 바꿨다.
  - 사용자 지적으로 확인: 평소 보이는 집중 위젯은 접힌 상태(241×78)이고 `tomato_mini.png`(38px)를 쓴다. 마우스를 올렸을 때만 펼친 상태(241×126)가 되어 `tomato.png`(50px)가 보인다. 두 그림은 서로 다른 그림이다. Version 8에서 접힌 상태와 `tomato_mini.png`로 고치고 모자 위치를 다시 맞췄다(미니 토마토는 머리 시작이 약 5% 낮다). 구현 때는 두 그림 모두에 모자를 맞춰야 한다.
- 캔버스 Version 5: B 보드를 13개(2줄)로 다시 그렸고 A 보드는 '보류'로 아래에 남겼다. 태극기는 시안용 간략 그림이며 구현 때 국기 규격으로 다시 그린다.

## 설계 문서 (2026-11-01)

- 다른 모델이 구현할 수 있도록 [설계 문서](../superpowers/specs/2026-11-01-holiday-theme-design.md)를 썼다. 시안 원본과 모자 확인 그림을 `docs/superpowers/specs/2026-11-01-holiday-theme/`에 복사했다(`output/`은 git 제외라서).
- 설계 문서의 테스트 벡터 17개를 실제 `holidays.py`에 같은 규칙으로 돌려 모두 일치했다.
- 사용자 결정: 설정에 `공휴일 테마` 끄기 스위치를 둔다(키 `holiday_theme_enabled`, 없으면 켬).
- 설정창 실측(실제 `SettingsWindow`, 합성 데이터, 소스 미변경 일회성 테스트): 내용 549px/창 560px. 행 추가(+41px)는 넘침, 하단 바는 제작자 문구 2px 부족, 600px 창은 1366×768·125%에서 넘침. 왼쪽 열 40px 행을 36px로 줄이면 자연 높이 478px로 들어간다. 2배율 렌더를 설계 문서 폴더에 두고 캔버스(Version 9) '설정창 시안' 보드와 휴대폰으로 보냈다.

- 구현 계획서: [2026-11-01-v4.6-holiday-theme.md](../superpowers/plans/2026-11-01-v4.6-holiday-theme.md). 7개 태스크(판정 → 설정 스위치 → 캘린더 → D-Day·스티키 → 집중 모자 → 장식·움직임 → 문서·전체 검증). 다른 모델이 구현한다. 커밋은 아직 하지 않았다.
