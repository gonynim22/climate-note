## 결정과 진행

- `--diagnose-regions`를 별도 선택해야 실행하며 첫 버전은 baseline에만 허용한다. `recognize`의 검출 상자를 그대로 관측한 뒤, 같은 세션의 `_read`에 정답 **좌표만** 주고 모델 출력 뒤에 정답 문자열로 채점한다. 텍스트를 인식 입력으로 넘기지 않는다.
- 주석은 `QFontMetrics`의 글꼴 치수 사각형이며 글리프 픽셀의 완벽한 경계가 아니다. `as-annotated`와 `pad-2`(원본에서 사방 2px, 이미지 끝에서 자름)를 고정 비교한다. 결과를 이론적 최고 정확도나 모델 오류의 확정적 분해로 해석하지 않는다.
- 제품 layout을 거친 전체 결과와 주석 순서대로 이어 붙인 공백 제외 결과를 따로 채점한다. 후자는 영역뿐 아니라 읽기 순서도 알려준 조건이므로 둘의 차이는 재구성 문제의 단서다. 표 구조 평가는 제품 layout 결과에만 적용한다.
- 기하 관측은 주석 영역의 합집합 피복률, 가장 겹치는 상자 높이 비율, 여러 상자와 겹치는 주석, 여러 주석과 겹치는 상자, 주석과 대응하지 않는 상자, 검출끼리 크게 겹치는 쌍을 남긴다. 대응은 교집합/작은 사각형 면적 ≥0.5, 낮은 피복은 합집합/주석 면적 <0.5, 작은 상자는 높이 ≤8px 또는 폭 ≤3px로 사전 고정한다. 확정 누락·중복의 정답 판정이 아닌 관측 지표다.
- 원문 전체와 주석 순서의 공백 제외 텍스트가 같은 자료만 단계 채점한다. 주석은 최대 256개, 검출 상자는 최대 512개로 진단 비용을 제한한다. 제품의 입력 축소가 생기는 큰 이미지는 첫 버전에서 제외 상태를 명시한다.
- 기준 문서: [제품 계약](../SCREEN_TEXT.md), [검증](../TESTING.md), [진단 사용법](../SCREEN_TEXT_LAB.md), [앞 단계 후보 기록](2026-10-10-screen-text-lab-candidates.md). 수정 범위를 제한하는 기존 karpathy-guidelines를 계속 적용한다.
