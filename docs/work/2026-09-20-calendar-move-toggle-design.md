## 결정과 진행

- 소스 기준 헤더 좌우 그룹은 각각 92px, 검색/더보기는 각각 32px다. 추천안은 좌우 그룹을 104px로 대칭 확장하고 오른쪽 아이콘 간격을 4px로 줄여 380px 안에서 중앙 정렬을 보존한다.
- `eventFilter()`의 large 분기가 현재 이동을 막는다. `_finish_calendar_drag()`에는 이미 대상 화면 크기 재계산·5mm 스냅·화면 내 보정·위치 저장 흐름이 있다.
- 크게는 화면 작업 영역보다 폭/높이가 40px 작아 같은 화면에서 가능한 전체 이동 구간이 각 40px다. 토글은 크기 축소 기능과 구분해 제안한다.
- 추천: 네 방향 이동 아이콘, ON 밝은 채움/OFF 사선, 명확한 상태 툴팁. 핀과 스위치도 비교한다. 아직 제품 결정/구현이 아니므로 정본 UI 계약을 바꾸지 않는다.
- 기본값은 모든 크기 ON을 제안하고 이후 사용자 선택을 크기/재시작과 무관하게 유지한다. OFF는 캘린더 본체 수동 드래그만 막고 화면 구성 변경 복구·설정 위치 변경·개별 위젯 이동과 구별한다.
- 앱 클래스를 시안 스크립트에서만 상속하여 버튼과 헤더 배치를 렌더했다. Qt 6.11.2 offscreen 렌더는 Windows 맑은 고딕을 명시적으로 로드한다. 제품 소스·의존성은 수정하지 않았다.
- 실제 PDF 4쪽을 Qt PDF로 2400×1500 PNG로 렌더해 확인했다. 초기 렌더에서 발견한 확대 컨트롤 배경과 중간 화면 카드 하단 넘침을 수정하고 다시 검증했다.
- 산출물: [PDF](../../output/pdf/calendar-move-toggle-design.pdf), [자체 포함 HTML 보기](../../output/design/calendar-move-toggle/index.html), [추천안 PNG](../../output/design/calendar-move-toggle/page-01.png). HTML 하단의 ON/OFF 버튼은 정적 시안 이미지만 바꾼다.
