- 제외 범위: 새 학습/추론/실제 앱 조작, 자동 교정, 보류 자료, 학습 후보 제품 채택.

## 결정과 진행

- 현재 제품은 상자 평균 점수 0.80 미만 및 숫자 열의 혼동 문자 조건을 ‘확인 필요’로 표시한다. 글자 탭은 해당 칸 범위를 노랗게 표시하며, 표는 칸 표시와 수정 후 해제를 지원한다. 계약은 [화면 글자 따기](../SCREEN_TEXT.md), 구현은 `screen_text/layout.py`·`window.py`다.
- 이번 세 오독의 평균점수는 약 0.97로 기존 조건을 통과한다. 같은 모델로 같은 이미지를 다시 읽어도 같은 결과여서 단순 반복은 새 경고 근거가 되지 않는다.
- 가장 나았던 B BN 고정 후보 F의 원문을 유지하고, 기존 제품 P와 **공백 제외 판독이 다르면 해당 줄/칸에 경고**하는 방법을 저장 결과로 비교했다. P/F의 모델/사전 해시는 각각 고정하며 같은 manifest/이미지/정답/순서와 완료 증거를 검증했다. 정답은 경고 생성 함수에 전달하지 않는다.
- 자료는 20원문/12작성 가족에서 만든 합성 100줄이며 이미 여러 후보 선택에 사용했다. 독립 실제 업무 성능이나 제품 구현을 뜻하지 않는다.

| 방법 | 오답 15줄 중 경고 | 놓친 오답 | 정상 85줄의 오경고 |
|---|---:|---:|---:|
| 기존 점수 0.80 기준 | 0 | 15 | 0 |
| 점수 기준만 0.98로 올린 사후 예시 | 14 | 1 | 31 |
| 기존 경고 + P/F 비공백 불일치 | 14 | 1 | 5 |

- `ppm` 작은 글씨와 `묶음` 어두운 배경/작은 글씨는 **세 줄 모두 경고 가능**했다. 그러나 `ppm`은 `m` 누락 자리 대신 세미콜론을 차이로 표시했다. 오답 줄 경고 14건 중 실제 오류 위치 적중은 13건이며, 전체 표시 49곳 중 적중 29곳/다른 위치 20곳이다. 특정 글자를 정확히 알아낸 것처럼 안내하지 않는다.
- UI 제안: 기존 노란 줄/칸 표시와 ‘확인 필요 N곳’을 사용하고, 이유는 ‘판독 결과가 달라 원본 확인이 필요합니다’로 안내한다. 사용자가 원본을 대조해 수정한 내용을 복사하도록 한다. 경고가 없음을 정확성 보증으로 표현하지 않는다.
- **판단: 경고 보강의 유망한 탐색 결과**다. 정상 5/85줄의 추가 확인 부담, 놓친 오답 1줄, 정확한 누락 위치 한계를 함께 유지한다. 단순 임계값 인상은 이 자료에서 정상 오경고가 더 많았다. 0.98은 사후 설명용 비교이며 채택/보정된 임계값이 아니다.
