# 작업 기록: 실제 앱 화면에 표시한 디자인 점검 HTML

작성일: 2026-10-09 / 상태: HTML 완성 및 검증 완료

## 목표와 범위

- 목표: 앞선 38개 디자인 개선 후보를 실제 제품 Qt 위젯 캡처의 해당 위치와 연결한 독립 HTML로 제공한다.
- 변경 대상: 이 작업 기록과 `output/harness/`의 격리 캡처·HTML·검증 자료.
- 데이터 영향: 실행별 합성 AppData만 사용한다. 실사용 데이터와 실행 중 앱은 접근하지 않는다.
- 제외 범위: 제품 UI 수정, 실제 EXE·데스크톱 캡처, 배포.
- 시작 시 사용자 변경: AGENTS.md, docs/RELEASE_HISTORY.md 및 기존 미추적 작업 기록을 보존한다.

## 결정과 진행

- 2026-10-09: 앞선 [디자인 진단](2026-10-09-design-audit.md)의 번호를 유지한다. 캡처 이미지 자체를 수정하지 않고 HTML/CSS로 위치 표시를 겹친다. 합성 내용·모의 변환/OCR 상태 및 코드로만 확인한 동작은 구분해서 설명한다.
- Windows Qt 새 캡처 56장 중 27장과 앞선 Windows Qt 집중 재현 4장을 사용했다. 31화면에 진단 38개·위치 표시 54개를 연결했다. PNG 원본 31개를 그대로 HTML에 내장했으며 약 1.3MB다.
- [최종 HTML](../../output/harness/20261009-233526-design-visual/기후노트-디자인-점검.html) / [데스크톱 미리보기](../../output/harness/20261009-233526-design-visual/report-preview.png) / [좁은 화면](../../output/harness/20261009-233526-design-visual/report-mobile.png).
- 검색·우선순위 필터·번호 선택·부분 확대·주석 끄기·원본 크기/맞춤 확대를 구현했다. 브라우저의 임시 390×844 뷰포트는 검증 후 복원했다.
- 제품 Python 소스 50개의 SHA-256은 캡처 시작 및 앞선 진단과 일치한다. 시작 시 사용자 변경을 보존했다.
