## 결정과 진행

- 크게의 크기 계산은 그대로 유지한다. 동일 화면에서 전체 이동 가능 구간은 보통 축당 40px이며, 다른 화면에 드롭하면 기존 대상 화면 크기 재계산/5mm 스냅/화면 내 보정을 재사용한다.
- 이동 OFF는 캘린더 수동 드래그만 차단한다. 개별 플로팅 위젯 이동·모니터 분리 복구·설정 위치 선택은 별도다.
- 초기 관련 검사에서 새 테스트 2개가 Windows 활성화 이벤트 처리 전 포커스를 판단해 실패했다. 실제 활성 창/포커스를 기다린 뒤 입력하도록 테스트를 수정했고, Tab으로 실제 이동 버튼에 진입해 Space/Enter를 보내도록 검증했다.
- 100/125/150% 합성 배율 캡처에서 헤더·스마일 원을 확인했다. 배율별 실제 이미지 픽셀 외경 차이는 1px 이내이며 입력부 두 원의 논리 외경은 22px다. 앱 버전·DB·Export·salt·의존성 파일 변경 없음.
