## 결정과 진행

- 원인과 수정 전 실패 12건은 [조사 기록](2026-09-22-kvm-window-position-investigation.md)에 보존한다.
- 자동 복구는 임시 표시만 변경한다. 사용자 좌표와 화면 기준 원점은 명시적 배치 때 묶어서 저장한다.
- 화면은 고유 serial+제조사/모델을 우선하고, serial이 없거나 중복이면 이름+장치 정보 조합으로 유일할 때만 선택한다. 화면 이름 하나를 보장된 고유 ID로 취급하지 않는다. 대상이 없거나 모호하면 기본 화면에 임시 표시하며 선호 설정은 유지한다.
- 새 키가 없는 기존 사용자는 유효한 숫자 인덱스를 메모리에서만 채택한다. 새 키를 자동 생성하지 않는다. 설정·Import·초기화로 선택값이 바뀌면 캐시를 갱신한다.
- 스티키/D-Day/집중도 자동 화면 이탈 보정 좌표를 DB에 역저장하지 않는다. 사용자의 수동 이동 저장은 유지한다.
- `tests/test_ui_kvm_position.py`의 40개 회귀를 전체 수집에 포함했다. 수정 전 조사 파일은 이 파일로 승격했으며, 전체 기본 검사에 실패를 숨기는 xfail/skip을 추가하지 않았다.
- 모니터 선택은 메인의 위치 저장 콜백을 통해 좌표·화면 정보를 같은 트랜잭션으로 갱신한다. 실패 시 기존 저장값/기하/콤보 선택을 유지한다. 설정 창이 열린 동안 재정렬되거나 장치가 사라진 경우도 검사했다.
- 화면 작업 영역과 논리/물리 DPI 변경을 감시하고 화면 복구 시 진행 중 드래그를 취소한다. 기존 500ms debounce는 유지하며 대기 시간 증가에 의존하지 않는다.
- 이미 구버전에서 틀어진 위치가 저장됐으면 그 이전 위치를 추정하지 않는다. 개선 EXE에서 한 번 원하는 위치로 옮기거나 모니터/모서리를 선택하면 새 복원 기준을 저장한다.
