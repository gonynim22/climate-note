## 결정과 진행

- 2026-09-27: 현재 주머니의 문제를 진단했다.
  - 생성 PNG(광택 3D, 1,000,621바이트)와 평면 SVG 아이콘의 스타일이 섞여 있다.
  - 모든 타일이 같은 연파랑 배경에 테두리까지 있어 무겁고 앱끼리 구분이 약하다.
  - 점선 예정 칸 두 개가 절반을 차지해 미완성처럼 보인다.
  - 머리부의 테두리 있는 닫기 버튼과 11px 굵은 글씨가 답답하다.
- 2026-09-27: 제약을 정했다.
  - Qt에서 그대로 구현할 수 있는 표현만 쓴다: QSS 배경·테두리·radius, 기존 `QGraphicsDropShadowEffect`, QtSvg Tiny 범위의 SVG(선형 그라데이션·stroke).
  - blur 유리 효과와 CSS 전용 효과는 쓰지 않는다.
  - 글꼴은 앱 기본 Malgun Gothic만 쓴다.
  - 동작 계약은 유지한다: 닫기·Esc·그림자 여백 클릭, 예정 칸 클릭/Tab 차단, 잠금/숨김 정리, 열림 상태 비저장.
- 2026-09-27: 3안을 만들었다.
  - A 앱 런처(추천): 테두리 없는 타일, 앱별 그라데이션 아이콘, 252×280px.
  - B 도구 목록: 이름·설명·숫자 키, 단색 선 아이콘, 292×268px.
  - C 네이비 카드: 캘린더 헤더색 머리부, 파스텔 배지, 280×292px.
  - 아이콘 도형 7종(주머니·환산·날짜시간·보고서 수치·금액·글자 수·준비 중)을 24px 격자 한 벌로 그려 세 안이 공유하고, 색과 그릇만 다르게 입혔다.
- 2026-09-27: 첫 렌더 후 수정한 것:
  - 보고서 수치 아이콘이 막대와 % 기호 때문에 "00%"처럼 읽혀, 축+상승선 차트로 바꿨다.
  - 아이콘이 그릇에 비해 작아 도형 비율을 키우고, 환산 아이콘을 넓혔다.
  - 400px 폭에서 긴 `<code>` 경로가 넘쳐 줄바꿈되게 했다.
  - 좁은 화면에서 무대가 줄어 주머니가 잘려, 무대를 실제 크기로 고정하고 자기 영역 안에서만 가로로 스크롤되게 했다.
