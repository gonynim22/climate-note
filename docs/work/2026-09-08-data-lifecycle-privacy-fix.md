## 결정과 진행

- 2026-09-08: `karpathy-guidelines` 적용. 기존 리뷰의 합성 재현을 정식 회귀 검사로 옮겨 실패를 확인한 뒤 수정한다.
- 수정 전 회귀: quick 기본 검사와 새 회귀 15건을 합쳐 72건 실행, 13 failed/59 passed로 문제를 고정했다.
- 가져오기: 기존 스티키/D-Day/집중 인스턴스는 ID 기준으로 재사용한다. 설정은 최신 스티키 저장이 성공해야 보호백업·병합을 수행한다. large 패널 목록도 갱신한다.
- 초기화: 최신 저장과 보호백업 성공 후 숨긴 미니 패널까지 포함해 모든 타이머를 정지하고 가드 참조를 해제·폐기한다. DB 교체 전 실패와 교체 시도 후 실패를 구분한다. 전자는 기존 객체를 유지하고, 후자는 현재 DB에서 새 객체로 UI를 복원한다. DB/salt 형식이나 스키마는 변경하지 않았다.
- 잠금: 트레이/패널/레지스트리 상태를 표시 시점에 확인한다. 설정·검색·휴지통을 비활성화/숨기고 진입을 차단한다. 이미 예약된 창 표시와 폐기된 객체의 예약 콜백도 차단한다. 활성 모달/팝업을 취소하고 집중 자동 완료는 잠금 중 팝업 없이 기록한다.
- 보조 창은 기존처럼 닫은 뒤 재진입 시 설정을 새로 읽되, 이전 객체를 `deleteLater()`해 잠금 범위 밖에 오래된 창이 남지 않게 한다. 설정창 위치 보정 예약도 현재 객체에만 적용한다.
- 2026-09-09: 저장 실패·보호백업 실패·DB 교체 실패·실제 Qt 타이머·PIN 모달 취소 등을 포함한 회귀 19건으로 확장했다. 중간 quick은 76건 통과했다. 이후 D-Day 원본/폐기/잠금 확인과 설정창 예약 보정을 보강했으므로 최종 근거는 새 full 실행으로 남긴다.
