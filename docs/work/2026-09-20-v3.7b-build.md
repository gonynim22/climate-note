- `docs/TESTING.md`의 release 프로필을 사용한다. 과거 full의 통과 수를 새 빌드 증거로 대신하지 않는다.

- `release`는 새 실행 폴더의 build/dist에서 같은 `.venv` PyInstaller로 빌드했다. 717개 테스트와 신규 설치/기존 데이터/손상 salt 시작 차단 3개 시나리오를 통과했다. 기존 합성 8개 테이블 raw·복호화 내용·ID·salt 보존을 확인했다.

- 실제 한글 IME·탐색기 드롭/기본 프로그램·구형 EXE 재편집·PC 두 대 이동·Win+D·혼합 DPI/KVM·Defender·라이선스/SBOM/서명은 별도 미확인이다.
