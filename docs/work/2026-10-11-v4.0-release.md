## 결정과 진행

- [표 구성 개선](2026-10-11-screen-text-table-layout.md)을 적용하며 문자 인식 모델 자체의 정확도가 향상됐다고 표현하지 않는다. [추가 학습](2026-10-11-screen-text-diverse-training.md)은 미채택·보류다.
- 개발용 진단 도구의 소스·가벼운 검사·기록은 재현을 위해 Git에 남기고, 대용량 자료/학습 환경/실험 모델은 기존 `output/`에만 보존한다. 앱이나 일반 검사에서 학습을 시작하지 않는다.
- `release`가 전체 검사를 포함하므로 quick/full을 먼저 중복 실행하지 않는다. 빌드 중 제품 코드·검사·정본 문서를 고정하고 실행별 합성 데이터만 사용한다.
- 기존 `main`의 미전송 커밋을 보존한 채 명시적으로 `main`만 push한다. 서버 검사 거부 시 실제 원인을 기록하며 우회하거나 강제 push하지 않는다.
- `release` 실행 `20261011-215138-fbcbbb30e7`에서 2,437개 통과(실패/오류/skip 0), 빌드와 fresh/existing/blocked 시나리오가 모두 통과했다. 입력 해시는 실행 전후 같았다. 기존 qfluentwidgets의 SciPy import 경고 1개는 실패와 구분한다.
- 별도 증거 실행 `20261011-215030-3133e2c7be`: EXE의 프로젝트 모듈 50개가 현재 소스 컴파일 결과와 일치한다. 기존 모델/사전·MANIFEST 유지, 네이티브 파일 64개와 리소스 91개가 빌드 원본 및 직전 v3.9a EXE와 일치한다. Git/mingw DLL과 개발용 진단/학습 내용은 포함되지 않았다.
- 실제 EXE의 Windows File/Product Version은 `4.0.0.0`, 크기는 **94,040,203 bytes**이며 직전 표 개선 v3.9a보다 153 bytes 크다. SHA-256은 `71179E6499E027540C2BDCDA6F104CE78A0EAC63567B297AA89E7365624B820E`다.
- 확인 당시 루트 `dist/`는 비어 있었다. 이전 EXE는 `output/harness/20261011-212137-470e230764/dist/`에 보존하고, 새 파일을 `dist/기후노트_v4.0.exe`로 배치한 뒤 해시를 재확인했다.
- 커밋 공백 검사에서 발견한 개발 도구 `datasets/__init__.py`의 여분 EOF 빈 줄만 제거했다. 전후 컴파일 결과가 같고 EXE에 없는 파일이며 관련 자료 도구 quick 91개를 다시 통과했다. 제품/모델/lock/빌드 입력 코드는 변경하지 않았다.
- 첫 소스 커밋은 `c610e11`이다. 첫 `git push origin main`은 서버 Semgrep의 `dynamic-urllib-use-detected` 1건(`tools/screen_text_lab/training/bootstrap.py:19`)으로 거부됐다. Gitleaks·OSV-Scanner·Trivy·Syft는 통과했고 서버는 파일 미표시 검사기 오류 1건도 보고했다. 원격은 갱신되지 않았다. 앞선 전체 검사의 보안 회귀는 당시 추적 파일만 검사해 미추적 개발 도구를 포함하지 않았으므로, Git 등록 후 해당 검사를 명시적으로 다시 수행한다.
- 차단 원인을 수정한다. 개발 도구의 다운로드를 고정된 공식 HTTPS 주소 2개로 제한하고, HTTPS 전용 처리기/기본 인증서 검증·HTTPS 프록시 유지·비HTTPS와 리디렉션 거부·기존 파일 비덮어쓰기를 적용한다. 규칙 제외나 경고 억제는 하지 않는다. 이 도구는 EXE에 없으므로 배치 EXE와 제품 코드/모델은 그대로이며 관련 보안 검사를 다시 실행한다.
- 수정 후 `quick --tests tests/test_screen_text_lab_bootstrap.py tests/test_screen_text_lab_training.py tests/test_security_scan_rules.py` 실행 `20261011-220727-80821056a8`에서 109개 통과했다. 실제 네트워크/학습을 실행하지 않고 고정 주소·프록시·리디렉션·비덮어쓰기와 Git에 등록한 Python 파일 전체의 보안 회귀를 확인했다.
- 서버와 같은 규칙 사본의 Semgrep 1.177.0을 Git 인덱스의 Python 사본에 적용했다. 기본 제외를 적용한 122개 파일/200개 규칙에서 지적 0·오류 0이고 수정한 `training/bootstrap.py`도 검사 대상에 포함됐다. 최초 로컬 실행의 샌드박스 인증서 저장소 접근 실패 로그를 보존하고, 권한을 허용한 재실행 결과와 구분한다. EXE 및 번들 프로젝트 모듈 50개의 해시는 이 후속 수정 뒤에도 동일하다.
