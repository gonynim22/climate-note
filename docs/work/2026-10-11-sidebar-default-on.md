# 작업 기록: 바로가기 사이드바 기본값 켜짐(A안)

작성일: 2026-10-11 / 상태: 로컬 구현·검증, 브랜치 `fix/sidebar-default-on`(커밋·병합·빌드는 사용자 지시 대기). 버전 v3.9a 유지

## 배경

- 사용자 보고(2026-10-11): 새 EXE를 처음 띄웠더니 '작게'(기본 크기) 모드에서 바로가기 사이드바가 사라짐. "중대 결함", "원래 on이 기본인데", 설정의 '바로가기' 스위치는 꺼져 있었음.
- 조사(실사용 DB는 열지 않음, 합성 데이터만):
  - 기본 크기의 사이드바는 `show_sidebar` 설정을 따르며, 스위치가 꺼져 있었으므로 DB 값이 '0'이었다.
  - 위치 편집(J안) 변경(`d56803a..c07f4f7`)에는 설정을 쓰는 코드가 없다(예전 이동 설정 저장 한 줄을 지웠을 뿐).
  - release 스모크의 합성 데이터 시드(`show_sidebar=0`, 크기 compact)는 `output/harness` 경계 밖으로 쓸 수 없고 기존 DB가 있으면 멈춘다. 설정 창은 열 때 스위치 값을 저장하지 않는다. 처음 실행 흐름은 DB가 없을 때만 돈다.
  - 코드 기본값은 v3.5부터 줄곧 꺼짐('0')이었다(v9 이전의 `INSERT OR IGNORE ... '0'`, 모든 읽기 기본값 "0"). 예전에 보였다면 사용자가 켰던 값이다.
  - 무엇이 실사용 값을 꺼짐으로 바꿨는지는 확인하지 못했다(실사용 DB 비열람 원칙). 같은 날 다른 도구(Codex)가 이 PC의 화면 자동 조작을 쓸 수 있게 설정하고 미니앱을 검증 중이었다는 점만 사용자에게 알렸다.
  - 중간·크게는 [바로가기 | 달력 | 일정] 배치라 스위치와 무관하게 늘 보인다(기존 설계). 그래서 꺼짐 상태에서 크게 → 작게로 바꾸면 사라진 것처럼 보인다.
- 사용자 결정: A안 — 새 설치 기본값을 켜짐으로, 스위치 이름에 적용 범위 표시, 기존 사용자 값은 그대로.

## 변경

- `database.migrate`: 새 DB이고 처음 실행 크기 선택(`initial_calendar_scale`)이 있을 때 `show_sidebar='1'`도 넣는다. 아래 v9의 `INSERT OR IGNORE '0'`은 이 행을 덮지 않는다. 이미 있는 DB는 바꾸지 않는다.
- `database.reset_database`: 초기화도 새 설치와 같은 기본값(기본 크기, 바로가기 켜짐)으로 `migrate(initial_calendar_scale=DEFAULT_CALENDAR_SCALE)`.
- `ui_settings`: 스위치 이름 '바로가기' → '기본 크기 바로가기'(116px 라벨 안, 맑은 고딕 13px 기준 114px), 툴팁 "기본 크기에서 바로가기 열을 보입니다. 중간·크게에서는 늘 보입니다."
- `ui_first_run`: 기본 크기 미리보기를 460×660으로, 왼쪽 바로가기 열을 그린다(중간·크게와 같은 그리기 함수 `_paint_sidebar`).
- 데이터 영향: 기존 사용자의 `show_sidebar` 값은 바꾸지 않는다. 새 설치·초기화만 켜짐. DB v17·Export v2·salt·설정 키 불변.

## 결정과 진행

- Ruling: 사용자 A안은 "새로 설치하는 사람 기준"이었지만 초기화도 새 설치와 같은 기본값으로 맞췄다 — 초기화 뒤에만 꺼짐이면 같은 혼란이 되풀이된다 — 틀리면 `reset_database`의 한 줄.
- Ruling: 크기 선택 없이 만든 DB(합성 시험 DB, v8→v9 이전 경로)는 예전처럼 꺼짐으로 둔다 — 기존 시험의 기본 크기 380px 전제를 지키고, 이전(업그레이드) 사용자의 값을 새로 만들지 않는다 — 시험 이름을 `test_migrate_without_first_run_choice_keeps_sidebar_off`로 바로잡음.
- RED → GREEN: `test_sidebar_default.py` 5개 RED(새 설치·초기화 '0', 스위치 이름 없음) → 7개 통과. `test_first_run.py` 3개 RED(첫 실행 기본 크기 380, 미리보기 380·바로가기 열 없음) → 51개 통과. 관련 18개 시험 파일 700개 통과.
- 처음 실행 대화상자 캡처로 기본 크기 미리보기 왼쪽 바로가기 열을 확인했다.
