- 제외 범위: 특정 단어 치환, 정답/주석 기반 분할, 후보를 반복 조정, 새 캡처/다운로드, 미검토 자료 채점, 독립 평가용 12개 조기 사용.

## 고정 실험과 판단 기준

- 배경이 균일한 가로줄만 대상으로, 픽셀 글자 높이의 6배 또는 10배 길이를 목표로 빈 세로 열에서 분할한다. 짧은 줄·복잡한 배경·안전한 틈 없음·16구간 초과는 원문을 유지한다. 원문/정답/태그로 자를 위치를 정하지 않는다.
- 같은 검출기·인식 모델·원본 높이/글리프 픽셀을 사용한다. 짧은 구간 결과를 합치되 비공백 글자가 같으면 원래 문자열/점수를 보존한다. 빈 구간 판독이 있으면 해당 줄 전체를 원문으로 되돌린다. 새 점수는 글자 수 가중 평균으로 관측용이며 보정된 확률이 아니다.
- 실제 dev 기준: 공백 제외 오류 20% 이상 감소, 기존 완전 정답 손상 0, 공백 포함 오류 비증가. 모두 충족한 후보만 합성 dev의 전체/표/내용별 퇴행을 확인한다.
- 실제 dev에서 두 후보 모두 기준 미달이면 이번 분할 방식의 탐색을 종료한다. 같은 자료의 길이/임계값을 다시 조정하지 않는다. 이 결과를 모든 분할 방식의 불가능 증명으로 일반화하지 않는다.
- 관련 문서: [진단 사용법](../SCREEN_TEXT_LAB.md), [검증](../TESTING.md). karpathy-guidelines의 작은 변경 원칙에 따라 기존 격리 실행·보고서를 재사용한다.

## 미해결과 인계

- 현재 소형 모델에 시험한 입력 조정·선택적 재인식·짧은 구간 분할만으로 채택 가능한 개선을 얻지 못했다. 같은 방식의 반복 대신 인식 전략/학습 가능성을 다시 검토해야 한다. 모델이나 의존성을 임의로 바꾸지 않았다.
- 새 후보는 개발 도구에서 명시적으로 선택할 때만 실행되며 일반 테스트/빌드에는 대규모 실행을 연결하지 않는다. 사용자에게 원본 수집 작업을 추가 요구하지 않았다.
- 배포·커밋·push: 수행하지 않음.
