## 결정과 진행

- 2026-10-25: 파란 곡선과 중심 `(256,259)` 사이 최소 거리는 약 197.62px인데 선 두께가 12px여서 안쪽 경계는 약 191.62px다. 대륙 clip 반지름 197px는 그 위에 겹친다. 대륙 그룹만 같은 중심에서 95%로 축소하면 표시 반지름은 187.15px로 약 4.47px의 안전 간격이 생긴다. 기존 해안선·원형 clip을 함께 축소해 대륙 모양을 더 잘라내지 않는다.
- 대륙을 먼저, 파란 궤도를 그다음, 잎가지를 마지막에 그린다. 캔버스 전체 확대와 투명 배경은 유지한다.
- 기존 path 167개의 도형·색상 속성은 모두 유지했다. Edge에서 수정 전후의 대륙·파란 선을 각각 분리 렌더링해 알파 겹침을 비교했다: 1024px 기준 845픽셀 → 0픽셀. 곡선의 거리 제곱 미분식의 극값으로 계산한 최소 간격은 4.47338px(원본 SVG 좌표)다.
- 최종 전체 알파 경계는 1024px에서 `(16,34,1008,990)`로 앞선 투명 아이콘과 같다. 최종 PNG와 Qt 크기별 확인판을 직접 열어 파란 선이 가려지지 않는 것과 밝은/어두운 배경 표시를 확인했다. 모든 크기의 ICO를 Qt와 Windows `LoadImageW`로 읽었다.
