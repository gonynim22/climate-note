## 결정과 진행

- 이전 추가 학습 F는 합성 선택 100줄의 공백 제외 오류를 57→32자로 줄였으나 실제 메모장/문서에서는 악화했다. 입력 변형·소형 대체 모델·경고/표 구성 작업과 구별한다.
- 첫 고정 실험은 원래 모델과 미세학습 모델의 가중치 보간이다. 그래프·사전·입출력이 같은 미학습 확장 R_B와 BN 고정 F 사이의 **0.25·0.5 두 비율**만 시험한다. 추가 학습 0회이며 기존 학습을 보수적으로 반영하는 가설이다. 추론 결과를 보고 비율을 추가 탐색하지 않는다.
- [WiSE-FT 연구](https://arxiv.org/abs/2109.01903)의 가중치 결합 아이디어를 참고하되 그 논문의 분류 성능을 한국어 OCR 성능 근거로 사용하지 않는다. 이번 방식은 동일 ONNX 추론 그래프의 부동소수점 상수 가중치를 보간하는 별도 OCR 실험이다.
- ONNX 그래프의 1,037개 노드는 가중치 tensor를 제외하면 동일하고, 다른 float32 상수는 222개였다. 크기/구조/정수 상수는 바꾸지 않는다. 동일 구조 모델 한 개이므로 다중 추론은 추가하지 않으며 실제 시간은 별도로 측정한다.
- 기준 P 및 R_B/F 양 끝점도 함께 확인한다. 미학습 확장 R_B가 P와 같은 문자 출력을 내는지 확인하기 전에는 P 보존 효과로 해석하지 않는다. 가중치 파일은 개발 출력에만 두고 기존 등록/출처 검사에 학습 모델인 것처럼 위장하지 않는다.
- 사전 밖 ○·★·₂는 이 실험으로 생기지 않는다. 이들은 별도 학습 자료/출력 클래스가 필요한 남은 문제로 구분한다.
- 채택 검토 조건: 공개 문단과 실제 메모장 각각 공백 제외 오류 20% 이상 감소, 합성 선택 오류 비증가, 기존 비공백 정답 손상/새 숫자·단위 오류 0, 공백 포함 오류 비증가. 후보가 통과한 경우에만 CPU 반복 속도(중앙/p95 1.10배 이내)와 독립 자료 확인으로 넘어간다. 인식 모델은 15MB 이내. 과거 보류/최종 집합은 열지 않는다.

### 문자 비교 결과

표는 공백을 제외한 편집 오류 문자 수다. 공개 표의 수치는 읽기 순서 영향도 포함하므로 문자 인식의 주된 근거는 공개 문단과 실제 메모장으로 삼는다.

| 자료 | 현재 P | 미학습 R_B | 기존 추가 학습 F | F 25% 반영 | F 50% 반영 |
|---|---:|---:|---:|---:|---:|
| 합성 선택 100줄 / 2,640자 | 57 | 57 | 32 | 49 | 41 |
| 실제 메모장 48장 / 3,006자 | 129 | 129 | 258 | 125 | 144 |
| 공개 문단 9개 / 908자 | 26 | 26 | 61 | 26 | 33 |
| 공개 표 7개 / 871자 | 123 | 123 | 143 | 144 | 123 |

- **25% 후보:** 메모장 오류 감소는 4자(3.1%)이고 공개 문단은 감소하지 않았다. 공백 포함 오류는 문단 133→41, 메모장 435→238로 줄었지만 대부분 띄어쓰기 개선이다. `531ppm→531pprn` 새 단위 오류가 두 후보에 모두 생겼다. 원본 crop을 다시 시각 대조했다. 이미 틀리던 ○가 같은 사례에 있어 ‘기존 완전 정답 사례 손실 0’만 보면 이 퇴행을 놓친다.
- **50% 후보:** 메모장 129→144, 공개 문단 26→33으로 악화했고 메모장에서 기존 공백 제외 정답 사례 4개가 새로 틀렸다. `4.38점`의 소수점 누락도 확인했다.
- 25% 후보의 공개 표 오류 증가는 `real-doc-36`의 일부 빈/잡음 상자에 새 문자가 출력되어 같은 레이아웃 규칙의 행·표 구성까지 달라진 영향이 포함된다. 표의 21자 증가를 모두 순수 글자 치환으로 해석하지 않는다. 레이아웃 코드는 실험 중 고정했다.
- R_B는 P와 164개 모두 텍스트·표가 동일했고 P는 저장된 이전 기준 164개를 상자/점수까지 재현했다. 인식 입력은 나머지 네 모델과 656쌍 모두 같았다. 검출은 화면마다 한 번 수행해 다섯 모델이 같은 좌표를 썼다.
- 모델은 각 **13,431,233 bytes**로 P 13,401,252 bytes보다 29,981 bytes 크다. 단일 추론 모델이지만 실제 속도 동일성은 측정하지 않았으며 보장하지 않는다.
- 판단: 두 후보 모두 미채택. 기존 F의 퇴행을 줄인 효과를 P보다 글자를 잘 읽는 효과로 부풀리지 않는다. 비율 추가 탐색·추가 학습·제품 반영은 수행하지 않았다.

### 재현과 제한

- 실행: 별도 ONNX 변환 환경의 `prepare.py` → 제품 `.venv`의 `evaluate.py` → `verify_results.py`. 실행 폴더에 코드와 입력/모델/정답 해시를 보존했다. 기존 결과 덮어쓰기 재실행은 하지 않는다.
- 준비 중 과거 R_B 보고서의 `bundle_candidate.py` 해시가 후속 기능 추가 전 버전임을 발견했다. 모델/사전/checkpoint/probe의 해시는 모두 일치했다. 알려진 해당 도구 파일 한 개의 과거·현재 해시만 명시 기록했고, R_B/F 두 모델을 고정 Paddle 출력 21개씩과 다시 대조했다. 오래된 보고서 전체 소스가 지금도 같다고 주장하지 않는다.
- 모델 가중치 보간은 검증된 원본·추가 학습 ONNX의 부동소수점 상수를 직접 결합한 개발 실험이다. 새로 학습한 모델이나 기존 후보 등록 출처 검사를 통과한 학습 산출물로 가장하지 않는다.
- 작업별 격리 AppData·소유 Windows Job·CPU 4스레드·텔레메트리 끔을 사용했다. 이미지/검출 좌표만 인식 함수에 전달했고 정답은 채점에만 사용했다. 기존 보류 자료는 열지 않았다.
- 최초 계획 사본은 `plan-before-evaluation.md`에 보존했다. 실행 후 이 작업 기록을 결과로 갱신한 것을 다른 보호 파일의 변경과 구별한다.

## 미해결과 인계

- **사용자가 원하는 실제 글자 인식 향상은 아직 달성하지 못했다.** 작은 용량·빠른 인식 우선순위는 유지한다. 다음 유효 경로는 기존 400장/80문구 파일럿을 반복 조정하는 것이 아니라, 학습에 쓰도록 별도로 준비한 더 다양한 업무 화면과 지원되지 않는 기호를 포함한 자료로 소형 모델을 추가 학습하는 것이다. 새 실제 학습 자료 수집·정답 독립 검토·독립 평가·학습 실행은 이번 고정 실험에서 완료하지 않았다.
- 이번 공개 문서 16영역은 `training_allowed=false`인 평가 자료로 유지한다. 오류를 보고 정답을 학습에 섞지 않는다. 사전 밖 ○·★·₂ 지원은 새 클래스/학습 자료가 필요한 별도 미해결 사항이다.
- 제품 변경·빌드·커밋·push: 수행하지 않음.
