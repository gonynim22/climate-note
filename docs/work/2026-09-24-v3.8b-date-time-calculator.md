## 결정과 진행

- 2026-09-24: 사용자 A안 선택 및 v3.8b 구현/커밋/빌드 요청 확인. 순수 계산, 주머니/메인 통합, Qt 화면을 파일 소유권별로 분담한다.
- 계산 기준은 계획서를 따른다. 초는 정수로 보존하고 소수 분 숫자 복사는 최대 소수 12자리, 내림·반올림·올림은 명시적 선택이다. 공휴일 데이터는 기존 2025–2027년 자료만 사용한다.
- A안 실제 Qt 배치는 내용 480×620px/그림자 포함 528×668px로 정리했다. 입력 폼만 스크롤하고 결과·오류·복사·최근 기록은 고정한다. 공통 콤보를 재사용하며 복사 형식의 긴 문구가 작은 화면의 최소 폭을 키우지 않도록 말줄임 가능한 폭 정책을 적용했다.
- 독립 리뷰에서 합산 종류 전환 시 행 교체/계산 순서, 다른 종류의 입력 보존, 빈 합산 기록 복원을 보완했다. 근무일 시작/종료 교환도 구현했다.
- 최초 9개 실패 중 4개는 복사 콤보의 최소 너비 문제였다. 2개는 Qt 체크박스의 실제 hit 영역 밖인 행 중앙을 누른 검사로, 스타일 indicator 중앙 클릭으로 수정했다. 3개는 `qWaitForWindowActive`만 확인하고 창 노출 전에 닫아 늦은 활성 이벤트가 다음 팝업을 닫던 테스트 경쟁으로, `qWaitForWindowExposed` 조건을 먼저 확인했다. 별도 격리 probe `output/harness/20260924-datetime-popup-probe/`의 baseline/exposed/checkbox JSON을 근거로 하며 제품 하네스 통과로 간주하지 않는다.
