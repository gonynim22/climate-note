## 목표와 범위

- 목표: 미니앱 주머니뿐 아니라 실행된 단위 환산기 창에도 그림자를 표시한다. 추가 사용자 요청에 따라 왼쪽 분류 버튼 간격을 줄이고 글꼴을 키운다.
- 변경 대상: `ui_unit_converter.py`, 최초 실행 위치를 정하는 `ui_main.py`, 관련 UI 테스트와 정본 문서. 검증 중 발견된 기존 Job 소유권 테스트의 PID 파일 게시 경합도 해당 테스트 안에서 보완한다.
- 데이터 영향: 표시·배치만 변경. DB v17·Export v2·salt·기존 본문/설정/바로가기·계수·최근 12개 메모리 기록 유지.
- 범위: 기존 440×580px 내용 영역을 유지하고 바깥 그림자 공간을 추가한다. 화면 경계 보정·작은 화면 스크롤·제목 드래그·닫기/숨김/잠금 수명을 유지한다. 앞선 사용자 지시에 따라 빌드·AGENTS 갱신·로컬 커밋 포함.
- 시작 시 사용자 변경: `.gitignore` 2줄, AGENTS 4줄, RELEASE_HISTORY 16줄 및 기존 미추적 작업 기록 3개. 보존하며 이번 작업분만 커밋한다. 시작 HEAD `6968b5b`.

## 결정과 진행

- 주머니와 같은 Qt 그림자(blur 20px, 아래 4px, alpha 80)를 환산기의 안쪽 컨테이너에 적용하고 사방 24px 투명 여백을 확보한다. 기본 외곽은 488×628px이다. native 중복 그림자는 끈다.
- 최초 위치 계산과 화면 보정은 그림자 여백을 고려한다. 작은 화면에서는 기존 스크롤 접근성을 유지한다.
- 주머니와 달리 도구 창의 그림자/바깥 클릭은 닫기 동작을 추가하지 않는다. X/Esc 숨김과 기존 수명 계약을 유지한다.
- 현재 창은 단위 환산기 하나다. 새 공용 프레임워크나 계산 변경은 추가하지 않는다.
- 글꼴 확대 후 `mg/kg` 기호가 32px 칸을 넘는 것을 검사에서 발견해 기호 칸을 40px, 분류 목록을 124→132px로 조정했다. 이름 13px/기호 12px를 유지한다.
- 340×400 합성 작업 영역에서 그림자 여백이 본문 최소 너비를 침범했다. `fit_to_screen()`은 실제 내용 최소 너비와 세로 스크롤바 폭을 확보한 뒤 그림자 여백/blur를 함께 줄인다. 넓은 화면으로 복귀하면 기본 크기/24px 여백을 복원한다.
- 두 번째 quick에서 기존 `test_job_kills_its_descendants_but_not_other_processes`가 빈 PID 파일을 읽어 실패했다. 파일 생성과 내용 기록 사이의 경합을 확인하고 테스트 자식이 임시 PID 파일을 닫은 뒤 `os.replace`로 게시하도록 바꿨다. 실행기/앱/프로세스 정리 계약은 바꾸지 않고 전체 release로 재검증한다.
- 정본: [UI](../UI_PATTERNS.md), [아키텍처](../ARCHITECTURE.md), [검증](../TESTING.md), AGENTS.md.
