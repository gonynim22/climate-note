## 목표와 범위

- 목표: 공휴일 첫날 3일 전부터 마지막 날까지 캘린더 머리줄·오늘 칸·D-Day 커버·스티키 머리띠·집중 위젯 바탕을 공휴일 색과 장식으로 자동 전환한다. 대상은 13개 공휴일(대체공휴일 포함)이다.
- 변경 대상: 새 `src/holiday_theme.py`(판정·색표), `src/ui_main.py`·위젯·설정창의 화면 연결(Task 2 이후), `tests/test_holiday_theme.py` 등. 세부는 구현 계획을 따른다.
- 데이터 영향: 없음. 테마는 화면 전용이며 유일한 쓰기는 설정 스위치의 `app_settings` 키 `holiday_theme_enabled`(`"1"`/`"0"`, 키가 없으면 켜짐)다. DB v19·Export v4·salt·암호문·기존 설정 키·D-Day 저장색·스티키 색과 본문은 바꾸지 않는다.
- 제외 범위: 음력·공휴일 계산(날짜는 `holidays.KOREAN_HOLIDAYS`만 사용), A안(남색 유지 + 가장자리 장식), 설정창 크기 변경(800×560 유지).
- 시작 시 사용자 변경: `docs/work/` 아래 추적되지 않은 기록 15개와 `motion/` 폴더가 이미 있었다. 이번 작업에서 건드리지 않았고 커밋에도 넣지 않았다.
