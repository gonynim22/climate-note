- 수동 확인으로 남는 것: 실제 스캐너 이미지, 업무 PC 속도, 혼합 DPI. 한글·엑셀 화면과 EXE 판독은 자동화했다.
- 변경한 정본 문서: `docs/SCREEN_TEXT.md`, `docs/TESTING.md`, `AGENTS.md`.
- 다음 행동: 남은 오독을 고르면 이어서 고친다. 내보낼 때 `release`를 다시 돌린다.
- 배포·커밋·push 여부: `b9cb282`로 커밋했고 v4.8 버전 표시를 올렸다. 사용자 결정으로 개발을 이어 가므로 push·태그·Release 게시는 하지 않았다.
