## 결정과 진행

- 2026-09-27: 사용자 요청으로 후보 추천 후 시각 시안을 만든다. 후보 선정 기준은 사용자(기후에너지환경부 직원·망분리 오프라인), 기존 두 앱의 "정확한 계산 도구" 성격, AGENTS.md의 오프라인·메모리 전용·DB/설정 불변·추정 데이터 금지·새 의존성 회피다.
- 2026-09-27: 공문서 금액 표기 형식은 「행정업무의 운영 및 혁신에 관한 규정 시행규칙」 제2조의 예시 `금113,560원(금일십일만삼천오백육십원)`을 확인해 사용한다([국가법령정보센터](https://www.law.go.kr/LSW/lsInfoP.do?efYd=20230628&lsiSeq=252189), 조문 확인은 [U-LEX 사본](https://www.ulex.co.kr/%EB%B2%95%EB%A5%A0/252189-007319-%ED%96%89%EC%A0%95%EC%97%85%EB%AC%B4%EC%9D%98%EC%9A%B4%EC%98%81%EB%B0%8F%ED%98%81%EC%8B%A0%EC%97%90)). 실제 구현 시 원문을 다시 대조한다.
- 2026-09-27: 시안 스타일은 `ui_date_time_calculator.py`(창·메뉴·결과 카드 색/크기), `ui_converter_combo.py`(28px 콤보), `ui_mini_apps.py`(주머니·92px 타일) 값을 그대로 옮긴다. 예시 수치는 실제 정책·통계값이 아닌 중립 값이다.

- 2026-09-27: 첫 렌더에서 발견해 수정한 것:
  - 줄바꿈 정리 본문이 1px 넘쳐 원문 입력칸 높이를 줄였다.
  - 입력값에서 나온 합계·차이가 `1,005.0`처럼 표시되어, 입력값은 입력 정밀도로, 계산한 비율만 선택 자릿수로 표시하게 바꿨다.
  - 비중 반올림 경고 때 합계 숫자 전체가 빨갛게 보여, 경고 문장만 강조했다.
  - 정리 미리보기가 고정폭 글꼴로 보여 앱 글꼴로 바꿨다.
  - 빈 공간에 한 줄 복사 미리보기를 추가했다. 비중·목표 감축 화면이 넘치지 않도록 항목 추가 버튼을 표 머리글로 옮겼다.
- 2026-09-27: Chrome 디버깅 연결이 없어 이전 시안과 같은 방식을 썼다. 프로젝트 `.venv`의 Qt WebEngine off-record 프로필을 이 폴더에 한정해 사용했다. 앱·실사용 데이터는 열지 않았다.
