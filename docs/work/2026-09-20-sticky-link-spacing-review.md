## 결정과 진행

- 현재 배지 글꼴은 9px, 채움 높이는 13px로 고정되어 있다.
- 링크 끝 장식 여백은 내부 4px + 주의 표시 16px이며 정상 상태에도 동일하다.
- 합성 경로만 사용하며 파일 검사와 환경 식별은 진단 프로세스 안에서 가로챈다.
- 기본 Malgun Gothic 13px에서는 줄 높이 17px, 라벨 높이 15px, 배지 높이 13px다. 상하 1px에 테두리 1px가 들어가므로 안쪽 빈 간격이 0px다. 12px/11px 본문에서는 배지가 테두리 영역과 각각 0.5px/1px 겹친다. 두 편집기에서 같은 결과다.
- 공백 없는 `앞회의자료다음글자`에서 라벨 끝과 다음 글자의 실제 커서 위치 사이가 16px다. 마지막 링크 글자의 advance 끝부터는 내부 여백까지 20px이며 기본 13px 글꼴의 공백 5px 기준 약 4칸이다. 원문에는 공백이 추가되지 않았다.
- 권장 방향은 배지 글자 9→8px, 채움 높이 13→11px와 가로 padding 축소, 테두리와의 최소 내부 여백 보장이다. 현 구현은 pt가 아닌 px 단위이므로 1pt 감소와 같다고 표현하지 않는다. 정상 링크의 외부 간격은 2~3px 정도로 줄이고 끊김 표시만 별도로 공간을 처리하는 후속 설계가 필요하다.
