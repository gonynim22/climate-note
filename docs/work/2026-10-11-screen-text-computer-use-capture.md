## 결정과 진행

- 사용자가 다음 단계 진행을 요청했다. Computer Use 지침은 `Do not automate terminal applications`를 명시한다. 메모장에 CLI 형태의 시험 문구를 표시해 캡처하며, Windows CLI 자체의 렌더 검증과 구분한다.
- 기존 수집 계획의 30원문(6분류 × 5개), dev 24 / holdout 6을 그대로 유지한다. 첫 조건 및 더 큰 표시 조건을 실제 창에서 확인한다. 파생 이미지 수를 새 원문 수로 부풀리지 않는다.
- 실제 프로그램 화면이지만 직접 구성한 시험 문구다. 자연 업무 자료·다양한 앱/실제 혼합 DPI를 대표하지 않는다. 정답은 OCR 실행 전에 원본 화면을 대조해 확정한다.
- Computer Use의 실제 반환 형식은 **JPEG**였다. 원본 JPEG 12장을 그대로 보존하고 본문 영역만 좌표로 잘라 PNG 60개를 저장했다. 크기 조정·글자 재그리기는 없지만 PNG 저장이 원본 JPEG 압축을 되돌리지는 않는다.
- Windows Notepad 10.0.26100.8875, 맑은 고딕 보통 12pt, 밝은 배경, 실제 앱 확대 100/150%를 확인했다. Windows DPI는 따로 측정하지 않았다. 줄 바꿈 설정은 켜져 있었지만 시험 본문의 자동 줄 바꿈은 관찰되지 않았다.
- 원본 12장과 60개 crop의 접촉 시트를 OCR 전에 시각 대조했다. 정답은 원문 코드포인트/공백 복구 기준이며 AI의 시각 검토다. 독립적인 사람의 검토는 아니다. 맑은 고딕에서 역슬래시가 원화 글리프로 보이는 사례는 별도 태그를 남겼다.
- 초기 미검토 corpus `20261011-105930-3631be0e`를 보존했다. 포인터가 포함된 crop 1개의 사각형을 수정해 `20261011-110046-90709b58`을 만들고, 대조 완료본은 `20261011-110141-8580bbd5`에 별도 저장했다. 30개 원본 그룹의 dev 24/holdout 6 분할을 유지했다.
- 추론 전에 `evaluation-plan.json`에 dev 48개와 기존 `baseline`/`rec-selective-stable` 후보를 고정했다. holdout 12개는 추론하지 않았다. 정답·태그로 재인식 대상을 고르지 않았다.
- 새 시험 메모장의 확대를 100%로 복원하고, 마지막 시험 문구만 이번 실행 폴더에 저장한 뒤 해당 창을 닫았다. 저장 문구와 계획 원문이 일치하고 시험 창이 닫혔음을 확인했다. 글꼴은 조회만 했다.

## 보조 실패와 수정

- 첫 저장 보조 함수가 PNG 반환을 가정해 MIME 검사에서 중단했다. 실제 JPEG 형식을 확인한 뒤 원본 형식으로 저장했으며 잘못된 확장자 파일을 증거로 쓰지 않았다.
- 메모장 소유 대화상자의 UIA 요소 번호 일부가 유효하지 않아 선택이 실패했다. 새 상태/포커스를 확인해 키보드 경로로 마무리했다. 초기 창 표시 중 배경이 섞인 전환 프레임은 자료에 저장하지 않았다.
- 초기 접촉 시트 생성에서 포인터를 포함한 경로 crop의 폭 검사가 실패했다. 원본·초기 corpus는 보존하고, 글자 전체를 유지하는 사각형으로 수정한 새 미검토 corpus 및 검토 완료본을 만들었다. 모든 평가 결과는 수정 완료본을 사용한다.

## 미해결과 인계

- 첫 수집·평가 연결은 완료했다. 실제 CLI, 다양한 앱/테마/글꼴, 자연 업무 자료와 원본 1,000개 확보 목표는 남아 있다. 시험 입력 커서가 일부 보이며, JPEG 압축·글리프 모호성을 포함한 자료다.
- 제품의 영역 선택 UI부터 복사까지의 전체 경로, Windows DPI, 표 구조는 검증하지 않았다. 보류 12개는 후보를 확정하고 새 원문 그룹과 함께 확대할 때까지 유지한다.
- 다음 진단은 유사 문자·숫자·기호와 일반 한글의 무경고 오류를 분리해 입력/모델 및 불일치 경고를 평가한다. 경로 코드포인트 모호성과 일반 판독 오류를 섞어 규칙을 선택하지 않는다.
- 배포·커밋·push: 수행하지 않음.
