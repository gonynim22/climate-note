# 작업 기록: 공개 행정문서 실제 화면 평가

작성일: 2026-10-11 / 상태: 공개 원본 준비 완료, 실제 앱 접근 승인 차단으로 캡처 대기

## 목표와 범위

- 사용자 요청에 따라 합성 글자 이미지에서 실제 공개 행정문서의 앱 화면으로 평가 범위를 확대한다. 한글·PDF·Word와 일반 업무 메모를 구분한다.
- 공개 원본과 URL·SHA-256, 앱 캡처 원본·잘라낸 영역·정답 근거를 실행 폴더에 보존한다. 실사용 문서·AppData·DB·salt에는 접근하지 않는다.
- 현재 제품 모델 P와 마지막 후보 F(`export-f-b21-lr5e-5-frozen-bn-v1/bundle.json`)를 같은 화면에서 비교한다. 평가 자료로 재학습하거나 결과를 보고 정답·영역을 조정하지 않는다.
- 제품 코드·모델·사전·의존성·설정·EXE는 유지한다. 기존 dirty/untracked 작업을 보존한다.
- 관련 계약: [제품](../SCREEN_TEXT.md), [진단](../SCREEN_TEXT_LAB.md), [검증](../TESTING.md), [학습 기록](2026-10-11-screen-text-finetuning-implementation.md).

## 결정과 진행

- 사용자는 공개 행정문서로 진행하도록 선택했다. 행안부의 공개 HWP/PDF 문서를 우선 확보한다. 실제 앱 캡처와 PDF 직접 렌더, 공개 문서와 작성한 메모는 각각 구별한다.
- 1차 자료는 탐색용 실제 문서 파일럿이다. 앱별 충분한 독립 문서 수·사람 검토·잠긴 최종 평가 자료를 갖춘 제품 채택 검사로 해석하지 않는다. 기존 보류 12장은 열지 않는다.
- 에이전트 3개는 사용량 제한으로 중단되어 본 에이전트가 진행한다.
- 실행 ID: `20261011-173105-6d4069071c`.
- Computer Use가 `sky.launch_app`의 한글 2022 및 Word 실행을 각각 `Computer Use was not approved to use ...`로 거부했다. 다른 실행 경로로 우회하지 않는다. 원본 수집과 허용되는 앱 확인을 계속한다.
- Chrome의 로컬 PDF 탐색은 http/https 외 프로토콜 차단, 별도의 기관 웹사이트 공개 PDF 탐색은 `The user declined permission for this action`으로 거부됐다. 로컬 파일을 HTTP로 제공하거나 다른 앱으로 거절된 사이트에 접근하는 우회는 하지 않았다.
- 공개 원본 3개를 확보했다: 행안부 「공문서 작성 방법을 쉽고 편하게 바꾼다」 HWP/PDF 한 쌍, 환경부 「제12차 용산 어린이정원 대기 모니터링 결과」 PDF. **독립 문서는 2종**이며 PDF 합계 6쪽이다. 원본 SHA-256은 `sources.json`에 기록했다.
- 본문·날짜·비율·항목 표·금액·소수점·단위·불검출·결측이 있는 8개 대상 영역을 계획했다. 이는 완료된 사례 수가 아니다. 동일 문서의 앱/배율 차이는 독립 문서로 세지 않는다.
- PDF 텍스트와 원문 확인용 미리보기는 기존 QtPdf로 읽기 전용 생성했다. 흰 배경 합성 전 투명 미리보기는 보고서에서 제외하고, 수정 미리보기 6쪽만 연결했다. 파일 직접 렌더이므로 **실제 앱 캡처가 아니며 OCR 평가에 사용하지 않았다**.
- 금액과 숫자 표 일부의 정답 초안을 원문 미리보기와 대조했다. 실제 앱 화면·전체 셀·글자 코드·공백 검토와 독립 사람 검토는 미완료다. 공개 문서를 재작성한 Word/메모장 화면도 공개 원본 화면과 별도 구분할 예정이다.
- 제품 P의 모델·사전·검출기와 기존 최상 F 후보의 해시/출처를 검증했다. **현재 실제 캡처 0장, 인식 0건, 신규 오류율 없음**. 최종 보류 자료와 제품 파일은 변경하지 않았다.

## 미해결과 인계

- 실제 한글·Word 화면은 앱 사용 미승인으로 아직 확보하지 못했다.
- 후속 원문 수집: 사용자가 제안한 공공데이터포털 API를 `.env` 키로 확인했다. [API 실물 조사](2026-10-11-screen-text-public-doc-api.md)에서 JSON 30,278건·표본 20건·ppm 원문 13건을 확보했지만 원본 HWP/PDF는 묶음에 없었다. 실제 앱 캡처/정답 확정 단계는 그대로 남아 있다.
- 배포·커밋·push: 수행하지 않음.
