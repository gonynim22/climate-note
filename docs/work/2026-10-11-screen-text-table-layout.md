## 결정과 진행

- 기존 진단은 [진단 기록](2026-10-11-screen-text-original-diagnosis.md)을 따른다. 16영역은 이미 오류를 관찰한 개발 표본이며 독립 성능 평가로 표현하지 않는다.
- 원래 union 행을 무조건 중심 중앙값으로 분할하지 않는다. 두 열 이상에서 반복되는 분리된 줄이 확인될 때만 분할하는 후보를 확인한다. 셀 내부는 물리 줄 순서를 유지하고, 열 띠는 작은 접촉과 실제 겹침을 구별한다.
- 병합 헤더는 본문 열에서 기하 근거가 있는 경우만 첫 칸에 배치하며, 문장/불명확한 배치를 억지로 표에 넣지 않는다. 원문/정답/모델을 수정해 점수를 높이지 않는다.
- 구현은 `screen_text/layout.py`에 한정했다. 상자 좌표·글자·점수·공개 함수/블록 형식은 유지한다. 본문 전체의 열을 확인하고 머리글을 배치하며 작은 겹침은 열별 대응으로 처리한다. 한 셀 안에 들어가는 겹친 판독 조각은 같은 셀로 보존한다.
- 신규 회귀 25개(기존 19개 포함 총 44개)는 문서 문자열/ID와 무관한 합성 좌표를 사용한다. 100/125/150/200% 좌표·이동·입력 역순, 숫자 행 분리, 여러 줄 셀 순서/경고, 작은 열 접촉, 두 판독 조각, 병합 헤더·일반 문장·멀리 떨어진 머리글을 검사했다.
- 시행 중 합성 표의 두 판독 조각이 분리되는 퇴행 1건을 찾아 수정했다. 본문 행까지 간격 제한을 적용한 중간 후보는 실제 일정표 일부를 표 밖으로 빼므로 채택하지 않았다. 간격 확인은 별도 머리글에만 한정했다. 각 중간 결과는 실행 폴더의 `candidate-1/2/3`에 보존하며 통과 근거는 `final/`만 사용한다.

## 미해결과 인계

- 사전 미지원 기호와 인식 오류, 미수집 원본, 독립 사람 검수는 기존 후속 범위를 유지한다.
- 행을 가로지르는 `(ppm)` 표기, 여러 줄 극장 머리글, 비어 있는 일정 열은 완전히 복원되지 않았다. 표 7개 중 완전 일치는 여전히 1개다. 이번 개발 표본 개선을 일반 문서 정확도로 주장하지 않는다.
- 정본 변경: [화면 글자 따기 계약](../SCREEN_TEXT.md), [검증 지침](../TESTING.md). 시작 시 기존 문서 수정은 보존했다.
- 다음 행동: 새 실제 표 자료/독립 검수로 일반화 확인, 남은 인식/사전 지원은 표 구성과 분리하여 다룬다.
- 배포·커밋·push: 수행하지 않음.

### 후속 적용 결정

- 사용자가 추가 학습 보류와 기존 모델/표 구성 개선 유지를 선택했다. [EXE 적용 기록](2026-10-11-screen-text-table-build.md)의 PowerShell release `20261011-212137-470e230764`에서 현재 코드 2,437개 검사·새 빌드·격리 3개 시나리오를 통과했고 `dist/기후노트_v3.9a.exe`에 배치했다. 모델은 기존 그대로다.
- 위 최초 검증 표의 EXE 미실행은 당시 상태다. 실제 한글 붙여넣기·혼합 DPI 미확인은 유지하며, 이 후속 빌드를 독립 문서 정확도 평가로 세지 않는다.
