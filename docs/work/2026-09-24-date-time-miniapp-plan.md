## 기능 계획 (A안 기준)

앱 이름은 **날짜·시간 계산기**로 제안한다. 주머니의 두 번째 자리(첫 행 오른쪽)를 사용하며 기존 단위 환산기를 유지한다.

| 모드 | 입력 | 주요 결과 |
|---|---|---|
| 시간 차이 | 시작·종료 날짜/시각, 휴게 공제 분. `날짜 포함 → 시간 없이 날짜만 비교`도 제공 | 총 분을 주 결과로, 일·시간·분·초와 총 초. 날짜만 비교 시 경과 일수가 주 결과 |
| 날짜 더하기·빼기 | 기준 날짜/시각, 년·월·일·시간·분·초, 더하기/빼기 | 계산된 날짜/시각, 적용 순서 및 월말 보정 표시 |
| 근무일 | 시작·끝 날짜, 양 끝 포함, 제외 요일, 공휴일 제외 | 근무일 수와 제외 일수, 사용한 공휴일 자료 범위 |
| 시간 합산 | 기간 여러 개, 행별 더하기/빼기. 구간 합산에서는 시작·종료·휴게 여러 행 | 누적 총 분·총 초와 일·시간·분·초 |

### 계산 기준

- 시각은 24시간제다. `12:00 → 18:59`는 **6시간 59분 = 419분 = 25,140초**다. 시간 차이에 포함일 옵션을 적용하지 않는다.
- 초까지 입력할 수 있다. `419분 30초`를 임의로 419분 또는 420분으로 바꾸지 않는다. 정수 분 복사가 필요한 경우 버림·반올림·올림을 명시적으로 선택하는 방식을 실제 구현 시 제공한다. 기본 결과·기록에는 원본 초를 보존한다.
- 시간만 입력할 때 자정 넘김은 `다음 날`을 명시적으로 선택한다. 종료가 먼저라고 자동으로 다음 날로 추정하지 않는다. 날짜를 켜면 두 날짜를 직접 비교한다.
- 휴게 공제는 기본 0분이며 수동 입력이다. 전체 구간을 초과하는 공제는 오류로 표시한다. 기본 근무시간, 점심시간, 최소 인정시간 등을 자동으로 차감하지 않는다.
- 경과시간의 하루는 24시간이다. **년·월은 달력 연산**이며 1년=365일, 1개월=30일 같은 고정 환산을 하지 않는다.
- 날짜 연산은 년·월을 총 월수로 합쳐 한 번 적용한 뒤 일·시간·분·초를 적용한다. 대상 월에 날짜가 없으면 말일로 보정하고 결과에 그 사실을 표시한다. `2026-01-31 + 1개월 → 2026-02-28`.
- 날짜 두 개 사이의 달력상 `몇 년 몇 개월 며칠` 표현도 제공한다. 두 시각을 오름차순으로 정렬하고, 앞 날짜에서 한 번의 월 이동으로 뒤 날짜를 넘지 않는 최대 총 월수를 구한 뒤 12로 나눠 년·월을 표시한다. 보정된 중간 시각부터 남은 일·시·분·초를 센다. 역순 입력은 전체 기간 앞에 음수 부호를 표시한다. 이 분해 결과는 총 일/분/초와 구분하며, 음수 월 연산을 되돌리면 항상 원본이 되는 것은 아니다.
- 순수 날짜 차이의 기본은 경과 일수다. 근무일의 양 끝 포함 개수와 구분한다. 일반 날짜 차이·기간 합산은 음수 결과를 허용하고, 근무 구간·근무일의 역순 입력은 오류와 시작/종료 바꾸기 동작을 제공한다. 잘못된 날짜·24:30·초 60·음수 휴게·범위 초과는 기존 결과를 지우고 해당 입력에 오류를 표시한다.
- 근무일은 기본 양 끝 포함, 토·일 및 공휴일 제외다. 시작/끝 포함을 개별 선택하고 공휴일과 주말은 중복 차감하지 않는다.
- 공휴일은 기존 `holidays.py`의 실제 API 자료만 사용한다. 현재 `KOREAN_HOLIDAYS`의 범위는 **2025–2027년**이며 2050년까지의 음력 매핑과 구분한다. 자료 밖 연도는 공휴일을 0으로 간주하지 않고 공휴일 제외 결과를 보류한다. 사용자가 공휴일 제외를 끄면 선택한 요일만 제외한 결과임을 표시한다.
- 날짜 없는 기간 합산은 일·시간·분·초만 받는다. 년·월을 포함하는 연산은 기준 날짜가 있는 모드에서 처리한다.
- 일반 업무용 현지 날짜·시각의 벽시계 계산을 대상으로 한다. 다른 시간대 간 변환·DST·윤초는 초기 범위 밖이다.

계산 기준 참고: [Qt QDate의 월말 보정](https://doc.qt.io/qt-6/qdate.html#addMonths), [Python datetime의 기간/총 초](https://docs.python.org/3.13/library/datetime.html#timedelta-objects). 공휴일은 외부 계산을 도입하지 않고 저장소의 자료를 그대로 사용한다.

## 시안 방향

**사용자 선택: A · 분 중심 업무형.** 2026-09-24 사용자가 "좋아 A가 좋네"라고 선택했다. 기존 환산기와 통일되는 왼쪽 메뉴, 입력 아래 총 분 강조를 기본 배치로 확정한다. B/C는 비교용 시안으로 보존하며 C의 계산표 배치를 혼합하는 것으로 해석하지 않는다. 네 가지 계산 모드와 아래 계산 기준은 A의 메뉴 구조에 배치한다.

1. **A · 분 중심 업무형**: 환산기와 통일되는 어두운 왼쪽 메뉴. 입력 아래 총 분을 강조한다.
2. **B · 간결한 탭형**: 위쪽 기능 탭과 세로 시간 흐름. 작은 창에서 날짜와 시간을 고르게 다룬다.
3. **C · 계산표형**: 여러 시간 구간을 행으로 입력하고 합계를 상단에 표시한다. 반복 초과근무 구간 계산에 적합하다.

시안은 `output/design/date-time-miniapp/concept-a.html`, `concept-b.html`, `concept-c.html`이며 대화에서 직접 조작할 수 있게 제공한다. 작업용 원본은 같은 폴더의 `concept-template.html`, 자료 삽입/렌더 재현은 `prepare_preview.py`, 검증은 `verify_preview.py`다. 로컬 검토용 완성 페이지 `preview-a.html`~`preview-c.html`도 생성했다. 제품 코드에는 포함하지 않는다.

시안의 초기 너비는 A 480px/B 440px/C 560px이며 검토 화면 폭에 맞춰 줄어든다. 실제 Qt 창의 내용 크기·그림자 여백·짧은 화면에서의 스크롤은 선택 후 배율 검증으로 확정한다. C의 시안에서는 구간 합산을 시간 차이 화면으로 전면 배치하며, 실제 구현에서는 기간 합산과 구간 합산의 구분을 유지한다.

시안 조작 범위: 네 모드 전환, 시간·초 입력, 휴게 공제, 익일 선택, A/B의 날짜 포함 및 날짜만 비교, 년월일시분초 더하기/빼기, 실제 번들 공휴일과 제외 요일 계산, 기간 합산, C의 구간 추가. 결과 복사는 브라우저 권한이 허용되면 클립보드에 쓰고 제한된 미리보기에서는 결과 선택 후 Ctrl+C로 안내한다. 모드 전환 시 예시는 초기화된다. 최근 기록·입력 상태 보존·행 삭제·구간별 날짜·년월일 차이 분해·정수 분 반올림 선택은 실제 구현 단계의 기능이며 이 시안에 모두 구현되어 있지는 않다.
