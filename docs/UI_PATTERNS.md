# UI Patterns Reference

## v4.5 반복 회차 편집

반복 일정의 우클릭/더블클릭에서 '이 날만 수정'과 '반복 전체 수정'을 선택한다. 실제 메뉴의 마우스 클릭과 Enter 선택은 같은 실행 경로를 사용하며, 소유 타이머가 메뉴 클릭 반환 후 편집기를 연다. 재조회·숨김·잠금·폐기 때 메뉴와 예약을 취소하고 실행 직전에 가시성·활성·잠금·트레이 상태를 확인한다.

회차 편집은 본문/이모지·기존 3색(v4.9부터 줄 앞 색 원)·시각·알림만 제공한다. 날짜 이동·기간·반복 행은 숨기고 편집 범위를 표시한다. 수정 회차에서 전체 편집을 열면 DB 원본을 읽는다. 편집 중에는 목록에 입력·범위 안내를 포함한 한 행의 최소 높이를 확보하고 종료 때 원래 최소 높이로 복원한다(large의 요약 잘림 방지). 취소와 무변경 완료는 수정 행을 만들지 않고, 저장 실패 시 편집 원본을 유지하며 이동/종료를 보류한다. 전체 수정은 수정 회차를 보존하고 반복 해제는 일반 일정으로 남긴다. 첫날 수정 회차가 있으면 같은 날 두 일정이 남을 수 있음을 카드에서 안내한다.

'이 날만 수정됨' 표시는 화면 전용이다. 일정/검색 툴팁은 `ui_text.plain_tooltip`으로 HTML처럼 보이는 본문을 escape해 원문 글자로 표시하며 DB·복사·내보내기 본문을 바꾸지 않는다. 데이터 계약과 검증은 [설계](superpowers/specs/2026-10-25-recurring-occurrence-edit-design.md)·[v4.5 기록](work/2026-10-25-v4.5-execution.md)을 따른다.

## Layout

- **Two-Tone Layout**: `#mainContainer` (transparent wrapper) → `#headerSection` (navy `#01295F`, top-rounded) + `#calendarSection` (white `#FFFFFF`, bottom-rounded). Header uses individual `border-*-radius` properties for Qt stylesheet compatibility.
- **Header (Navy)**: Month label (`"26년 3월"`), nav buttons (◀▶), "오늘" button — all white text/icons on `#01295F`. Icon buttons use `FIF.xxx.icon(Theme.DARK)` for forced white icons. Nav group (◀ label ▶) is a sub-layout; `addStretch()` separates it from right-aligned action buttons.
- **Font**: Malgun Gothic is the default app font. App text fonts are not bundled; users can switch between installed system fonts in Settings, and the selection is saved immediately and applied after app restart. Sticky todo backing markers remain Font Awesome-compatible, while their visible checkbox is painted as a vector control. The display highlighter gives every marker (FA or legacy ☐/☑) the painted box width through letter spacing only, so the body keeps the same position and gap when checked or unchecked and the strikeout never touches the box; stored HTML and characters are unchanged.
- **Font Sizes**: Use integer `px` values only in QSS (`12px`, `14px`, etc.). Avoid fractional pixel sizes because they blur more noticeably in Windows Qt rendering.
- **Theme (2026-10-10 밝게 고정)**: Windows 다크 모드와 무관하게 항상 밝게 그린다. `main._apply_light_theme()`이 창을 만들기 전에 Qt 색 구성표(`styleHints().setColorScheme(Light)`)와 qfluentwidgets `Theme.LIGHT`를 함께 고정한다. Windows가 다크면 Qt 기본 위젯 팔레트(windows11 스타일)도 어두워지므로 한쪽만 고정하면 흰 바탕에 흰 글자가 남는다. 실행 중 Windows 테마를 다시 읽거나 따라가는 경로(예전 60초 레지스트리 폴링)를 두지 않는다. Header is always navy (`#01295F`), calendar section always white (`#FFFFFF`). qfluentwidgets icon buttons in header use `Theme.DARK` for white icon rendering regardless of OS theme.

## Calendar

- **v4.3 저장·크기 전환**: 스티키 주기 저장은 현재 보기의 변경된 원본만 저장한다. 성공 후 변경 상태를 해제하고 실패 시 유지·재시도하며 상태줄에 실패를 남긴다. large에서는 숨은 플로팅 본문으로 저장하지 않는다. 크기 전환의 스티키 인계가 실패하면 전체 레이아웃·D-Day/집중 패널·현재 적용 크기와 설정 선택을 이전 상태로 유지한다. 설정 복원 실패는 로그를 남기고 메모리의 현재 크기를 유지한다. 화면 갱신 중 예외가 나도 `setUpdatesEnabled(True)`를 복원한다. 새 스티키 상한 10개는 가시성이 아니라 등록된 열린 노트 수로 센다.
- **v4.3 잠금 PIN**: 설정창은 기존 PIN/검증값을 입력칸에 미리 채우지 않는다. 새 PIN 저장 성공 후 입력을 비운다. 잠금 오버레이는 5회 실패 뒤 30초, 이후 실패마다 대기 시간을 늘려 최대 300초를 적용한다. 성공 시 횟수를 초기화하고 숨김/재표시로 대기를 초기화하지 않는다. 대기는 메모리 전용이며 앱 재시작 또는 DB 파일 접근까지 막는 보안 경계는 아니다.

- **망 전환/KVM 위치 복원(v3.8 후속)**: 기본·중간·크게 모두 자동 화면 보정을 임시 표시로 취급한다. 원래 저장 좌표를 덮어쓰지 않으며 대상 화면이 돌아오면 복원한다. 위치 고정 상태(위치 편집 중이 아닐 때)도 같은 복원 규칙을 따른다. 명시적 이동·모니터/모서리 선택 때만 화면 식별 정보와 위치를 함께 저장한다. 설정의 모니터 목록이 열린 동안 연결 순서가 바뀌어도 표시된 장치를 선택하며 사라진 항목과 저장 실패는 이전 선택을 유지한다. 가로↔세로 모니터 선택 시 크기도 목적지 기준으로 다시 계산한다. 새 설정 없는 기존 사용자는 인덱스를 세션 내에서만 기억하고 자동 설정 쓰기를 하지 않는다. 구체적인 식별·저장 계약은 [아키텍처](ARCHITECTURE.md)의 KVM 계약을 따른다.

- **위치 편집 단추 (2026-10-11 J안, v3.7b 이동 토글 대체)**: 검색 → 십자 화살표 → 더보기 순서로 32px 버튼 3개와 4px 간격을 둔다. 좌우 헤더 그룹은 104px, 연월 그룹은 148px라 기본 380px에서도 중앙 정렬과 전체 클릭 영역을 유지한다. 십자 화살표는 다른 머리줄 아이콘처럼 바탕을 채우지 않은 흰 선이며 상태를 표시하지 않고 위치 편집을 시작한다(이전 ON 점·OFF 사선 토글은 '점이 무슨 뜻인지 모르겠다'는 사용자 의견으로 폐기). 편집 중에는 검색·십자 화살표·더보기를 숨기고 같은 104px 묶음 오른쪽 끝에 '완료' 알약(52×32, 13px 굵게, 테두리 `#93C5FD`)을 둔다. Tab → Space/Enter로 시작하면 포커스가 '완료'로, '완료'에서 끝내면 십자 화살표로 돌아온다. 두 단추 모두 마우스 클릭으로 일정 입력 포커스를 빼앗지 않는다. 화면·문서에서는 '십자 화살표'라고 부른다.
- **위치 편집 상태·범위**: 캘린더는 항상 고정 상태로 시작하고 편집 상태는 메모리 전용이다. 예전 `calendar_move_enabled` 행은 읽지 않으며 지우거나 새로 쓰지도 않는다(Export·Import에도 그대로). 편집 중에는 창 안쪽 가장자리에 2px 점선(6px 선·4px 틈)을 그린다. 남색 머리줄 위는 `#93C5FD`, 그 밖(흰 칸·회색 바로가기 열·안내 띠·크게 오른쪽 열)은 `#2563EB`로 어느 바탕에서도 대비 4.6:1 이상이다. 노랑은 키보드 포커스(`#FBBF24`)와 겹쳐 쓰지 않는다. 머리줄 바로 아래 28px 안내 띠(`#EAF2FF`/`#1D4ED8`, "머리줄을 끌어 원하는 곳에 두고 '완료'를 누르세요")는 달력 칸을 밀지 않도록 겹쳐 그리며 마우스는 통과한다(`CalendarMoveEditOverlay`). 위치는 끌기를 놓을 때 저장하고 '완료'는 저장하지 않는다. '완료'·Esc·창 비활성(다른 곳 클릭)·PIN 잠금·트레이 숨김·크기 변경·가져오기/초기화에서 편집이 끝나고 진행 중 끌기를 취소한다(놓기 전이면 창을 끌기 전 자리로 되돌린다). 모니터 변경은 편집을 유지하고 끌기만 취소한다. 고정 중 머리줄을 끌면 실행마다 한 번 머리줄 바로 아래 가운데에 InfoBar(제목·본문 세로 배치, 3초)를 띄워 십자 화살표를 알려 준다(위쪽 자동 배치는 그 단추를 가려서 쓰지 않는다). 개별 위젯 이동·설정의 화면/모서리 선택·모니터 분리 복구는 편집 상태와 무관하다. 크게의 크기 계산은 유지하므로 같은 화면에서는 보통 축당 총 40px 안에서만 이동하며 다른 화면에서는 목적지 크기로 보정한다.

- **Calendar Cells**: `CalendarDayButton(QWidget)` supports compact and expanded modes. Compact keeps the 3-row [Day Number] / [Color Squares] / [Total Count] structure. Expanded shows one-line colored schedule chips, elides long titles, and ends overflow with `+N 더` while preserving at least one real event chip.
- **요일 열 너비**: 날짜 그리드와 별도 요일 제목 그리드 모두 7열에 동일한 stretch를 둔다. 일정 칩은 가로 `QSizePolicy.Ignored`를 사용해 말줄임된 QLabel 문자열이 셀/열의 최소 권장 너비를 결정하지 않게 한다. stretch만 같게 두는 것으로는 긴 일정이 있는 열의 최소 너비를 해소할 수 없다. `tests/test_ui_calendar_columns.py`는 세로 화면의 첫 표시·금토 일정 추가·월 이동 후 오늘·가로/세로 화면 왕복에서 실제 7열의 너비 차이와 제목 중심 오차가 1px 이내인지 검증하며, 칩 폭 변화 후 말줄임·툴팁 전체 본문과 기존 암호문·salt·설정·Export 보존도 확인한다. 열 너비를 바꾸려고 일정 본문·색상이나 DB 값을 수정하지 않는다.
- **Calendar Scale**: `compact` keeps the schedule panel below the calendar. `medium` and `large` force the shortcut sidebar visible and re-parent the schedule panel into a right column, producing [shortcuts | calendar | schedules]. 기본 크기(compact)의 바로가기 열만 설정 '기본 크기 바로가기' 스위치(툴팁에 적용 범위 표시)를 따른다. 새 설치(처음 실행 크기 선택)·초기화의 기본값은 켜짐(460px)이고, 기존 DB의 저장값은 바꾸지 않는다(2026-10-11, 이전 기본 꺼짐 380px). 중간·크게(expanded 셀)에서는 날짜 숫자를 일정 칩과 같은 왼쪽 위(26×26)에 두고, 오늘은 칸을 칠하지 않고 숫자 뒤 남색 원(`#01295F`, 흰 숫자), 고른 날은 칸 전체를 기본 크기와 같은 연한 회색(`rgba(1,41,95,20)`)으로 채우고 테두리는 두지 않는다(오늘을 고르면 회색 칸 위 남색 원, 2026-10-11 사용자 요청으로 15번 테두리를 되돌림). 요일 머리줄은 기본 11px 가운데, 중간 12px·크게 13px 왼쪽 정렬이다(`_style_weekday_header`). 기본 크기 칸(오늘 남색 칸·선택 옅은 채움)은 그대로다(2026-10-10 디자인 점검 15번).
- **날짜 칸 구분선(v4.9 A안, 설정 스위치·기본 꺼짐)**: 설정 '칸 구분선'(`calendar_grid_lines_enabled`, `"1"`/`"0"`, 키가 없으면 꺼짐)을 켜면 세 크기 모두 날짜 칸과 칸 사이 1px 틈에만 `#E3E6EA` 선을 긋는다. 바깥 틀(맨 위·맨 아래·좌우 끝)과 요일 머리줄 아래에는 긋지 않고, 이번 달 밖 빈 칸 사이에도 이어 긋는다. 켜면 날짜 격자와 요일 머리줄 격자의 틈이 함께 2px→1px이 되고, 오늘(기본 크기 남색 칸)·고른 날·공휴일 테마 바탕의 채움은 선에서 2px 안쪽(칸 QSS `margin: 2px`, 배경만 줄고 칸 안 배치는 그대로)·모서리 5px다. 끄면 v4.8 모양(틈 2px·모서리 6px) 그대로다. 선은 `ui_calendar_grid.CalendarGridLines`(캘린더 영역 전체를 덮는 마우스 통과 맨 아래 층, 그릴 때마다 칸 위치를 잰다)가 배율과 무관하게 장치 1픽셀 선으로 긋고, 여러 날 막대는 그 위를 지나간다. 고른 날은 채움만 쓴다(15번 되돌림 유지). 숫자 위치·오늘 원·칩·`+N 더`·색 네모와 최초 크기 선택 미리보기는 바꾸지 않는다. 표시 전용이고 쓰기는 스위치 키 하나다. 검사는 `tests/test_ui_calendar_grid_lines.py`(1.25·1.5배 하위 프로세스 포함), [설계](superpowers/specs/2026-11-10-calendar-cell-grid-lines-design.md).
- **Calendar Drag**: Drag only the navy header background or month label. Movement below `QApplication.startDragDistance()` remains a click. All three sizes use the header movement toggle (default ON); OFF blocks only manual calendar dragging. A completed drag resizes layouts for the destination screen, clamps the full window, then stores free coordinates, target screen, and nearest corner. Saved target screen wins over a newly calculated center when the window changes size. Navigation/search/settings controls keep their normal click behavior; Monitor or corner selection in Settings switches back to corner placement.
- **Window Opacity (v4.9 두 갈래)**: `app_opacity` (calendar value) applies to the main window, including the large-mode mini panels inside it; `widget_opacity` applies to floating sticky/D-Day/focus windows and falls back to `app_opacity` while the key is missing. Both are 30-100 percent and applied immediately; new and reloaded floating widgets open with the widget value. Details are in '투명도' below.
- **Schedule Color Squares & Count**: `_refresh_calendar()` calls `db.get_all_schedule_date_colors()` and `db.get_all_schedule_date_counts()` once each. Raw schedule colors remain the three canonical slot tokens; `db.schedule_display_color()` resolves the selected display palette for compact squares, expanded chips, the schedule list, color-cycle button, and search results. `_refresh_cell_for_date()` updates a changed date in place. 기본 크기 칸의 네모는 그날의 서로 다른 색마다 하나(최대 3개)이고, 아래 숫자는 네모로 다 보이지 못한 일정 수만 `+N`으로 보인다(같은 색 3개 → 네모 1개 + `+2`, 네모 수와 일정 수가 같으면 숫자 없음, 2026-10-10 디자인 점검 12번).
- **Schedule Inline Edit**: Double-click a schedule item to edit in-place. Enter saves, Escape cancels, and focus leaving the composite editor saves. Moving between its input, emoji button and owned popup does not finish editing. Uses `db.update_schedule()` for encrypted update. `_editing_item` guard prevents concurrent edits; save failure preserves the editor and blocks date/month/search navigation, list replacement, data changes and normal quit.
- **일정 편집 색(v4.9 B안 · 앞 색 원)**: 편집 중에는 줄 앞 16px 색 점(`schedule_color_dot`) 자리에 입력줄과 같은 22px 색 원(`SmoothCircleButton`, `ui_schedule_emoji.py`)을 둔다. 누를 때마다 3슬롯 순서(1→2→3→1, `next_schedule_color`, 입력줄과 공용)로 다음 색이 되고 설정의 표시색으로 보인다. 팔레트 밖 색은 그 색 그대로 보이고 누르면 1번 슬롯부터 순환한다. 일반·반복 전체·이 날만 수정이 모두 같은 원을 쓰고 반복 일정의 색 원 3개 줄은 없다. 원은 편집 영역의 일부다: 원은 Tab 포커스만 받고, 원을 담은 자리 위젯(`color_slot`, 폭 22px·위 여백 2px로 입력칸 줄 가운데)이 클릭 포커스를 받아 입력칸에 넘기므로 눌러도 입력 포커스와 편집이 그대로다(원만 두면 Qt가 부모를 거슬러 일정 목록에 포커스를 줘 편집이 끝났다). 키보드는 입력칸 → 스마일 → 시계 → 색 원 순서이고 원 다음 Tab은 v4.8처럼 편집 영역 밖으로 나가 저장한다(원을 담은 자리는 입력칸으로 넘기는 포커스 프록시라 Qt가 Tab 자리로 세므로 Tab 순서에서 입력칸 바로 앞에 둔다). 원에서 Space는 다음 색, Enter는 저장, Esc는 내용과 색을 함께 취소다. 잠금·트레이 숨김 중에는 바뀌지 않는다. 저장은 색이 실제로 바뀐 때만 3슬롯 원래 값을 `schedules.color`에 쓰고, 편집이 끝나면 원 자리를 걷고 색 점을 되돌린다. 접근 이름은 "일정 색상 하늘 — 누를 때마다 다음 색"처럼 표시색 이름(팔레트 밖은 "사용자 지정 색"), 툴팁은 "누를 때마다 다음 색"이다. [설계](superpowers/specs/2026-11-10-schedule-edit-color-design.md).
- **일정 행 높이**: `QListWidget::item`의 padding은 0으로 두고 행 레이아웃의 여백에 포함하여 `sizeHint()`에 반영한다. 인라인 편집기는 `show()`한 뒤 행 높이를 다시 계산하여 입력창과 26px 이모지 버튼의 하단을 모두 표시한다. 편집 저장·취소 뒤에는 본문 행 높이로 복귀한다. 편집기 입력칸과 요약 줄은 가로 `QSizePolicy.Ignored`라 남는 폭을 쓰되 줄에 폭을 요구하지 않는다. 요구하면 줄 앞 색 원이나 긴 반복 요약 때문에 편집 줄이 목록(중간·크게 287px)보다 넓어지고, 가로 스크롤바가 보이는 높이를 줄여 요약 줄을 가렸다(v4.9, `test_editor_row_fits_list_width_without_horizontal_scroll`).
- **일정 이모지**: 입력 행은 `[색상 → 이모지 선택 → 본문 → 추가]` 순서다. `ui_schedule_emoji.py`의 공용 선택창은 16개 이모지(4×4)와 `없음`을 제공한다. 선택은 입력창 앞의 알려진 `이모지 + 공백 한 칸`만 추가·교체·제거하고, Enter/추가 또는 인라인 편집 확정 시 기존 본문으로 암호화 저장한다. 본문 중간·미지원·복합 이모지는 변경하지 않는다. 직접 입력한 알려진 선두 표식도 같은 방식으로 편집한다. 별도 중요도·색상 슬롯은 만들지 않는다.
- **이모지 선택 버튼**: 노란 웃는 얼굴 글리프 대신 `QPainter` 테두리 스마일을 사용한다. 입력부 색상 원과 스마일 외경은 공용 `SCHEDULE_CONTROL_DIAMETER=22`로 맞추며 세로 중심도 일치한다. 클릭/포커스 영역과 인라인 행 높이 계약은 기존 26×26px를 유지한다. 인라인 편집에도 같은 스마일을 사용하며 팝업의 실제 이모지·선택/Undo·본문 저장은 바꾸지 않는다.
- **이모지 표시·조작**: compact는 하단 일정 목록에, medium/large는 일정 목록과 날짜 칩에 표시하며 검색 결과와 전체 본문 툴팁에도 포함한다. compact 날짜 칸 3행과 기존 칩 크기·말줄임은 유지한다. 선택 버튼과 팝업은 키보드로 접근할 수 있고, 팝업의 방향키/Tab으로 이동·Enter/Space로 선택한다. 팝업에서 Escape는 팝업만 취소하고 입력으로 복귀하며, 편집 입력의 Escape는 수정 전체를 취소한다. 선두 치환은 Undo 한 번으로 되돌릴 수 있다.
- **이모지 팝업 수명·폰트**: 팝업은 한 개만 열고 호출 버튼의 화면 작업 영역 안에 배치한다. 닫힌 팝업은 `deleteLater()`하고 선택 콜백을 무효화한다. 잠금·트레이 숨김·초기화 때 팝업과 예약된 포커스 복원을 취소하여 뒤늦은 저장·재표시를 막는다. 선택창은 시스템 `Segoe UI Emoji`, 일정 본문은 기존 앱 글꼴과 Qt 폴백을 사용한다. 외부 폰트·이미지는 추가하지 않는다. 방향키는 실제 포커스 버튼의 이벤트를 받아 격자 안에서 좌우 한 칸·상하 한 행으로 이동한다.
- **컬러 이모지 렌더링**: Qt 6.10.2의 Windows DirectWrite 글리프 캐시에는 비트맵 우측·하단 한 픽셀을 누락하는 문제가 있어 Qt/PySide6 6.11.2를 사용한다. 버튼 높이·padding을 늘려도 이 문제는 해결되지 않는다. `test_emoji_rendering.py`에서 캐시를 거친 화면 렌더와 원본 컬러 비트맵의 경계를 비교한다. 본문 글꼴·Unicode 저장값은 유지한다.
- **Lunar Setting**: Cached as `self._show_lunar` on `MainCalendarWindow`, refreshed once per `_refresh_calendar()` (not per cell). It now gates ONLY the bottom-panel lunar-date text (`lunar_info_label`). Holiday highlighting (red day number) and the bottom-panel holiday name (`holiday_info_label`) are always shown regardless of this setting (holiday = rest day). Holiday lookup uses `holidays.is_holiday()` / `holidays.get_holiday()`.

- **인사말**: 공휴일 첫날~마지막 날(예고 기간 제외)에만 전체 문구로 보이고 말줄임·툴팁이 없다. 날짜 줄에 들어가면 개수 라벨 앞, 아니면 숨기지 않고 바로 아래 오른쪽 정렬 둘째 줄(높이 15px+간격 8px)에 둔다. 자리 판단은 인사말 위치와 무관한 폭으로 한다(기본 크기는 실제 패널 폭 356px, 중간·크게는 패널 최소 폭 300px에서 안쪽 여백을 뺀 276px). 그래서 인사말이 일정 패널 폭을 바꾸지 않고 같은 날짜·내용·테마의 결과가 조작 순서와 무관하다. 날짜·음력·공휴일명·개수 라벨은 인사말 때문에 줄지 않는다.
- **장식 레이어(`ui_holiday_decor.DecorationLayer`)**: 부모를 덮는 마우스 투과(`WA_TransparentForMouseEvents`) 위젯이고 부모의 가장 아래 층(`lower()`)이라 글자·버튼 아래에 그려진다. SVG(`resources/holiday_themes/<키>/`)는 한 번 QPixmap으로 만들어 캐시하며(`app_paths.resource_root()`, 바탕은 레이어마다 한 장·조각은 48장 상한으로 오래 안 쓴 것부터 버려 크기를 끌어 바꾸는 스티키에서도 늘지 않는다), 글자 장식('한' 도장·'한글'·'헌법' 스티커)은 SVG `<text>`가 아니라 QPainter가 맑은 고딕으로 그린다. 표면 사각형으로 잘라 부모의 둥근 모서리(사이드바 왼쪽·확대 오른쪽 0, 아니면 12px)를 따른다. 테마를 여러 번 입혀도 레이어는 하나다.
- **기준점·세로·빈 곳**: 장식 위치는 고정 px이 아니라 실제 위젯에서 읽은 기준점(머리줄: left_gap=`+` 버튼 오른쪽 끝, center=연월 라벨 가운데, right_gap=다음 달 버튼 오른쪽 끝, right=머리줄 오른쪽 끝. 스티키 띠: 링크 버튼 오른쪽·닫기 버튼 왼쪽 사이)으로 정한다. 머리줄 장식은 위쪽 막대 행(맨 위 여백 12+버튼 32+간격 8=52px)에만 놓고 70px 시안을 `map_band_y`로 그 행에 맞춘다(검색 줄은 켜도 꺼도 장식이 없다). **버튼·제목·숫자를 가리지 않는 것이 장식 완성도보다 우선**이다. 버튼·연월 글자 자리를 장애물로 넘겨 겹치는 조각은 빈 곳에 맞춰 줄이거나(0.5배 이상) 옮기고 안 되면 그리지 않는다(`fit_clear`). 기본 380px 머리줄은 버튼 묶음 사이에 빈 곳이 거의 없어(왼쪽 12px, 오른쪽 0px) 시안 배치가 들어가지 않으므로, 테마마다 따로 정한 **작은 배치**(`holiday_decor.HEADER_COMPACT`, 380×52 실제 px, 기준점 `full`)를 쓴다(2026-11-03 사용자 결정 '기본 크기에서도 장식이 보이게'). `_sync_header_decor`가 크기가 `compact`일 때 `DecorationLayer.set_compact(True)`를 부른다. 조각은 버튼 위 띠(y 14 미만)·연월 글자 위(y 15.5 이하)·버튼 사이 틈(`+`~이전 달 x 102~118, 글자 양옆 138~151·229~242, 오른쪽 끝 366~380 등)·글자 아래에만 놓아 13개 모두 빠지거나 줄어드는 조각이 없다: 해·보름달(글자 뒤에서 떠오름)·국화·책·풍선·손 태극기 3개는 연월 글자 위, 바람개비·커피잔·태극기·무궁화는 버튼 사이 틈, 조기·바람개비·`한` 도장은 오른쪽 끝, 연등 9개는 줄에 매달려 버튼에 닿지 않는 높이, 억새는 글자 아래, 자모는 세로 틈에서 떠오른다. 바탕(색동·박음질·줄·원고지·가랜드·능선)은 머리줄과 같다. 중간·크게에서도 시안 자리가 실제 버튼 위라 빠지던 어린이날 풍선 2개·부처님오신날 연등 3개는 빈 곳 기준점으로 옮기고(연등은 왼쪽 4·오른쪽 5개, 시안 간격 42px), 글자 아래에 11px 호만 남던 추석 보름달은 오른쪽 빈 곳 가운데 억새 위에 지름 30px로 띄웠다. 삼일절 손 태극기·개천절 민무늬 구름·추석 억새는 빈 곳의 실제 가운데 기준점(`span_l` = `+` 오른쪽 끝~이전 달 버튼 왼쪽 끝, `span_r` = 다음 달 버튼 오른쪽 끝~오른쪽 버튼 묶음 왼쪽 끝, 위젯 위치에서 읽음)에 놓아 중간(빈 곳 약 208·200px)·크게(약 576·564px)에서는 손 태극기 6개(두 빈 곳에 3개씩, 번갈아 흔들림)·민무늬 구름 2개·억새 2개가 모두 그려진다. 손 태극기는 `Sprite.min_scale = 1`이라 좁은 틈에 줄여 끼우지 않고 그 자리에서 뺀다. 눈 개수는 폭에 비례해 3배까지 늘린다. 모든 크기·13키에서 어떤 조각도 장애물과 겹치지 않고, 기본 크기는 작은 배치의 모든 조각이, 중간·크게는 시안 배치의 모든 조각이 그려짐을 테스트가 고정한다.
- **움직임·정지**: 공용 프레임 시계 하나(`FRAME_MS=42`, 약 23.8fps)가 움직이는 레이어에만 `update_frame()`을 시키며, 가입 조건은 움직이는 조각이 있음·보임·멈춤 아님·최소화 아님·`motion_allowed()`(Windows `SPI_GETCLIENTAREAANIMATION`, 약 4초마다 다시 읽음)다. 가입자가 없으면 타이머가 선다. 숨김(`hideEvent`·트레이)·PIN 잠금(`_lock`→`set_paused(True)`, `_unlock`은 위젯을 다시 보이기 전에 `False`)·테마 해제·설정 스위치 끔에서 멈추고 숨김·잠금 구간은 시간에서 빼 다시 보일 때 이어 간다(새 테마는 처음부터). 잠금 중 새로 열린 창은 멈춘 채 입는다. 현충일은 움직임이 없어 타이머가 없다. **Windows 애니메이션 끔에서는 `once` 조각(떠오르는 해·달)만 끝 위치(떠오른 모습)에 두고** 나머지는 멈춘 시각의 장면으로 선다: 처음부터 꺼져 있으면 첫 장면(t=0)이고, 움직이는 도중에 끄면 그 순간의 자세로 선다(시간이 거기서 서기 때문이다). 첫 장면에 세우면 해·달이 능선에 반쯤 가린 채 멈추기 때문이다. 멈춘 그림도 `motion_state`를 거쳐 후광의 은은한 투명도를 지킨다. 프레임은 실제로 그리는 띠 높이까지만 다시 그린다.
- **스티커·모자**: 스티커는 56px 그림을 -6° 기울인 한 장의 QPixmap(레이블 62px, 사방 3px 여유)이고 떠 있는 스티키 본문 오른쪽 아래에 놓이며 마우스를 통과시켜 크기 손잡이·본문 클릭을 막지 않는다(최소 크기 220×126에서는 마지막 줄과 겹쳐 보일 수 있음). 토마토 모자는 `hat_pixmap`이 토마토 상자 위로 나가는 모자를 한 장에 합성해(접힌 38px·펼친 50px, 장치 배율 1.0/1.25/1.5에서 가장자리 잘림 없음) 레이블 둘이 클릭을 통과시키며, 어린이날 프로펠러만 `hat` 레이어가 따로 돈다(움직이지 않아도 첫 프레임은 그려 늘 보인다).
- **설정창 행**: 화면 표시 패널 마지막에 `공휴일 테마` 스위치 행(툴팁 "공휴일 3일 전부터 캘린더와 위젯에 그날 분위기를 입힙니다.")을 두고(v4.9부터 같은 행 오른쪽 절반에 '칸 구분선' 스위치, 아래 Settings UI 참고), 800×560·무스크롤을 지키려고 왼쪽 열(화면 표시·위젯·도구) 9개 행을 `_add_row(row_height=36)`으로 줄였다(`화면 위치`는 기존 최소 높이 60, 오른쪽 열도 2026-11-04 인터넷 접속 줄을 넣으며 36px로 맞췄다). 실측 왼쪽 열 자연 높이 478px, 레이아웃 최소 높이 549px, 하단 바 위 9px 여유다. 행을 더 넣으면 과거 버튼 겹침 회귀가 되살아나므로 `minimumSize` 실측이 필수다. 스위치는 키 하나만 저장하고 InfoBar를 띄우지 않으며 콜백은 `SettingsWindow.on_holiday_theme_changed`다.
- **검증·미확인**: 자동 검사는 `tests/test_holiday_theme.py`(판정)·`test_holiday_decor.py`(순수 장식 정의·SVG)·`test_ui_holiday_*.py`(캘린더·위젯·집중·장식 레이어)·`test_ui_settings_holiday_theme.py`다. 태극기는 위키미디어 작도와 위키백과로 교차 확인했고 국기법 시행령 별표 원문 대조, 실제 125%·150% 배율, 혼합 DPI 모자 선명도, 한글 IME, Win+D, 실제 EXE는 [작업 기록](work/2026-11-01-v4.6-holiday-theme.md)의 수동 확인 대기 목록에 있다.

## Settings UI

- **공휴일 테마 행(v4.6)**: 화면 표시 패널 마지막 행과 왼쪽 열 행 36px 규칙은 위 '공휴일 테마 (v4.6)' 절을 따른다.

'칸 구분선' 글자는 `inlineRowLabel`이라 행 라벨(`rowLabel`) 목록에 들지 않는다. 툴팁 "캘린더 날짜 칸 사이에 가는 선을 긋습니다.", 키 하나만 쓰고 콜백은 `SettingsWindow.on_grid_lines_changed`다. 행 높이 36px·800×560 무스크롤은 그대로다.
- **투명도 행(v4.9 두 갈래 B안)**: '전체 투명도'를 '투명도' 한 줄로 바꿨다. 라벨 52px, `캘린더 [56px 슬라이더] 80%` · `스티키 [슬라이더] 100%`(이름 12px, 이름-슬라이더 4px, 묶음 사이 10px, 행 안 278px). '스티키' 글자·슬라이더 툴팁은 "스티키·D-Day·집중 위젯"이다. 슬라이더는 움직이는 즉시 저장·적용한다. 캘린더 슬라이더는 `db.save_calendar_opacity`로 저장해, 위젯 키가 없으면 바꾸기 전 값을 위젯 키로 먼저 남긴다(위젯이 덩달아 바뀌지 않는다). 값 칸(`OpacityValueField`, 38px, 값은 슬라이더 쪽으로 붙임, 툴팁 "두 번 눌러 직접 입력", 글자 입력 커서)은 두 번 누르기·Enter·F2로 숫자 입력칸(숫자 3자리, 끝 `%` 고정, 11px)이 되고 글자가 모두 선택된다. Enter·포커스 이동은 확정(30 미만 30, 100 초과 100, 비었으면 이전 값), Esc는 취소다. 56px 슬라이더는 손잡이 22px을 빼면 실제 이동 34px라 값 직접 입력이 보완한다. [설계](superpowers/specs/2026-11-10-opacity-split-design.md).
- **라이선스 열람(v3.9a 고지 정비)**: 설정 본체 800×560과 기존 버튼 위치를 유지하고 `ui_licenses.LicenseDialog`를 부모 소유의 별도 모달로 연다. 기본 780×560, 작업 영역에 맞춰 줄이며 구성요소 선택·읽기 전용 원문 스크롤·전체 복사·닫기를 제공한다. `licenses/components.json`과 존재하는 선택형 앱의 `screen_text/licenses/components.json`이 목록 정본이다. `app_paths.resource_root()` 아래 원문만 읽고 URL은 텍스트로 제공한다(브라우저/네트워크 호출 없음). 부모 숨김·비활성·닫기, PIN 잠금 때 종료하며 DB·설정·선택 이력을 저장하지 않는다. 원문 누락은 읽기 오류로 표시한다.

- **최초 크기 선택(데스크 뷰, 2026-10-05)**: 신규 설치에만 캘린더 전에 `FirstRunSizeDialog`를 표시한다. 기본 680×500 논리 px. 왼쪽 240px에 제목·안내 2줄·라디오 행 3개(이름+짧은 설명), 오른쪽에 모니터 미리보기를 둔다. 미리보기는 1920×1080 화면(작업 표시줄 48px)에 `ui_main`의 기본 크기 규칙(새 설치 기본인 바로가기 켜짐 460×660 — 왼쪽 바로가기 열도 그림, 중간 60%, 크게 −40px)과 오른쪽 아래 20px 위치를 스냅 전 좌표로 적용한 QPainter 벡터 그림(`preview_window_rect()`)이며, 선택하면 창이 240ms 동안 이동한다. 선택 설명 문구는 두지 않는다. 초기 선택은 기본이고 선택 표시는 메모리 상태에만 연동한다. ‘이 크기로 시작’(기본 버튼, Enter)으로 확정하고 X/Esc/종료는 DB 생성 없이 종료한다. 기존 사용자 업데이트·앱 내 Factory Reset에는 표시하지 않는다. 창 크기는 min(680, 작업 영역 폭−24)×min(500, 높이−24)다. 높이 470 미만은 여백·글자를 압축하고, 넓은 배치에서는 두 번째 안내를 하단 버튼 왼쪽으로 옮긴다. 폭 580 미만 또는 높이 370 미만은 한 열 배치(위 기본/중간/크게 버튼, 아래 미리보기)를 쓴다. 미리보기 모니터는 남는 공간에 맞춰 최대 1배로 축소한다. 시스템 테마와 무관하게 항상 밝게 그린다. 제목·크기 이름·시작 버튼은 번들 Pretendard(미로드 시 맑은 고딕), 본문은 맑은 고딕이다. Tab/방향키/Space/Enter/Esc와 화면 변경 시 작업 영역 재배치를 지원한다. DB 접근·실제 메인 창 재사용·이미지 자산은 없다. 저장 오류는 기존 초기화 오류로 시작을 중단한다.

- Organized as a no-scroll (800x560) layout of five **section panels** in two columns: 화면 표시, 위젯·도구 (left); 데이터, 보안, 시스템 (right). No large in-window "설정" title. Each panel is a `CardWidget` with a `StrongBodyLabel` header (objectName `panelHeader`) on a light `#F6F6F6` strip (`panelHeaderBar`) built by `_make_panel`; header color/weight are fixed via `setTextColor(#1A1A1E)` + `setFont(Bold)` (not QSS) so theme re-application can't wash them out. The panel body does not darken on hover. Each setting is a `_add_row(body, label, control)` row with label-left / control-right on a unified right rail; the 화면 위치 row (`_position_row`) is min-height 60. Footer credit (`author_label`) is single-line (`wordWrap(False)`). Monitor combo width 210.
- **Calendar size** uses `CalendarSizePicker` (not a combo): three same-size monitor illustrations whose blue app block area grows for `compact`/`medium`/`large` (anchored bottom-right, the app's default corner). Pure `QFrame` + QSS, no external image assets; selection highlight via a `selected` style property. Emits `scaleChanged(str)` → `_on_scale_changed(scale)` → saves `SETTING_CALENDAR_SCALE`.
- **Schedule colors** use `ScheduleColorPicker`: three compact swatches map to the three canonical storage slots. Each opens a 10-color `RoundMenu`; colors already used by another slot are disabled. Saving changes only `app_settings`, then immediately repaints the app.
- 화면 잠금 PIN은 `_validate_pin`, 이동 파일 암호는 `_validate_transfer_password`로 구분한다. v4.3 내보내기·가져오기 입력칸은 110px 왼쪽 정렬·최대 128자로, 각각 `암호 12자 이상`/`암호 / 이전 PIN`을 안내한다. 새 파일은 12자 이상, 이전 파일 가져오기는 4자리 숫자 PIN도 허용한다. '저장 경로' 행은 폴더 버튼을 유지하고 그 왼쪽에 실제 저장 폴더를 190px 한 줄로 보인다(넘치면 드라이브와 마지막 폴더 이름을 남기고 가운데를 `…`로 줄임, 툴팁 전체 경로).
- **데이터 초기화(Factory Reset)** uses no PIN (usability decision): soft-danger red button (`factoryResetButton`) → confirm `MessageBox` only. 앱 종료 (`quitAppButton`, dark) first checks `prepare_for_quit()` through its callback. Only a successful save allows closing Settings and calling `QApplication.quit()`.

- **데이터 작업 전 저장**: 가져오기·초기화는 현재 플로팅/large 패널 원본을 저장한 뒤 보호백업을 만든다. 저장 실패 시 해당 작업을 보류한다. 가져오기 뒤 기존 ID의 편집창은 재사용하고, large 패널 목록은 최신 편집을 보존하며 갱신한다.
- **초기화 객체 정리**: 보호백업 성공 후 기존 플로팅 창과 숨긴 미니 패널의 타이머를 모두 정지·폐기한 다음 DB를 초기화한다. 초기화 전 메모의 지연 저장이 같은 ID의 새 메모에 적용되면 안 된다.

- `StickyNoteWindow.save()` is the public entry point for external saves. Internal: `_auto_save_content()`.
- 4 background colors (노랑/민트/보라/하늘).
- Color button styled as rounded rectangle matching B/S/A format buttons.
- `_ColorGridPopup._on_pick()` calls `deleteLater()` on close to prevent memory accumulation.
- Todo markers (`\uf0c8`/`\uf14a`, plus legacy `☐`/`☑`) stay unchanged in plain text and HTML. A `QSyntaxHighlighter` masks only their rendered glyph and `_TodoTextEdit.paintEvent()` draws a 15px rounded checkbox with a roughly 22px hit target, hover accent, and checked tick. Body text clicks must not be captured by the expanded target.

## D-Day Widgets

- Floating 220x95 countdown windows. Created via "+" dropdown menu. Double-click to edit name/date.

- **D-Day 만들기·집중 모드 추가 창(2026-10-10 디자인 점검 17번)**: 창 안에 굵은 16px 제목(`D-Day 만들기`/`D-Day 편집`, `집중 모드 추가`)을 두고 버튼 위 여백을 넓혔다(340×316, 430×270). D-Day 날짜는 연·월·일 직접 입력을 유지하고 옆 달력 버튼이 `QCalendarWidget` 팝업(한국어, 일요일 시작, 일요일 빨강·토요일 파랑, 선택 `#2563EB`)으로 세 칸을 채운다. qfluentwidgets 달력은 요일이 영어이고 월요일 시작이라 쓰지 않는다. 날짜 아래 미리보기는 `D-13 · 10월 22일(목)`, 오늘은 `D-Day`, 지난 날은 `D+N`, 잘못된 날짜는 `날짜를 확인하세요`다.

- In `large` mode the floating windows are hidden and mirrored in `DDaySidePanel` (`ui_dday_panel.py`) as a **3-column grid** of mini cards (no scroll; up to 5 = 2 rows). Each card has an X (`delete_requested(int)`) → main `_on_panel_dday_delete` confirms, deletes from DB, cleans the hidden floating window, refreshes the panel.

## Focus Mode Widgets

- Floating quiet focus timer widgets. Created via "+" dropdown menu → "집중 모드".
- `FocusTimer` owns session timing/progress logic; `FocusWidgetWindow` owns UI state and persistence.
- UI states: Ambient (goal + percent + thin progress ring + right-side `tomato_mini.png`, no remaining time), Glance on hover (same width, taller only: hide mini tomato, show mode, `MM:SS` remaining time, next break, and larger `tomato.png`). Clicking the larger tomato shows a random encouragement speech bubble below it for 3 seconds. No double-click edit/control panel; users configure once in the create dialog and recreate the widget if they want a different goal or mode.
- Modes display without shorthand ratios: 짧은 집중 (`25분 집중/5분 휴식, 포모도로`), 깊은 집중 (`50분 집중/10분 휴식`), 몰입 블록 (`75분 집중/15분 휴식`).
- Manual session end opens `FocusReviewDialog` for focus rating 1-5 and distraction category. Automatic focus completion stores a completed session, shifts the widget to a subtle completion color, then asks "집중 모드 완료, N분 휴식하시겠습니까?" with buttons. Accepting starts break mode with no sound.
- Visual style: white-to-blue gradient (`#FFFFFF` → `#EEF6FF` → `#DDE8FF`) with `#FF5A45` focus accent and transparent tomato assets.
- **목표 문구 말줄임**: 플로팅 위젯과 large 미니 카드의 목표는 `ui_focus.FocusGoalLabel`(가로 `QSizePolicy.Ignored`)로 레이아웃이 준 폭만 쓰고 넘치면 끝을 `…`로 줄인다(말줄임 앞 빈칸은 뗀다). 줄였을 때만 전체 목표를 툴팁으로 보여 준다. 일반 QLabel은 글자 전체 폭을 최소 폭으로 잡아, 241px 고정 위젯에서는 토마토 앞에서 글자가 그냥 잘리고 large 오른쪽 열에서는 긴 목표가 열을 300→471px로 밀어냈다(2026-10-10 디자인 점검 3번). 저장된 목표(최대 60자)는 바꾸지 않는다.
- In `large` mode the floating focus window is hidden and mirrored in `FocusMiniCard`/`FocusSidePanel` (`ui_focus_panel.py`). The mini card has an X (`close_requested`) → main `_on_panel_focus_close` confirms, then reuses `FocusWidgetWindow._on_close()` (stops timer, deletes from DB, pops registry) and clears the panel.

## Known Issues & Notes

- **Privacy Lock 표시 계약**: 잠금 중에는 트레이 복원이나 예약된 창 표시로 플로팅 스티키/D-Day/집중 창을 노출하지 않는다. 열려 있던 설정·검색·휴지통은 비활성화하고 숨기며, 잠금 중 재진입은 차단한다. 활성 확인/파일 대화상자와 팝업은 취소한다. 잠금 해제 후 위젯은 현재 패널/트레이 상태에 맞춰 복원하고, 보조 창은 사용자가 다시 연다. 집중 자동 완료가 잠금 중 발생하면 완료 기록은 저장하되 휴식 팝업은 생략한다. 잠금 화면(`LockOverlay`)은 `WA_StyledBackground`로 불투명 `#1e1e2e` 배경을 실제로 칠해 머리줄·사이드바·달력·일정을 모두 덮는다(속성이 없으면 QSS 배경이 그려지지 않아 내용이 비친다).

## 일정 시각·알림·반복·기간 (v4.1)

- **시계 보정 후 알림(v4.5)**: 저장/메모리의 처리 시각이 현재보다 미래이면 현재부터 알림을 재개한다. 이미 지난 구간을 보정 순간에 몰아서 알리지 않으며, 같은 실행에서 이미 표시한 회차는 중복하지 않는다. 표시 키는 메모리 전용이라 앱을 재시작하면 앞선 시계에서 표시한 알림이 다시 나올 수 있다. 보정만으로 설정을 쓰지 않고, 알림 표시 또는 알림이 있는 정상 종료 때 보정한 마지막 확인 시각을 저장한다. 최근 12시간 놓친 알림·5분 뒤 다시·잠금/트레이 표시 계약은 유지한다.
- **입력줄**: `[색 원][스마일][시계][입력칸][추가]`. 시계 버튼은 26px 클릭 영역에 22px 원을 그리고, 값이 있으면 파랑(`#2563EB`)과 오른쪽 위 6px 점을 그린다. 아래 알약 줄은 입력칸 왼쪽에 맞추고 값이 있을 때만 보인다(없으면 지금 배치와 같다). 알약은 22px·최대 150px 말줄임이며 누르면 카드, ×는 그 항목만(시각 ×는 알림도) 지운다. 추가에 성공했을 때만 비운다. 보류 값의 기간은 길이로 기억해 날짜를 바꿔도 따라가고, 새 날짜보다 앞선 반복 끝은 '계속'으로 돌린다.
- **세부 카드(v4.2 리디자인)**: 폭 320px 흰 카드(`#CCDBEB` 테두리·radius 12px·그림자 여백 16px)의 `Qt.Popup`. Azure 600 `#335C8A` 머리띠(위 모서리 radius 11px)에 제목·모두 지우기·완료를 모으고 아래 안내/완료 줄은 두지 않는다. 본문 여백 위 12·좌우 14·아래 14px, 줄 간격 12px. 18×18 라벨에 기존 선 아이콘을 16px로 그리고 10px 간격 뒤에 선택 바를 둔다. 아이콘·바에 시각/알림/기간/반복 접근성 이름과 툴팁을 주며 값이 있으면 600, 없으면 `#64748B`, 막힌 반복은 `#B8C2CF`다. 설명·달력·반복 끝 줄은 28px 들여쓴다.
- **카드 선택 바·색**: 바 배경 Azure 50 `#F4F7FB`·테두리 100 `#E8EEF6`·radius 8px, 안쪽 여백/간격 2px. 칸 높이 24px·12px 글꼴·radius 6px, 선택은 600 채움+흰 굵은 글자, 비선택 `#475569`·hover 100, 비활성 `#B8C2CF`. 알림(시각)/반복은 같은 폭으로 한 줄을 채우고 종일 알림은 글자 폭에 비례한다. 시각·기간·끝 바는 글자에 맞추고 좌우 여백 12/14/9px. 끝 칸은 높이 22px·11px 글꼴이다. 진한 값 글자는 700 `#2D4F77`, 안내 `#64748B`, 막힘/끝 라벨 `#94A3B8`. 본문 포커스는 파랑 2px, 머리띠 포커스는 노랑 `#FBBF24` 2px이며 QSS는 카드/객체 이름에 한정한다. 시계 버튼·알약의 `ACTIVE_COLOR=#2563EB`는 유지한다.
- **카드 값·설명**: 시각은 하루 종일/시각+60×28px 입력칸(Enter·다른 곳 누르기·닫기 때 반영, 틀리면 빨간 테두리 뒤 마지막 값). 알림 칸은 시각 일정에서 없음·정시·10분·30분·1시간·1일, 종일에서 없음·당일 9시·전날 9시이며 긴 뜻을 접근성 이름/툴팁에 둔다. 시각+알림일 때만 `alarm_caption`으로 보고 있는 날짜 기준 '10분 전, 14:50에 알림'을 표시하고 다른 날이면 날짜도 붙인다. 기간은 하루/여러 날 + 작은 달력(365일 상한 유지), `period_short_caption`으로 '~ 17일(토) · 3일'을 표시한다(일수는 회색). 접혔을 때만 ▾를 붙이고 글자 폭이 넘치면 들여쓴 다음 줄로 내린다. 반복 중에는 '반복 중엔 하루만', 여러 날이면 '여러 날 일정은 반복할 수 없어요'로 안내한다. 반복은 안 함·매일·평일·매주·매월·매년 한 줄, 그 아래 설명(말줄임·전문 툴팁)+끝 계속/날짜까지를 한 줄로 둔다. 반복 끄기 경고는 기존 문구와 주황 `#B45309`를 유지한다.
- **카드 작은 달력·수명**: 달력 상자는 Azure 50 배경·100 테두리·radius 8px·여백 8/8/6px, 월 이동 버튼 22×22px. 7열은 가로 간격 0·칸 폭을 채우며 기간 첫날 `start`(100·왼쪽 둥근 끝), 사이 `in`(100·각진 끝), 끝날 `end`(600·오른쪽 둥근 끝), 반복 끝 `single`(600·양쪽 둥근 끝)로 이어진 띠를 그린다. 시작일은 선택 불가여도 띠를 표시하고 다른 비활성 날짜·요일·공휴일 색은 유지한다. 선택 즉시 반영, Esc/바깥/완료 닫기, 여러 날/반복 배타, 팝업 안 팝업 금지, `clicked(bool)`의 인자 없는 slot 호출을 유지한다. 달력 펼침/5↔6주 이동 때 `size_changed`로 다시 배치한다. 잠금·트레이 숨김·초기화 전 폐기·크기 전환·미니앱 열기·종료 때 닫고 늦은 변경은 버린다. DB v18·Export v3·설정·salt·저장값은 변경하지 않는다. [설계](superpowers/specs/2026-10-18-schedule-options-card-redesign-design.md)·[검증 기록](work/2026-10-18-schedule-options-card-redesign.md).
- **목록 줄**: `[색 점][시각 열][본문+반복·종 아이콘][기간 글자][휴지통]`. 시각 열(40px)은 그날 시각이 보이는 일정이 있을 때만 생긴다. 정렬은 시각 없이 보이는 것(하루 종일·기간 둘째 날 이후) 먼저 ID 순, 그다음 시각·ID 순이다. 본문은 PlainText이고 그릴 때만 말줄임한다(`text()`는 전체). 툴팁은 본문 + 세부 설명 줄. 추가 직후 새 줄은 1.2초 동안 `#EFF6FF`.
- **편집**: `[스마일][시계][본문]` + 요약 줄(반복이면 `… · 모든 날에 적용`). 반복 일정은 시리즈 전체를 고치고, 다른 날에서 반복을 끄면 첫 날짜만 남는다고 카드에 안내한다. 세부 설정을 바꿔 저장하면 편집 종료 뒤 목록을 다시 만들고, 다른 줄을 편집 중이면 그 편집이 끝날 때까지 미룬다. 형식이 다른 옛 날짜 일정은 시계 버튼을 끄고 본문만 고친다.
- **반복 지우기**: 휴지통·우클릭에 `이 날만 삭제`(달력 아이콘)/`반복 전체 삭제`(빨간 반복 아이콘). 반복이 아닌 일정은 여러 날 기간이어도 지금처럼 바로 지우고(묻지 않음) 우클릭은 `편집/삭제`다. 끝 날짜가 있는 반복에서 `이 날만 삭제`로 마지막 남은 날을 지우면 일정 행 자체가 삭제되고, 끝 날짜가 없는 반복은 행이 그대로 남는다.
- **달력**: 기본 크기는 칸 구조를 그대로 두고 나타나는 일정으로 개수·색을 센다. 중간·크게는 시각 칩 `14:00 본문`(굵게 안 함, PlainText)이고, 여러 날 일정은 `CalendarSpanOverlay` 막대다(칩과 같은 선 6px/4px, 주가 이어지는 쪽은 각진 끝, 칸 높이에서 칩 자리-1까지 차선, 나머지는 `+N 더`). 7열 같은 stretch·칩 Ignored 계약은 그대로다(오버레이는 레이아웃 밖).
- **알림 카드**: 카드를 띄운 화면 작업 영역의 오른쪽 아래, 12px 안쪽에 붙으며(내용이 늘어 크기가 바뀌어도 같은 자리에 다시 맞춘다) 320px, 왼쪽 4px 띠, `Tool|Frameless|StaysOnTop`·`WA_ShowWithoutActivating`. 최대 3건 + `외 N건`, `[5분 뒤 다시][확인]`. '놓친 알림'은 시작·절전 복귀 때 확인 창(12시간)에서 2분 넘게 지난 것만이며 확인만 있다. '5분 뒤 다시'로 돌아온 알림은 놓친 알림이 아니라 `[5분 뒤 다시][확인]`이 있는 일반 카드다. PIN 잠금 중에는 내용을 숨기고(건수만 보임) 다시 알림 버튼도 없다. 누르면 캘린더를 보이고 그 날짜로 가며 잠금 중에는 카드만 닫는다. 새 알림마다 `QApplication.beep()` 한 번. 트레이·보스 키로 숨긴 동안에도 알린다.
- **업데이트 안내**: 예전 형식 DB를 이번 실행에서 올렸을 때만 메인 창이 뜬 0.8초 뒤 '기후노트 업데이트 안내'를 한 번 띄운다. 부모 없는 맨 위 모달 `Dialog`(폭 440, [확인]만)이고, 이전 버전에서 뜨는 '데이터 보호를 위해 실행을 중단했습니다' 창의 뜻과 이전 EXE·바로가기 삭제를 안내한다. 아무것도 저장하지 않으며 새 설치·이미 새 형식이면 뜨지 않는다.

## UI 상세 계약

- **앱 글꼴**: 기본 본문 폰트는 Windows 시스템 폰트 `Malgun Gothic`이다. 설정 키는 `SETTING_APP_FONT = "app_font"`이며, 적용은 앱 시작 시 `app_fonts.apply_app_font()` 경유. 설정창에서 변경하면 저장만 하고 재시작 안내를 표시한다.
- **폰트 크기**: QSS의 `font-size`는 정수 `px`만 사용한다. 소수점 픽셀 크기는 Windows Qt 렌더링에서 흐림을 만들 수 있다.
- **설정 위험 버튼**: 데이터 초기화 버튼(글자 `초기화`, 2026-10-10 영문 `Factory Reset`에서 변경)은 `factoryResetButton` + `FIF.DELETE`(소프트 danger: 배경 `#FEF2F2`/테두리 `#F0C2C2`/글자 `#DC2626`, hover 시 `#DC2626` 채움), `앱 종료`는 `quitAppButton` + `FIF.POWER_BUTTON`(다크 `#1F2937`) 사용. 아이콘과 텍스트가 겹치지 않도록 왼쪽 padding과 최소 폭을 유지한다. **테스트 고정값**: factoryReset QSS는 `border-radius: 6px` + `padding: 5px 14px 5px 34px` + minWidth≥152, quit QSS는 `border-radius: 6px` + `padding: 5px 12px 5px 32px` + minWidth≥112를 유지한다(QSS에 `#28a745`/`#dc3545` 금지).
- **설정창 레이아웃(시안 A)**: `ScrollArea` 없이 800x560 고정/최소 크기를 유지하며, 레이아웃 최소 크기가 800×560을 넘지 않아야 한다(긴 저작권 라벨은 `setWordWrap(True)`+`QSizePolicy.Maximum`으로 창 폭을 강제하지 않게 한다). 5개 섹션(화면 표시/위젯·도구/데이터/보안/시스템)을 각각 **테두리 카드**(`_SettingsPanel`: 흰 배경 + 라운드 11px `#D7DAE2` 테두리, hover 배경/테두리 변화 없음, `_make_panel`)로 감싸 2열 배치한다. 헤더는 **밝은 바**(`panelHeaderBar` `#F6F6F6` + 라운드 상단/좌우/하단 경계 `#D7DAE2`) 안에 **블루 섹션 아이콘 + 진한 굵은 `StrongBodyLabel`**(`panelHeader`, `#1A1A1E`)로 두며, **딥 네이비(`#01295F`) 풀 바로 되돌리지 않는다**. 섹션 헤더 텍스트는 반드시 `StrongBodyLabel`(섹션명)이어야 한다(테스트 의존). 모든 컨트롤은 스크롤 없이 보여야 한다. 각 행은 `_add_row`로 `라벨-좌(고정폭) / 컨트롤-우`(우측 정렬 레일) + 행간 1px 구분선(`#F2F3F6`, 섹션 마지막 행은 `divider=False`). 모니터와 화면 위치는 **별도 두 행**으로 분리한다(콤보 / 4모서리 2×2 `posGrid`). 화면 위치는 4모서리(top/bottom × left/right)만 지원하며 `_position_btns`는 항상 4개. 카드 보조 설명은 넣지 않고 라벨은 짧게 쓴다. **캘린더 크기**는 콤보가 아니라 `CalendarSizePicker`(동일 크기 모니터 외곽 + 내부 앱 블록 크기로 `compact`/`medium`/`large` 표현, 선택 시 외곽·테두리·블록·캡션 블루 강조, `QFrame`+QSS, 외부 이미지 없음; `scaleChanged(str)` → `_on_scale_changed(scale)` → `SETTING_CALENDAR_SCALE` 저장)다.
- **전역 블루 액센트**: `main.py`에서 `setThemeColor(QColor("#2563EB"))`로 토글(`SwitchButton`)·슬라이더·포인트색을 단일 블루로 통일한다. 테마 고정 함수에서 함께 적용한다. **글자 선택 색**도 같은 함수가 앱 팔레트의 `Highlight` `#2563EB`/`HighlightedText` 흰색만 지정한 빈 `QPalette`로 고정한다(2026-10-10 디자인 점검 7번). Qt 기본 입력칸(일정 편집, 날짜·시간·금액 입력, 스티키 본문 등)은 이 값이 없으면 Windows 강조색(PC마다 다름, 측정 PC는 청록 `#009faa`)을 선택 바탕으로 쓴다. Fluent `LineEdit`은 자체 QSS로 테마색 계열 파랑을 쓴다. 나머지 팔레트 색은 밝은 시스템 팔레트를 그대로 따른다. 집중모드 `#FF5A45`, 공휴일 `#D32F2F`, 오늘 남색 등 **명시 색상은 테마색과 무관**하므로 영향받지 않는다.
- **미니앱 주머니 (v3.7b 후속)**: 80px 사이드바 최상단에 64×48px 미니앱 버튼(흰 배경·1px `#D9E1EC`·radius 10, 번들 `resources/icons/mini_apps/launcher.svg` 20px + 텍스트, 열림 `#EAF2FE`·`#8DB4F0`·글자 `#1D4ED8`)을 두고, 구분선/바로가기 제목/기존 6개 슬롯을 이어 배치한다. `self.slots`와 DB ID는 1~6 그대로이며 기존 64×64px 버튼·이름·경로·등록/관리/드롭 계약을 유지한다. 기본 660px에서 6개 모두 보이고 짧은 화면에서는 목록만 세로 스크롤한다. compact의 저장된 사이드바 숨김 설정과 medium/large의 표시 규칙을 유지한다.
- **주머니 동작·수명 (v3.8c A안 앱 런처)**: 252×280px 흰 카드(1px `#D9E1EC`, radius 16)와 사방 24px 그림자 여백(전체 300×328px)을 사용한다. 그림자는 blur 20·아래 4·`rgba(24,46,76,80)`이다. 머리부 48px은 색 띠 없이 `미니앱`(15px 굵게 `#172B4D`)과 실행 가능한 앱 개수(`N개`, 11px `#7A8699`), 테두리 없는 28px 닫기를 둔다. 104×100px 타일을 2×2(가로 간격 12, 세로 10, 여백 왼쪽 16·위 6·아래 14·오른쪽 8+스크롤바 6px 자리)로 배치한다. 타일은 평소 투명·2px 투명 테두리, hover `#F2F6FC`, pressed `#E7EEF9`, focus 2px `#2563EB`이고 48px SVG 아이콘과 12px `#253447` 이름(최대 2줄)을 표시한다. 타일(`MiniAppTile`)은 아이콘을 위 8px에 고정하고 이름을 그 6px 아래 위쪽 정렬로 직접 그려, 한 줄 이름과 두 줄 이름의 첫 줄 높이가 같다(2026-10-10 디자인 점검 19번). 순서는 단위 환산기 → 날짜·시간 계산기 → (v3.8c) 금액·숫자 표기 → (v4.4 확장) 파일 변환이다. 준비 중 칸은 `upcoming.svg`와 `#9AA6B5` 글자의 비활성 칸으로 클릭·키보드 실행·Tab 이동을 막는다. 실제 앱이 추가되면 준비 중 자리를 순서대로 대체하고 이후에는 2열/목록 세로 스크롤을 유지한다. 버튼 오른쪽 우선/부족 시 왼쪽으로 보이는 카드와 버튼 사이 12px 간격을 두며 그림자까지 작업 영역 안에 보정한다. 재클릭/바깥 클릭/그림자 여백 클릭/Esc/닫기로 닫으며 원래 버튼에 클릭을 재전달하지 않는다. - **캘린더 셀 구조(2-모드)**: `CalendarDayButton`은 `mode`(`compact`/`expanded`)를 가진다. compact는 `[날짜 숫자 / 색상 심볼(■) / 총 일정 수]` 3행이며 개수 0이면 빈칸이다. expanded는 날짜 숫자와 일정 칩 스택을 표시하며, 셀 높이에 맞춰 칩 개수를 계산하고 넘치면 `+N 더`를 표시한다. medium 칩은 10px/16px/2px(글꼴/높이/간격), large 칩은 13px/22px/3px를 사용하고 실제 적용 폰트 메트릭으로 말줄임한다. 일정 추가·삭제·수정 시 `_refresh_cell_for_date()`로 해당 셀만 즉석 갱신한다.

Win+D는 바탕화면 셸 창을 z-order 앞으로 올리므로 최소화 복원만으로는 막을 수 없다. `ShowDesktopKeeper`는 셸 바탕화면이 foreground가 될 때만 메인+플로팅 창을 `HWND_TOPMOST`로 350ms pulse한다. 단, 그 순간 Win 키(왼쪽·오른쪽)가 눌려 있지 않고 커서 아래 최상위 창이 셸 바탕화면이면 바탕화면 클릭으로 보고 pulse하지 않는다. 바탕화면 클릭은 바탕화면을 올리지 않으며, pulse하면 캘린더가 위를 덮던 탐색기 등 일반 창 위로 350ms 튀어나와 깜빡인다(2026-10-24 실측). 바탕화면 아이콘 클릭은 마우스 버튼을 뗀 뒤에 활성화 알림이 오므로 버튼 눌림을 요구하지 않는다(2026-10-25 실측, v4.4a·v4.4b는 버튼 눌림을 요구해 아이콘 클릭마다 pulse했다). Win+D는 커서가 바탕화면 위여도 늘 Win 키가 눌려 있었고 '바탕화면 보기' 버튼은 커서가 작업 표시줄이다. 키·버튼 없이 바탕화면을 올리는 경로(터치패드 제스처, Win 키를 곧바로 떼는 자동 입력)는 클릭으로 볼 수 있으나, 바탕화면이 감시 창을 덮으면 아래 REORDER 확인이 같은 pulse를 한다. 셸은 Win+D·'바탕화면 보기' 버튼에서 활성화 알림 뒤 7~250ms에 바탕화면을 올리므로 알림 시점에 덮였는지로 판단하면 Win+D 보호가 깨진다. 클릭 판정에 실패하면 pulse를 유지하고, 클릭 경로도 settle 때 같은 데스크톱 레이어로 재고정한다. 바탕화면이 이미 활성일 때(바탕화면을 누른 뒤)의 Win+D는 활성화 알림이 다시 오지 않고 바탕화면만 올라온다(2026-10-25 실측, 다음 Win+D까지 가려짐). 그래서 바탕화면이 활성인 동안 루트 데스크톱 창(`GetDesktopWindow`)의 `EVENT_OBJECT_REORDER`가 오면, 보이는 감시 창이 바탕화면 호스트보다 아래로 내려갔는지 `GW_HWNDPREV`로 확인해 덮였을 때만 같은 pulse를 한다(v4.4b). 다른 앱이 활성이거나 덮이지 않았으면 아무것도 하지 않으며, 이 hook 등록이 실패해도 foreground 기반 보호는 그대로다. 바탕화면 보기를 되돌릴 때 활성화되는 앱이 없으면(바탕화면이 활성이던 Win+D, '바탕화면 보기' 버튼) 셸은 창들을 아직 위에 있는 바탕화면 아래에 되살린 뒤 바탕화면만 맨 아래로 내린다. 그러면 올라온 바탕화면 바로 위에 고정돼 있던 캘린더가 되살아난 창들 위에 남아 다른 창을 누를 때까지 가렸다(2026-10-25 실측). 그래서 pulse 뒤에는 같은 REORDER에서 감시 창과 바탕화면 호스트 사이에 보이는(최소화되지 않은) 다른 창이 처음 생기면 한 번만 같은 데스크톱 레이어로 재고정한다. 한 번으로 제한해 다른 '바탕화면 고정' 앱과 서로 밀어내는 반복을 막고, pulse가 없었으면 감시 창 아래의 창을 이유로 재고정하지 않는다. pulse 종료 후에는 먼저 `HWND_NOTOPMOST`로 내리고, `GetWindow(desktop, GW_HWNDPREV)`로 감시 창을 제외한 데스크톱 앞의 첫 창을 찾아 그 창 뒤·데스크톱 앞에 삽입한다. 결과 순서는 **바탕화면 아이콘 < 기후노트 < 탐색기·브라우저 등 일반 창**이어야 한다. 다른 창이 foreground가 되면 pulse를 취소하고 같은 데스크톱 레이어로 즉시 재고정한다. Win+M은 `WindowStateChange` 복원으로 별도 방어한다. **영구 topmost 및 WorkerW/SetParent 재부모화 금지**. 토글 OFF는 타이머 취소+즉시 demote, 앱 종료/객체 파괴 시 native hook을 반드시 해제한다.
- **모니터 구성 변경 시 크기 재계산**: `medium`/`large`는 화면 크기에 비례하는 스케일이므로, 모니터가 바뀔 때 좌표만 clamp하면 안 된다. `_clamp_calendar_xy()`는 `max(0, 화면폭 - 창폭)`을 쓰기 때문에 창이 화면보다 넓으면 좌측 정렬만 하고 초과분을 처리하지 못한다. `_on_screen_changed()`와 `_finish_calendar_drag()`는 **둘 다** `_calendar_scale_geometry(scale, 목적지화면)`으로 크기를 먼저 다시 구한 뒤 좌표를 정한다. - **집중 모드 UI**: 기본 Ambient는 남은 시간을 숨기고 목표·진행률%·얇은 원형 링·흰 배경이 제거된 투명 `tomato_mini.png`만 표시한다. 기본 배경은 `#FFFFFF` → `#EEF6FF` → `#DDE8FF` 대각선 그라데이션이며 포인트 색은 `#FF5A45`이다. Hover Glance는 같은 폭에서 세로만 늘리고, mini 토마토는 숨기며, 왼쪽에는 모드·남은 시간(`MM:SS`)·다음 휴식(`HH:MM AM/PM`)을, 오른쪽 아래에는 흰 배경이 제거된 투명 `tomato.png`를 `TOMATO_IMAGE_SIZE = 50`으로 표시한다. Hover Glance의 큰 토마토를 클릭하면 22개 응원 문구 중 하나를 랜덤으로 고른 말풍선을 토마토 아래에 3초간 표시하되, 말풍선 창 외곽은 투명해야 한다. 큰 토마토에는 Qt 기본 툴팁을 달지 않는다. 위젯 창 크기는 `AMBIENT_SIZE`/`GLANCE_SIZE`로 고정한다. Hover Glance에 `진행률` 행은 두지 않는다. 더블클릭 편집 패널은 제공하지 않으며, 설정을 바꾸려면 종료 후 새로 만든다.
- **집중 모드 위젯 제한**: 집중 모드 위젯은 1개만 생성/표시한다. `enforce_widget_limits()`가 앱 시작 시 최신(id 큰) 1개만 남기고 초과분은 데이터 보존 상태로 `is_open=0` 정리한다. 정리분이 있으면 모달 경고를 띄운다. 생성 제한 카운트는 `isVisible()`이 아니라 등록 딕셔너리 기준이다.
- **D-Day 위젯 제한**: D-Day 위젯은 최대 5개만 생성/표시한다. `enforce_widget_limits()`가 앱 시작 시 최신(id 큰) 5개만 남기고 초과분은 삭제 없이 `is_open=0` 정리한다. 생성 제한 카운트는 `isVisible()`이 아니라 등록 딕셔너리 기준이다.
- **크게 모드 오른쪽 열 글자(2026-10-10 디자인 점검 16번)**: D-Day 미니 카드 이름은 11px(최소 11px), 추가 칸은 한 줄 `+ D-Day 추가`(제한 칸 `최대 5개 · 삭제 후 추가`) 11px다. 스티키 서식 도구의 첫 버튼(배경 색상)은 색 견본 위에 팔레트 아이콘(`FIF.PALETTE` 13px)을 그려 빈 네모로 보이지 않게 한다.
- **D-Day Cover Tint(디자인)**: D-Day 플로팅 위젯(`ui_dday.py`)과 large 미니 카드(`ui_dday_panel.py`)는 **진한 커버색 단색 배경 + 전부 흰 타이포**다. 팔레트 `DDAY_COVER_COLORS`(sky `#46679C` 기본 / yellow `#A8801F` / mint `#2E8F6E` / pink `#B25C8B`)는 **스티키 전용 `STICKY_COLORS`/`STICKY_HEADER_COLORS`와 분리**한다(공유 상수 오염 금지). DB에 저장된 구 파스텔 색은 `dday_cover_color()`가 커버색으로 매핑해 렌더한다(저장값 변경 없이 표시만 매핑, 데이터 보존). 카운트는 색이 아니라 **표기+명도**로 상태 구분: 미래 `D-N`·당일 `D-Day`는 흰색(`#FFFFFF`), 지남 `D+N`은 `rgba(255,255,255,140)`(공백 없는 표기). 플로팅 위젯은 **소프트 드롭 섀도우 + 옅은 흰 헤어라인(`rgba(255,255,255,HAIRLINE_ALPHA)`)으로 배경에서 분리**(창을 `SHADOW_MARGIN`만큼 키워 그림자 여백 확보, 좌표 규약은 창 좌표 그대로 유지, 불변식 `SHADOW_MARGIN ≥ SHADOW_BLUR + SHADOW_OFFSET_Y`). 미니 카드(`ui_dday_panel.py`)는 흰 패널 위라 대비 문제가 없어 종전대로 **테두리 없음** 유지. radius 18(플로팅)/12(미니), 좌하단 큰 카운트·우하단 날짜 구도. 카운트/이름/날짜 폰트는 **Pretendard**를 `_dday_font()`로 `QFont` 픽셀 크기·굵기 직접 지정(QSS font-size/weight 미사용, 미로드 시 Malgun 폴백). 닫기 X는 커버 위 가독을 위해 흰색을 직접 그리는 `_CoverIconButton`. large 우측 컬럼의 `ddaySidePanel` **패널 컨테이너**는 스택 이음새 규칙(흰 배경·`border-top:none`·무radius)을 그대로 유지하고 **미니 카드에만** 커버 틴트를 적용한다.
- **집중 모드 세션**: 집중 완료 시 소리 없이 위젯 색만 미세하게 바꾸고 `집중 모드 완료, N분 휴식하시겠습니까?` 버튼 알림을 띄운다. `휴식 시작` 수락 시 break phase로 진입하고, `건너뛰기`면 완료 상태로 남긴다.
- **집중 모드 모드명**: 사용자 표시에는 `25/5` 같은 축약 숫자를 쓰지 않는다. `짧은 집중 (25분 집중/5분 휴식, 포모도로)`, `깊은 집중 (50분 집중/10분 휴식)`, `몰입 블록 (75분 집중/15분 휴식)` 형식을 유지한다.

## 스티키 로컬 파일 링크 (v3.7b, 2026-09-20)

상세 구현·실패 처리·실제 검증 결과와 수동 미확인은 [구현 기록](work/2026-09-20-sticky-file-links.md)에 남긴다.

- 선택 문구에 파일 연결 또는 파일 드롭으로 파일명 링크를 추가한다. 플로팅과 large 미니 패널에서 동일하게 제공하며 일반 클릭/선택/체크박스 편집은 유지하고 Ctrl+클릭 또는 관리 메뉴로 파일을 연다.
- 링크는 승인된 **B+C 파일 라벨**(옅은 배경 `#F6F9FE`·둥근 테두리 `#93B0D1`·파란 문구 `#164D96`·앞쪽 파일 종류 배지 `#205795`)로 표시한다. 체인 아이콘은 툴바에만 둔다. 확장자 영문/숫자 1~5자는 대문자로 표시하며(`PDF`, `HWPX`, `XLSX` 등) 없거나 긴/알 수 없는 표기는 `FILE`로 표시한다. 다른 PC·없는 파일·확인 대기/실패는 문구와 배지를 유지하고 점선 테두리와 옆의 주의 아이콘으로 표시한다. 원인은 툴팁/메뉴로 구별하며 배지/경고 문자·이미지는 본문에 저장하지 않는다. 상태 갱신·그리기만으로 메모 저장이나 Undo 기록을 만들지 않는다.
- 다시 연결 창은 표시 문구·이전 경로와 `취소` / `파일 다시 선택`을 제공한다. 선택한 링크의 연결 정보만 바꾸고 문구·체크박스·다른 링크는 유지한다. 링크 해제도 문구를 지우지 않는다.
- 다른 PC에서 가져온 링크는 같은 경로에 파일이 있어도 재연결 전에는 열지 않는다. 가져오기 직후에는 상태만 표시하고 사용자가 해당 링크를 열 때 재연결을 안내한다.
- 기존 메모를 자동 링크화하거나 서식을 일괄 변환하지 않는다. 잠금·트레이·원본 전환·초기화·객체 폐기 때 링크 대화상자와 지연 콜백을 취소하며 기존 저장 실패 보류 계약을 유지한다.
- 연결 버튼은 주변 굵게/할 일 QPushButton과 같은 QSS(24×22px 내용 상자 + 1px 테두리·반투명 배경·4px 모서리)를 사용하며 `NoFocus`로 선택 문구를 유지한다. 선택이 없으면 파일명을 삽입하며 여러 파일 드롭은 줄 단위 링크를 한 Undo로 추가한다. 여러 줄/체크 표식/기존 링크에 걸친 선택이나 지원 밖 파일이 섞인 드롭은 전체를 보류한다.
- 연결 버튼은 번들 `resources/fluent_icons/link.svg`의 체인 모양을 사용한다(`FIF.LINK`의 새 창 화살표 모양을 사용하지 않음). 드래그한 문구는 버튼 클릭 시 복사한 QTextCursor로 파일 선택 동안 고정하며 파일창에 `연결할 텍스트`와 문구 유지 안내를 표시한다. 파일명은 선택 문구를 대체하지 않는다. 실제 드래그→두 보기의 버튼→파일창 수락/취소 경로로 확인한다.
- `ui_sticky_link_labels.py`의 공용 highlighter가 원본 문서와 별개의 표시 서식으로 링크 첫/마지막 grapheme의 장식 공간을 확보한다. 기존 체크박스 투명 마스크도 같은 highlighter를 사용한다. 배지와 라벨·주의 표시는 QPainter로 그리며 문서 문자열·HTML·복사 내용·원래 서식·Undo를 바꾸지 않는다. 줄바꿈마다 라벨 테두리를 그리고 배지는 첫 줄, 주의 아이콘은 마지막 줄에 표시한다. 배지는 8px 굵은 글자·좌우 3px padding, 높이는 최대 11px이며 작은 줄에서는 상하 2px inset을 확보하도록 축소한다. 정상 링크의 라벨 뒤 간격은 2px이고, 끊김/확인 대기 상태에서만 경고 공간 14px를 추가한다. 상태에 따른 줄바꿈은 허용하되 비동기 결과 처리 시 다음 입력보다 먼저 표시용 QTextLayout 서식과 기하를 갱신한다. 문서 revision·수정 신호·Undo를 바꾸는 rehighlight는 호출하지 않는다. IME 조합 중인 블록은 preedit 서식을 유지하고 공간/아이콘 갱신을 조합 종료까지 보류한다(점선 상태 표시는 유지). 이전 편집기 오른쪽 경고 전용 여백은 사용하지 않는다. 배지 Ctrl+클릭도 해당 링크를 열고 주의 아이콘 클릭은 해당 링크 메뉴를 연다. 관련 검증·합성 캡처는 [간격 개선 기록](work/2026-09-20-sticky-link-spacing-fix.md)을 따른다.
- 일반 클릭은 편집, Ctrl+클릭은 파일 열기다. 우클릭과 키보드 메뉴에는 기존 편집 메뉴와 `파일 열기/파일 위치 열기/다시 연결/링크 해제`를 제공한다. 재연결은 해당 연결만 수정하고 링크 끝의 새 일반 입력은 anchor를 상속하지 않는다.
- 파일 선택창은 잠금 때 확실히 취소할 수 있는 Qt 대화상자이며 재연결 시 선택 문구·이전 경로·원인을 표시한다. 로컬 일반 파일만 지원하며 네트워크·실행 파일·스크립트·바로가기·정션/심볼릭 링크/클라우드 자리표시자는 제외한다. 파일 내용은 메모/백업에 첨부하지 않는다.
