### Task 1: Fix schedule double-click re-edit bug

**Files:**
- Modify: `ui_main.py:832-868`

The `_finish_edit` closure inside `_on_edit_schedule` suffers from re-entrancy: `layout.removeWidget(edit)` triggers `focusOutEvent`, which calls `_finish_edit` again before the first call completes. Fix by moving `self._editing_item = None` to the top of `_finish_edit` (before any widget manipulation) so re-entrant calls are immediately rejected by the guard at line 833. Also add `QLineEdit.focusOutEvent(edit, e)` call in the focusOut lambda so Qt internal focus state stays consistent.

- [ ] **Step 1: Apply the fix to `_finish_edit`**

In `ui_main.py`, replace the `_finish_edit` closure and the `focusOutEvent` lambda (lines 832-868):

```python
        def _finish_edit(save: bool):
            if self._editing_item is not item:
                return
            # 재진입 방지: 즉시 편집 상태 해제
            self._editing_item = None
            new_text = edit.text().strip()
            # LineEdit 제거, 라벨 복원
            layout.removeWidget(edit)
            edit.deleteLater()
            text_label.show()

            if save and new_text and new_text != old_text:
                try:
                    db.update_schedule(schedule_id, content=new_text)
                    text_label.setText(new_text)
                    item.setData(Qt.UserRole + 1, new_text)
                except (sqlite3.Error, OSError, ValueError):
                    InfoBar.error(
                        title="수정 오류",
                        content="일정 수정 중 오류가 발생했습니다.",
                        parent=self,
                        position=InfoBarPosition.BOTTOM,
                        duration=3000,
                    )

        edit.returnPressed.connect(lambda: _finish_edit(True))

        # Escape 키 처리
        orig_key = edit.keyPressEvent
        def _key_press(event):
            if event.key() == Qt.Key_Escape:
                _finish_edit(False)
            else:
                orig_key(event)
        edit.keyPressEvent = _key_press

        # 포커스 잃으면 저장 (base class 호출 포함)
        def _focus_out(e):
            _finish_edit(True)
            QLineEdit.focusOutEvent(edit, e)
        edit.focusOutEvent = _focus_out
```

Key changes:
1. `self._editing_item = None` moved BEFORE `layout.removeWidget(edit)` (was after)
2. `focusOutEvent` now calls `QLineEdit.focusOutEvent(edit, e)` for proper Qt cleanup
