# v4.6 공휴일 테마 자동 적용 Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** 공휴일 첫날 3일 전부터 마지막 날까지 캘린더·D-Day·스티키·집중 위젯에 그 공휴일의 색과 장식을 화면에만 입히고, 설정에서 끌 수 있게 한다.

**Architecture:** 날짜 판정과 테마 색표는 Qt·DB 없는 `holiday_theme.py`, 장식 배치와 움직임 계산은 Qt 없는 `holiday_decor.py`에 둔다. Qt 쪽은 `ui_holiday_theme.py`(판정 결과를 알리는 컨트롤러, 모자 그림)와 `ui_holiday_decor.py`(장식 레이어)이며, 메인 창이 컨트롤러 하나를 소유하고 각 위젯에 `set_holiday_theme(theme | None)`으로 전달한다. 테마는 표시 전용이며 DB에는 설정 스위치 키 하나만 쓴다.

**Tech Stack:** Python 3.13, PySide6 6.11.2, PySide6-Fluent-Widgets, QtSvg, pytest + pytest-qt, `tools/verify.py` 하네스

**Spec:** [docs/superpowers/specs/2026-11-01-holiday-theme-design.md](../specs/2026-11-01-holiday-theme-design.md) — 색표·판정 규칙·테스트 벡터·장식 목록의 정본. 장식 모양·좌표의 정본은 [mockup-scene.dc.html](../specs/2026-11-01-holiday-theme/mockup-scene.dc.html)이다. 구현 전에 설계 문서 전체와 `AGENTS.md`를 읽는다.

## Global Constraints

- 테마는 화면 전용이다. 테마 적용·해제·전환 경로에서 `database`의 쓰기 함수를 부르지 않는다. 유일한 쓰기는 설정 스위치가 `holiday_theme_enabled`를 `"1"`/`"0"`으로 저장하는 것이다.
- DB v19, Export v4, salt, 암호문, 기존 설정 키, D-Day 저장색, 스티키 색·본문 HTML, 일정 본문·색, 집중 세션 기록을 바꾸지 않는다. DB 버전을 올리지 않는다.
- 날짜는 `holidays.KOREAN_HOLIDAYS`만 쓴다. 음력·공휴일을 계산하지 않는다. 판정 이름은 "포함" 비교다.
- 보이는 기간: `[묶음 첫날 - 3일, 묶음 마지막 날]`. 같은 키의 날짜끼리 7일 이내면 한 묶음. 괄호 없는 `대체공휴일`·`임시공휴일`은 어느 묶음에도 넣지 않는다.
- 겹침: ① 진행 중 ② 첫날이 가까운 쪽 ③ 연휴가 긴 쪽 ④ 테마 키 순서(`newyear, seollal, samil, labor, children, buddha, memorial, constitution, liberation, chuseok, gaecheon, hangul, christmas`).
- 인사말은 묶음 첫날~마지막 날에만 보인다. 3일 전 예고 기간에는 색·장식만.
- 설정창은 800×560 그대로다. 왼쪽 열(화면 표시·위젯·도구)의 40px 행만 36px로 줄인다.
- 앱 코드는 `src/`에 두고 `import holiday_theme`처럼 이름으로 import한다(`src.` 접두 금지). 리소스는 `app_paths.resource_root()`로 찾는다.
- SVG는 QtSvg Tiny 범위만: 도형, 선, 선형 그라데이션, `transform`, `fill-opacity`, `stroke-dasharray`, `rx`. `<text>`, `filter`, `clipPath`, `mask`, `paint-order`, CSS(`style=`, `<style>`), `<image>`, 외부 참조 금지. 글자 장식은 QPainter로 맑은 고딕을 써서 그린다.
- QSS 글꼴 크기는 정수 px. 장식은 마우스를 받지 않는다(`WA_TransparentForMouseEvents`).
- 움직임: 프레임 간격 42ms(약 24fps) 이하 빈도. 숨김·잠금·트레이·현충일·Windows 애니메이션 끄기에서는 타이머가 돌지 않는다.
- `bare except`와 이유 없는 `except: pass` 금지. 테스트는 `app_dir` 픽스처의 합성 데이터만 쓴다. 실사용 AppData를 건드리지 않는다.
- 브랜치 `feat/v4.6-holiday-theme`에서 작업한다. push는 사용자가 요청할 때 `git push origin <브랜치>`처럼 브랜치를 명시해서만 한다. `--all`/`--mirror` 금지.
- 반복 확인은 `.\.venv\Scripts\python.exe -m pytest <파일> -q`, 태스크 끝 검증은 `.\.venv\Scripts\python.exe tools/verify.py quick --tests <파일들>`(PowerShell). 하네스의 `output/harness/<run-id>/summary.md`와 실행 ID를 작업 기록에 남긴다.

- Consumes: `holidays.KOREAN_HOLIDAYS: dict[str, str]` (키 `YYYY-MM-DD`)
- Produces:
  - `THEME_KEYS: tuple[str, ...]` — Global Constraints의 13개 순서
  - `MATCH_NAMES: dict[str, str]` — `newyear→"1월1일"`, `seollal→"설날"`, `samil→"삼일절"`, `labor→"노동절"`, `children→"어린이날"`, `buddha→"부처님오신날"`, `memorial→"현충일"`, `constitution→"제헌절"`, `liberation→"광복절"`, `chuseok→"추석"`, `gaecheon→"개천절"`, `hangul→"한글날"`, `christmas→"기독탄신일"`
  - `LEAD_DAYS = 3`, `GROUP_GAP_DAYS = 7`, `DEFAULT_HEADER = "#01295F"`
  - `@dataclass(frozen=True) class HolidayTheme: key: str; header: str; today: str; tint: str; cover: str; accent: str; focus_end: str; band: str; band_icon: str; greeting: str; band_stripes: tuple[str, ...] = (); motion: bool = True`
  - `THEMES: dict[str, HolidayTheme]` — 설계 문서 '색' 표 그대로. `seollal.band_stripes = ("#F6B0B0", "#FBE38E", "#B5DDB1", "#B4CDF0", "#F4BEDB")`, `seollal.band = "#F6B0B0"`, `memorial.motion = False`
  - `@dataclass(frozen=True) class HolidayThemeMatch: theme: HolidayTheme; first_day: date; last_day: date; dates: tuple[date, ...]; in_holiday: bool` (`dates`는 묶음에 든 실제 공휴일 날짜)
  - `resolve_holiday_theme(today: date, holidays: Mapping[str, str]) -> HolidayThemeMatch | None`
  - `current_match(today: date | None = None) -> HolidayThemeMatch | None` — `today` 없으면 `date.today()`, 자료는 `holidays.KOREAN_HOLIDAYS`. 화면 코드가 날짜를 얻는 유일한 입구다.

from PySide6.QtWidgets import QWidget
import database as db
from ui_settings import SettingsWindow

def _window(qtbot, **kw):
    win = SettingsWindow(**kw)
    qtbot.addWidget(win); win.show(); qtbot.waitExposed(win)
    return win

def _columns(win):
    grid = win.layout().itemAt(0).layout()
    return grid.itemAtPosition(0, 0).widget(), grid.itemAtPosition(0, 1).widget()

def test_switch_row_is_last_in_display_panel(qtbot, app_dir):
    win = _window(qtbot)
    left, _ = _columns(win)
    display = left.layout().itemAt(0).widget()
    labels = [w.text() for w in display.findChildren(QWidget, "rowLabel")]
    assert labels[-2:] == ["음력 및 공휴일", "공휴일 테마"]

def test_switch_default_on_when_key_missing(qtbot, app_dir):
    assert db.get_setting(db.SETTING_HOLIDAY_THEME_ENABLED, "") == ""
    assert _window(qtbot).holiday_theme_switch.isChecked()

def test_toggle_saves_only_key_and_calls_callback(qtbot, app_dir, monkeypatch):
    calls, saved = [], []
    real_save = db.save_setting
    monkeypatch.setattr(db, "save_setting", lambda k, v: (saved.append((k, v)), real_save(k, v)))
    win = _window(qtbot, on_holiday_theme_changed=lambda: calls.append(1))
    win.holiday_theme_switch.setChecked(False)
    win.holiday_theme_switch.setChecked(True)
    assert saved == [("holiday_theme_enabled", "0"), ("holiday_theme_enabled", "1")]
    assert calls == [1, 1]

def test_layout_fits_without_compression(qtbot, app_dir):
    win = _window(qtbot)
    qtbot.wait(100)
    assert (win.width(), win.height()) == (800, 560)
    assert win.layout().minimumSize().height() <= 560
    for column in _columns(win):
        assert column.height() >= column.sizeHint().height()

def test_left_rows_36_right_rows_40(qtbot, app_dir):
    win = _window(qtbot)
    left, right = _columns(win)
    left_heights = {r.minimumHeight() for r in left.findChildren(QWidget, "settingsRow")}
    right_heights = {r.minimumHeight() for r in right.findChildren(QWidget, "settingsRow")}
    assert 40 not in left_heights and 36 in left_heights
    assert right_heights == {40}
