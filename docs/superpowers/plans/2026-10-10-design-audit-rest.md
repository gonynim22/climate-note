# 디자인 점검 나머지(11·15~21번) Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** 디자인 점검 보고서(`output/design/design-audit-20261009/design-audit.html`)의 11·15·16·17·18·19·20·21번을 보고서 제안대로 고친다(12번 제외, 사용자 지시 2026-10-10).

**Architecture:** 항목마다 해당 위젯만 고친다. 새 공용 모듈은 만들지 않고, 이미 있는 것(`ui_window_card`, `ui_mini_app_frame`, qfluentwidgets 위젯)을 쓴다. 저장 데이터·설정 키·창 크기 계약은 그대로다.

**Tech Stack:** Python 3.13, PySide6 6.11.2, qfluentwidgets 1.11.1, pytest-qt, `tools/verify.py`.

**Spec:** 보고서 각 항목의 "제안" 문단 + 아래 "결정" 줄(사용자 승인 대상).

## Global Constraints

- DB v17·Export v2·salt·설정 키·바로가기 6슬롯·미니앱 메모리 기록 불변. 데이터 변경 없음.
- 창 크기 계약 유지: 설정 800×560 무스크롤, 미니앱 창 크기, 헤더 이동 버튼 32px·4px 간격·좌우 104px, 바로가기 64px 버튼.
- 화면 문구는 한국어(영문 금지, 6번 결정). QSS 글꼴 크기는 정수 px. 앱 강조색 `#2563EB`, 남색 `#01295F`.
- 각 항목은 실패하는 시험을 먼저 쓰고(TDD) 100/125/150% quick, 끝에 full. 커밋·빌드는 사용자 지시 때만.

## Review Focus

- 좁은 화면·125/150% 배율에서 새 글자(저장 경로, D-Day 미리보기, 끌어 놓기 안내)가 잘리거나 무스크롤 계약을 깨지 않는가.
- 15번: 오늘이 아닌 날을 고른 상태 ↔ 오늘을 고른 상태 ↔ 다른 달로 이동했을 때 원·테두리가 남지 않는가.
- 17번: 달력에서 고른 날짜와 직접 입력한 날짜가 서로 덮어쓰지 않고, 잘못된 날짜면 미리보기가 "날짜를 확인하세요"로 바뀌는가.
- 21번: 버튼을 숨기는 조건이 변환 중·실패·취소 상태 전환에서 기존 활성/비활성 규칙과 어긋나지 않는가.
- 18번: 저장 경로가 매우 길거나(사용자 이름이 긴 PC) 한글일 때 가운데 말줄임과 툴팁 전체 경로.

### Task 1: 11번 이동 버튼 켜짐 표시 (`ui_main.CalendarMoveButton`)

- 지금: 켜짐 = 연한 파랑 사각 채움 + 남색 화살표(검색·더보기보다 훨씬 강함), 꺼짐 = 투명 + 사선.
- **결정(제안):** 켜짐도 다른 머리줄 아이콘처럼 투명 바탕·흰 화살표로 두고, 버튼 아래 가운데에 작은 점(지름 4px, `#93C5FD`)으로 켜짐을 표시한다. 꺼짐은 지금처럼 사선. 크기·간격·키보드·저장 동작은 그대로.
- 시험(`tests/test_ui_calendar_move.py` 보강): 켜짐 상태 그림에서 버튼 가운데 바탕이 머리줄 남색과 같고(채움 없음), 아래 점 위치 픽셀이 `#93c5fd`; 꺼짐에는 점이 없다.

### Task 2: 15번 크게·중간 모드 날짜 칸 (`ui_main.CalendarDayButton`, 요일 머리줄)

- 지금: 숫자 가운데·일정 칩 칸 전체 폭(기준선 둘), 요일 글자 11px, 오늘 칸 전체가 남색 블록(칩까지 덮음).
- **결정(제안):** expanded 모드(중간·크게)에서만
  - 날짜 숫자를 왼쪽 위(칩과 같은 왼쪽 여백)로.
  - 오늘: 칸 바탕은 흰색 그대로, 숫자 뒤에 남색 원(지름 24px)·흰 숫자.
  - 고른 날: 칸에 남색 1.5px 테두리(모서리 6px), 바탕 채움 없음.
  - 요일 머리줄 글자 11→13px(크게), 12px(중간), 칸과 같은 왼쪽 정렬.
  - compact(기본 크기)는 그대로.
- 시험(`tests/test_ui_calendar_columns.py`·새 시험): expanded에서 숫자 라벨이 칸 왼쪽 위, 오늘 칸 칩 영역 픽셀이 흰색(남색 블록 아님), 고른 날 테두리 픽셀, 요일 글자 크기. 기존 "열 너비 1px 이내·요일 제목 정렬" 시험 유지.

### Task 3: 16번 크게 모드 오른쪽 열 (`ui_dday_panel.py`, `ui_sticky.StickyFormatToolbar`)

- D-Day 카드 이름 10→11px(최소 11px 규칙).
- 'D-Day 추가' 칸: "+ D-Day"/"추가" 두 줄 → 한 줄 "+ D-Day 추가"(11px). '최대 5개' 안내 칸도 한 줄로 맞춘다.
- 스티키 서식 도구 첫 버튼(배경 색상): 색 견본 위에 팔레트 선 아이콘(`FIF.PALETTE`, 12px)을 올린다. 툴팁 "배경 색상"은 이미 있음.
- 시험: 이름 글꼴 11px, 추가 칸 글자 한 줄(라벨 1개·줄바꿈 없음), 배경 버튼 아이콘이 비어 있지 않음.

### Task 4: 17번 D-Day 만들기·집중 시작 창 (`ui_dday.DDayCreateDialog`, `ui_focus.FocusCreateDialog`)

- **결정(제안):** 연·월·일 직접 입력은 그대로 두고(기존 사용자·시험 경로), 옆에 달력 버튼을 더해 qfluentwidgets 달력에서 고르면 세 칸이 채워진다.
- 창 안 제목("D-Day 만들기"/"D-Day 편집", 굵게 16px)과, 날짜 아래 미리보기("D-13 · 10월 22일(목)", 잘못된 날짜면 "날짜를 확인하세요")를 둔다. 버튼 위 여백 16px. 창 크기 320×200 → 약 340×280(작은 화면 확인).
- 집중 시작 창도 같은 틀(창 안 제목 "집중 모드 추가", 같은 여백·버튼 줄).
- 위험: qfluentwidgets 달력의 월·요일 이름이 영어로 나오면 한국어로 바꾸거나(로캘 지정) 직접 만든 작은 달력으로 대체한다.
- 시험(`tests/test_ui.py` D-Day 창, `tests/test_ui_focus.py`): 제목 글자, 미리보기(오늘+13 → "D-13"), 잘못된 날짜 안내, 달력 선택이 세 칸을 채움, 기존 저장 경로·검증 그대로.

### Task 5: 18번 설정 '데이터' (`ui_settings.py`)

- PIN 칸: 폭 60 → 약 110px, 글자 왼쪽 정렬, 안내 "PIN 4자리"(입력칸으로 보이게). 4자리·숫자·가림은 그대로.
- 저장 경로: **폴더 버튼은 그대로 두고** 그 왼쪽에 실제 경로 한 줄(12px 회색, 가운데 말줄임, 툴팁 전체 경로)을 둔다.
- 시험(`tests/test_ui.py` 설정): PIN 칸 폭·정렬·안내, 경로 라벨 툴팁 = 실제 저장 폴더, 긴 경로 말줄임, 설정 창 800×560 무스크롤·최소 크기 기존 시험 통과.

### Task 6: 19번 미니앱 주머니 이름 높이 (`ui_mini_apps.MiniAppTile`)

- 지금: Qt 기본 "아이콘 아래 글자"가 아이콘+글자 묶음을 세로 가운데에 놓아, 한 줄 이름(단위 환산기)만 아이콘이 아래로 내려간다.
- 수정: 타일이 아이콘을 위쪽 고정 위치에, 이름을 그 바로 아래 위쪽 정렬로 직접 그린다. 타일 크기·초점·키보드·`text()`는 그대로.
- 시험(`tests/test_ui_mini_apps.py`): 한 줄·두 줄 이름 타일의 아이콘 위쪽 y와 첫 줄 글자 위치가 같다(픽셀).

### Task 7: 20·21번 미니앱 빈 공간 (`ui_date_time_calculator.py`, `ui_document_converter.py`)

- 20 날짜·시간: 안내 문구를 입력 바로 아래에 붙이고(사이 빈 칸 제거), 남는 높이는 결과 카드 위 한 곳에만 모은다. 네 모드 모두 같은 규칙. 무스크롤·좁은 화면 압축 그대로.
- 21 문서 변환:
  - 파일이 없으면 표 자리에 "여기에 HWP 파일을 끌어 놓으세요 · 또는 [파일 추가]" 안내를 보인다.
  - **결정(제안):** 자주 쓰지 않는 버튼은 필요할 때만 보인다 — 선택 제거·목록 비우기(파일이 있을 때), 실패·취소 재시도(실패/취소 항목이 있을 때), 결과 저장 폴더 열기(완료 결과가 있을 때), 취소(변환 중). 활성 조건은 기존 그대로.
- 시험(`tests/test_ui_date_time_calculator.py`, `tests/test_ui_document_converter.py`): 안내와 마지막 입력 사이 간격 상한, 빈 목록 안내 표시/숨김, 상태별 버튼 표시, 기존 변환·취소·재시도 시험 통과.
