> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** 설정창을 시안 A에 충실하게 다듬고(제목 제거·헤더 강조·초기화 PIN 제거·크레딧 한 줄·콤보폭·위치 여백), 앱 종료 2회 버그와 크게/중간 모드(월 네비 중앙·D-Day 미니패널 3×2 그리드+X·집중 미니카드 X)를 고친다.

        try:
            target = date.fromisoformat(self._target_date)
        except (ValueError, TypeError):
            self.count_label.setText("?")
            return
        delta = (target - date.today()).days
        if delta > 0:
            self.count_label.setText(f"D-{delta}")
            self.count_label.setStyleSheet(
                "font-size:14px;font-weight:700;color:#0078D4;background:transparent;"
            )

            self.count_label.setText("D-Day")
            self.count_label.setStyleSheet(
                "font-size:14px;font-weight:700;color:#D32F2F;background:transparent;"
            )
        else:
            self.count_label.setText(f"D+{abs(delta)}")
            self.count_label.setStyleSheet(
                "font-size:14px;font-weight:700;color:#888;background:transparent;"
            )
