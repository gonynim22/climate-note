# v3.8c 금액·숫자 표기 도우미와 미니앱 주머니 A안 구현 계획

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** 미니앱 주머니를 A안(앱 런처·SVG 아이콘)으로 바꾸고, 세 번째 미니앱인 금액·숫자 표기 도우미를 추가해 v3.8c로 릴리스 검증한다.

**Architecture:**
- 1단계는 `ui_mini_apps.py`의 스타일·크기를 바꾸고 `resources/icons/mini_apps/*.svg` 아이콘 한 계열로 교체한다.
- 2단계는 Qt 없는 순수 계산 모듈 `money_notation.py`와 날짜·시간 계산기 틀을 따른 독립 창 `ui_money_notation.py`를 만든다. 메인 창이 날짜·시간 계산기와 같은 9개 수명 지점과 주머니 신호에서 이 창을 소유한다.
- DB·설정·Export·salt는 건드리지 않는다.

**Tech Stack:** Python 3.13, PySide6/Qt 6.11.2(`QtSvg` 포함), PySide6-Fluent-Widgets, pytest + pytest-qt, `decimal.Decimal`, PyInstaller(하네스 `release`)

**Spec:** [`docs/superpowers/specs/2026-09-27-v3.8c-money-notation-pocket-design.md`](../specs/2026-09-27-v3.8c-money-notation-pocket-design.md)

## Global Constraints

- DB v17, Export v2, salt, 암호화 키 유도, 기존 설정 키, 바로가기 6슬롯(DB ID 1~6, 64px 버튼), Qt 6.11.2, `requirements-lock.txt`를 바꾸지 않는다.
- 새 설정 키, DB 테이블, 컬럼을 만들지 않는다. 도우미 입력, 최근 12개, 창 상태는 실행 중 메모리 전용이다.
- 오프라인 전용이다. 네트워크와 외부 코드 로더는 금지한다. 리소스는 `app_paths.resource_root()`로만 찾는다. `Path(__file__).parent`로 경로를 만들지 않는다.
- QSS 글꼴 크기는 정수 px만 쓴다. 본문 글꼴은 앱 기본 Malgun Gothic이다.
- 보안 코딩 규칙:
  - `bare except`와, 이유나 처리 없이 `except`에 `pass`만 두는 코드는 금지한다.
  - 파일은 `with open`, DB는 `database._connection()`으로 연다.
- 계산에 `float`와 내장 `round()`를 쓰지 않는다. `int`, `Decimal`, 절댓값 기준 `ROUND_HALF_UP`만 쓴다. 상한은 절댓값 1경(`10**16`) 미만이다.
- 금액 한글은 모든 자리에 '일'을 적고 공백 없이 붙여 쓴다(`금113,560원(금일십일만삼천오백육십원)`). 억·만 표기는 `12억 3456만 7898`(묶음 안 쉼표 없음), 한글 읽기는 만 단위로 띄어 쓴다.
- 주머니 본체는 252×280px(창 300×328px), 타일 104×100px, 아이콘 48px이다. 순서는 단위 환산기 → 날짜·시간 계산기 → 금액·숫자 표기 → 준비 중 1칸이다.
- 도우미 창은 내용 480×620px(창 528×668px), 왼쪽 메뉴 108px이며 스크롤 영역을 두지 않는다.
- git
  - `main`에서 직접 커밋하지 않는다. `git push --all`/`--mirror`는 금지이고, 이 계획에서는 push하지 않는다.
  - 사용자의 기존 미커밋 변경(`.gitignore`, `AGENTS.md`, `docs/RELEASE_HISTORY.md`, 오래된 `docs/work/2026-09-1*.md`·`2026-09-24-unit-converter-redesign-concepts.md`)은 **스테이징하지 않는다**.
  - `AGENTS.md`는 내용만 갱신하고 커밋하지 않는다. `.gitignore`에 올라 있고 사용자 변경이 섞여 있으므로, 인계 때 보고한다.
- 커밋은 단계 끝(Task 3, Task 10)과 마무리(Task 11의 release 전 소스 커밋, release 후 기록 커밋)에만 파일을 명시해 만든다. 메시지 끝에 다음 줄을 붙인다.

```python
"""미니앱 SVG 아이콘 규칙(AGENTS.md 아이콘 디자인 규칙)과 실제 QtSvg 렌더를 검증한다."""
import pytest
from PySide6.QtCore import QRectF, Qt
from PySide6.QtGui import QColor, QImage, QPainter
from PySide6.QtSvg import QSvgRenderer

from app_paths import resource_root

ICON_DIR = resource_root() / "resources" / "icons" / "mini_apps"
APP_ICONS = {
    "unit_converter": ("#22B8CF", "#0B7285"),
    "date_time": ("#4C8DF6", "#1D4ED8"),
    "money_notation": ("#40C074", "#1E8E4E"),
}
ALL_ICONS = [*APP_ICONS, "upcoming", "launcher"]


@pytest.fixture(autouse=True)
def gui(qapp):
    # QPainter 렌더에는 QGuiApplication이 필요하다.
    yield


def render(name, size):
    renderer = QSvgRenderer(str(ICON_DIR / f"{name}.svg"))
    assert renderer.isValid(), name
    image = QImage(size, size, QImage.Format_ARGB32_Premultiplied)
    image.fill(Qt.transparent)
    painter = QPainter(image)
    renderer.render(painter, QRectF(0, 0, size, size))
    painter.end()
    return image


def distance(color, expected):
    target = QColor(expected)
    return (abs(color.red() - target.red()) + abs(color.green() - target.green())
            + abs(color.blue() - target.blue()))


def is_white(color):
    return color.alpha() == 255 and min(color.red(), color.green(), color.blue()) >= 235


@pytest.mark.parametrize("name", ALL_ICONS)
def test_icon_is_self_contained_qt_tiny_svg(name):
    path = ICON_DIR / f"{name}.svg"
    with open(path, encoding="utf-8") as stream:
        text = stream.read()
    for banned in ("<text", "<image", "<filter", "<mask", "<style", "http://w", "https://", "@import", "xlink:href"):
        if banned == "http://w":
            # SVG 네임스페이스 선언만 허용하고 다른 외부 주소는 금지한다.
            assert text.count("http://www.w3.org/2000/svg") == text.count("http://"), name
            continue
        assert banned not in text, (name, banned)
    assert QSvgRenderer(str(path)).isValid()


@pytest.mark.parametrize("name,colors", APP_ICONS.items())
@pytest.mark.parametrize("scale", [1, 1.25, 1.5])
def test_app_icon_has_gradient_rounded_corners_and_white_glyph(name, colors, scale):
    size = round(48 * scale)
    image = render(name, size)
    start, end = colors
    assert image.pixelColor(0, 0).alpha() == 0
    assert image.pixelColor(size - 1, size - 1).alpha() == 0
    assert distance(image.pixelColor(round(size * .16), round(size * .10)), start) <= 90
    assert distance(image.pixelColor(round(size * .84), round(size * .90)), end) <= 90
    inner = range(round(size * .2), round(size * .8))
    white = sum(1 for x in inner for y in inner if is_white(image.pixelColor(x, y)))
    assert white >= size, (name, white)


@pytest.mark.parametrize("scale", [1, 1.25, 1.5])
def test_date_time_clock_face_is_white(scale):
    size = round(48 * scale)
    image = render("date_time", size)
    # 시계 면(24 격자 (13.5,16.5))은 흰색이다. 바늘(x=17)과 안티에일리어싱이 닿지 않는 지점.
    x = round((9.6 + 13.5 * 1.2) / 48 * size)
    y = round((9.6 + 16.5 * 1.2) / 48 * size)
    assert is_white(image.pixelColor(x, y))


def test_upcoming_icon_is_dashed_outline_with_transparent_body():
    image = render("upcoming", 48)
    assert image.pixelColor(12, 12).alpha() == 0
    top = [image.pixelColor(x, 1).alpha() > 128 for x in range(14, 34)]
    assert any(top) and not all(top)
    assert image.pixelColor(24, 24).alpha() == 255


@pytest.mark.parametrize("size", [20, 40])
def test_launcher_icon_keeps_blue_accent(size):
    image = render("launcher", size)
    center = round(17 / 24 * size)
    assert distance(image.pixelColor(center, center), "#2563EB") <= 60
    assert image.pixelColor(round(7 / 24 * size), round(7 / 24 * size)).alpha() == 0
```

```python
    """번들 `resources/icons/mini_apps/<name>.svg`. 경로는 resource_root()만 기준으로 만든다."""

def pocket_position(anchor: QRect, size: QSize, available: QRect, *, shadow_margin: int = 0) -> QPoint:
    """버튼 오른쪽 우선, 공간 부족 시 왼쪽, 마지막으로 작업 영역에 보정."""
    gap = 12 if shadow_margin else 8
    x = anchor.right() + 1 + gap - shadow_margin
    if x + size.width() > available.right() + 1:
        x = anchor.left() - size.width() - gap + shadow_margin
    return QPoint(
        max(available.left(), min(x, available.right() + 1 - size.width())),
        max(available.top(), min(anchor.top() - shadow_margin, available.bottom() + 1 - size.height())),
    )
```

```python
"""금액·숫자 표기 도우미의 순수 계산. Qt·DB·네트워크에 접근하지 않는다.

근거: 「행정업무의 운영 및 혁신에 관한 규정 시행규칙」 제2조(금액 한글 병기),
한글 맞춤법 제43·44항(단위 명사·만 단위 띄어쓰기). 상세 계약은 docs/MONEY_NOTATION.md.
금액과 정수는 int, 환산은 Decimal만 쓰며 float와 내장 round()는 쓰지 않는다.
"""
from dataclasses import dataclass
from decimal import Decimal
import re

LIMIT = 10 ** 16  # 1경. 모든 모드의 절댓값 상한(미만)

_DIGITS = "영일이삼사오육칠팔구"
_SMALL = ("", "십", "백", "천")
_BIG = ("", "만", "억", "조")
_INTEGER = r"(?:\d{1,3}(?:,\d{3})+|\d+)"
_INTEGER_RE = re.compile(rf"([-−]?)({_INTEGER})", re.ASCII)
_FRACTION_RE = re.compile(rf"[-−]?{_INTEGER}\.\d+", re.ASCII)
_DECIMAL_RE = re.compile(rf"([-−]?)({_INTEGER})(?:\.(\d+))?", re.ASCII)
_FORMAT_MESSAGE = "숫자와 세 자리 쉼표만 입력할 수 있습니다."


class NotationError(ValueError):
    """사용자에게 그대로 보여 줄 한국어 입력 오류."""


@dataclass(frozen=True)
class OfficialAmount:
    digits: str  # '113,560'
    hangul: str  # '일십일만삼천오백육십'
    text: str    # '금113,560원(금일십일만삼천오백육십원)'


def parse_integer(text: str) -> int:
    """앞뒤 공백만 제거하고 정수 전체를 검증한다. 잘못된 값은 보정하지 않는다."""
    raw = text.strip()
    if not raw:
        raise NotationError("값을 입력하세요.")
    match = _INTEGER_RE.fullmatch(raw)
    if match is None:
        if _FRACTION_RE.fullmatch(raw):
            raise NotationError("정수만 입력할 수 있습니다.")
        raise NotationError(_FORMAT_MESSAGE)
    value = int(match.group(2).replace(",", ""))
    return -value if match.group(1) else value


def parse_decimal(text: str) -> Decimal:
    """단위 환산 입력. 소수는 6자리까지 정확한 Decimal로 받는다."""
    raw = text.strip()
    if not raw:
        raise NotationError("값을 입력하세요.")
    match = _DECIMAL_RE.fullmatch(raw)
    if match is None:
        raise NotationError(_FORMAT_MESSAGE)
    sign, integer, fraction = match.groups()
    if fraction is not None and len(fraction) > 6:
        raise NotationError("소수는 6자리까지 입력할 수 있습니다.")
    value = Decimal(integer.replace(",", "") + (f".{fraction}" if fraction else ""))
    return -value if sign else value


def _groups(value: int) -> list[int]:
    """0 이상 정수를 낮은 자리부터 네 자리 묶음으로 나눈다."""
    groups = []
    while value:
        value, group = divmod(value, 10000)
        groups.append(group)
    return groups


def _group_hangul(value: int, official: bool) -> str:
    """네 자리 묶음 하나를 읽는다. official이면 십·백·천 앞의 '일'도 적는다."""
    text = ""
    for position in range(3, -1, -1):
        digit = value // 10 ** position % 10
        if digit == 0:
            continue
        if digit == 1 and position > 0 and not official:
            text += _SMALL[position]
        else:
            text += _DIGITS[digit] + _SMALL[position]
    return text


def official_hangul(n: int) -> str:
    """공문서 금액 한글. 모든 자리에 '일'을 적고 공백 없이 붙여 쓴다(변조 방지 관례)."""
    if not 1 <= n < LIMIT:
        raise NotationError("금액은 1원 이상 1경 미만이어야 합니다.")
    groups = _groups(n)
    return "".join(
        _group_hangul(group, True) + _BIG[index]
        for index, group in reversed(list(enumerate(groups))) if group
    )


def official_amount(n: int) -> OfficialAmount:
    hangul = official_hangul(n)
    digits = f"{n:,}"
    return OfficialAmount(digits, hangul, f"금{digits}원(금{hangul}원)")
```

```python
    if n == 0:
```

```python
SCOPES = ("all", "man", "eok")


@dataclass(frozen=True)
class Reading:
    value: int       # 표시 범위를 적용한 값
    rounded: bool    # 반올림으로 값이 바뀌었는지
    notation: str    # '약 12억 3457만원'
    hangul: str      # '십이억 삼천사백오십칠만 원'
    original: str    # '1,234,567,890원'


def _check_limit(n) -> None:
    if abs(n) >= LIMIT:
        raise NotationError("절댓값 1경 미만까지 지원합니다.")


def _signed_digits(n: int) -> str:
    return ("−" if n < 0 else "") + f"{abs(n):,}"


def group_notation(n: int) -> str:
    """한글 맞춤법 제44항 예시 형식 '12억 3456만 7898'. 묶음 안에는 쉼표를 넣지 않는다."""
    _check_limit(n)
    if n == 0:
        return "0"
    groups = _groups(abs(n))
    text = " ".join(f"{group}{_BIG[index]}" for index, group in reversed(list(enumerate(groups))) if group)
    return "−" + text if n < 0 else text


def reading_hangul(n: int) -> str:
    """만 단위로 띄어 읽는다. 십·백·천 앞의 '일'과 만 묶음의 '일'을 생략한다."""
    _check_limit(n)
    if n == 0:
        return "영"
    parts = []
    groups = _groups(abs(n))
    for index in range(len(groups) - 1, -1, -1):
        group = groups[index]
        if not group:
            continue
        head = "" if index == 1 and group == 1 else _group_hangul(group, False)
        parts.append(head + _BIG[index])
    text = " ".join(parts)
    return "마이너스 " + text if n < 0 else text


def round_half_up(n: int, unit: int) -> int:
    """절댓값 기준 사사오입(0에서 먼 쪽). unit은 10 이상의 10의 거듭제곱이다."""
    magnitude = (abs(n) + unit // 2) // unit * unit
    return -magnitude if n < 0 else magnitude


def read_number(n: int, scope: str, unit_text: str = "") -> Reading:
    _check_limit(n)
    unit = unit_text.strip()
    if len(unit) > 8:
        raise NotationError("단위는 8자까지 입력할 수 있습니다.")
    if scope == "all":
        value = n
    elif scope == "man":
        value = round_half_up(n, 10 ** 4)
    elif scope == "eok":
        value = round_half_up(n, 10 ** 7)
    else:
        raise ValueError(f"알 수 없는 표시 범위입니다: {scope}")
    rounded = value != n
    if scope == "eok":
        eok = abs(Decimal(value)) / Decimal(10 ** 8)
        body = ("−" if value < 0 else "") + f"{eok:,.1f}억"
    else:
        body = group_notation(value)
    notation = ("약 " if rounded else "") + body + unit
    hangul = reading_hangul(value) + (f" {unit}" if unit else "")
    return Reading(value, rounded, notation, hangul, _signed_digits(n) + unit)
```

```python
def convert_money(value: Decimal, src: str) -> dict[str, Decimal]:
    """모든 단위의 정확한 값. 10의 거듭제곱 배수라 유한 소수로 끝난다."""
    with localcontext() as context:
        context.prec = 50
        won = value * _FACTORS[src]
        _check_limit(won)
        return {key: won / factor for key, _name, factor in MONEY_UNITS}


def _grouped(value: Decimal) -> str:
    """지수 표기 없이 천 단위 쉼표를 넣고 음수는 − 로 표시한다."""
    sign = "−" if value < 0 else ""
    integer, _dot, fraction = format(abs(value), "f").partition(".")
    return sign + f"{int(integer):,}" + (f".{fraction}" if fraction else "")


def exact_text(value: Decimal) -> str:
    """표 전용 정확한 값. 끝의 0과 불필요한 소수점을 지운다."""
    return _grouped(value.normalize() if value else Decimal(0))


def format_decimal(value: Decimal, digits: int | None) -> str:
    """표시 전용 반올림(ROUND_HALF_UP). None은 정확한 값을 소수 6자리까지 보여 준다."""
    if digits is None:
        if value.as_tuple().exponent < -6:
            value = value.quantize(Decimal("0.000001"), rounding=ROUND_HALF_UP)
        return exact_text(value)
    return _grouped(value.quantize(Decimal(1).scaleb(-digits), rounding=ROUND_HALF_UP))
```

```python
            self.copy_format.addItem(title, value)
        self.copy_format.setCurrentIndex(self._copy_choice[mode])
        self.copy_format.blockSignals(False)
        _set_property(self.result_detail, "strong", mode == "amount")
        self.update_results()

    def update_results(self, *args):
        if self._updating or not hasattr(self, "status_label"):
            return
        self._valid = False
        self._outputs = {}
        self._label = ""
        try:
            caption, main, detail, note, outputs, label = getattr(self, f"_compute_{self.mode}")()
        except NotationError as exc:
            self.error_label.setText(str(exc))
            self.error_label.show()
            self.result_caption.setText("계산 결과")
            self.result_label.setText("—")
            self.result_detail.setText("입력을 확인하세요.")
            self.result_note.clear()
            if self.mode == "convert":
                for name_label, value_label in self.unit_rows.values():
                    value_label.set_full_text("—")
                    _set_property(name_label, "hit", False)
                    _set_property(value_label, "hit", False)
        else:
            self.error_label.hide()
            self.result_caption.setText(caption)
            self.result_label.setText(main)
            self.result_detail.setText(detail)
            self.result_note.setText(note)
            self._outputs, self._label, self._valid = outputs, label, True
        self.copy_button.setEnabled(self._valid)
        self.save_button.setEnabled(self._valid)
        self._refresh_preview()
        self._fit_result_font()

    def _compute_amount(self):
        value = parse_integer(self.fields["amount"]["value"].text())
        amount = official_amount(value)
        main = f"금{amount.digits}원"
        outputs = {"official": amount.text, "hangul": f"금{amount.hangul}원", "digits": amount.digits}
        return ("공문서 금액 표기", main, f"(금{amount.hangul}원)", f"읽기: {reading_hangul(value)} 원",
                outputs, f"금액 표기 · {main}")

    def _compute_read(self):
        controls = self.fields["read"]
        value = parse_integer(controls["value"].text())
        reading = read_number(value, controls["scope"].currentData(), controls["unit"].text())
        note = f"원래 값 {reading.original}" if reading.rounded else reading.original
        outputs = {"notation": reading.notation, "hangul": reading.hangul, "digits": f"{value:,}"}
        return ("큰 수 읽기", reading.notation, reading.hangul, note, outputs, f"큰 수 읽기 · {reading.notation}")

    def _compute_convert(self):
        controls = self.fields["convert"]
        value = parse_decimal(controls["value"].text())
        source, target = controls["from"].currentData(), controls["to"].currentData()
        places = controls["digits"].currentData()
        places = None if places < 0 else places
        values = convert_money(value, source)
        for key, (name_label, value_label) in self.unit_rows.items():
            value_label.set_full_text(exact_text(values[key]))
            _set_property(name_label, "hit", key == target)
            _set_property(value_label, "hit", key == target)
        main = format_decimal(values[target], places) + UNIT_NAMES[target]
        note = ("표시는 소수 6자리까지 · 표는 정확한 값" if places is None
                else f"표시만 소수 {places}자리 반올림 · 표는 정확한 값")
        table = "\n".join(f"{UNIT_NAMES[key]}\t{exact_text(values[key])}" for key, _name, _factor in MONEY_UNITS)
        source_text = f"{exact_text(value)}{UNIT_NAMES[source]}"
        return (f"금액 단위 환산 · {UNIT_NAMES[source]} → {UNIT_NAMES[target]}", main, f"= {source_text}",
                note, {"value": main, "table": table}, f"단위 환산 · {source_text} → {main}")

    def fit_to_screen(self, available=None):
        if available is None:
            screen = QApplication.screenAt(self.frameGeometry().center()) or self.screen() or QApplication.primaryScreen()
            if screen is None:
                return
            available = screen.availableGeometry()
        compact = available.height() < WINDOW_HEIGHT
        margin = min(SHADOW_MARGIN, max(0, (available.width() - 420) // 2),
                     max(0, (available.height() - WINDOW_HEIGHT) // 2))
        self.header.setFixedHeight(40 if compact else 52)
        self.right_layout.setContentsMargins(12 if compact else 18, 6 if compact else 17,
                                             12 if compact else 18, 6 if compact else 16)
        self.right_layout.setSpacing(4 if compact else 7)
        self.mode_title.setVisible(not compact)
        self.status_label.setVisible(not compact)
        self.result_note.setVisible(not compact)
        self.result_label.setMinimumHeight(32 if compact else 43)
        self.result_layout.setContentsMargins(10 if compact else 14, 6 if compact else 12,
                                              10 if compact else 14, 6 if compact else 12)
        self.law_box.setText(LAW_LINES[0] if compact else "\n".join(LAW_LINES))
        for note in self._form_notes:
            note.setVisible(not compact)
            note.parentWidget().setToolTip(note.text())
        for page in self.page_widgets.values():
            page.layout().setSpacing(4 if compact else 7)
        self.body.layout().setSpacing(4 if compact else 7)
        self.layout().setContentsMargins(margin, margin, margin, margin)
        shadow = self.surface.graphicsEffect()
        shadow.setBlurRadius(max(0, margin - 4))
        shadow.setOffset(0, min(4, margin))
        shadow.setEnabled(margin > 0)
        # 숨김/여백 변경의 최소 높이를 안쪽부터 반영한 뒤 native 창을 줄인다.
        for widget in reversed(self.findChildren(QWidget)):
            if widget.layout() is not None:
                widget.layout().activate()
                widget.updateGeometry()
        self.layout().activate()
        self.resize(min(WINDOW_WIDTH + margin * 2, available.width()),
                    min(WINDOW_HEIGHT + margin * 2, available.height()))
        self.move(max(available.left(), min(self.x(), available.right() + 1 - self.width())),
                  max(available.top(), min(self.y(), available.bottom() + 1 - self.height())))

    def hide_owned_popups(self):
        for combo in self.findChildren(ConverterCombo):
            combo.hidePopup()
        popup = QApplication.activePopupWidget()
        owner = popup
        while owner is not None:
            if owner is self:
                popup.close()
                break
            owner = owner.parentWidget()

    def _fit_result_font(self):
        font = QFont(self.font())
        font.setBold(True)
        for size in (34, 30, 26, 22, 18, 15):
            font.setPixelSize(size)
            if QFontMetrics(font).horizontalAdvance(self.result_label.text()) <= self.result_label.width():
                break
        self.result_label.setFont(font)

    def eventFilter(self, watched, event):
        if event.type() == QEvent.KeyPress and isinstance(watched, QAbstractButton) and event.key() in (Qt.Key_Return, Qt.Key_Enter):
            if not event.isAutoRepeat():
                watched.click()
            return True
        if watched in (getattr(self, "header", None), getattr(self, "title_label", None)):
            if event.type() == QEvent.MouseButtonPress and event.button() == Qt.LeftButton:
                self._drag_origin = (event.globalPosition().toPoint(), self.pos())
                return True
            if event.type() == QEvent.MouseMove and self._drag_origin and event.buttons() & Qt.LeftButton:
                origin, position = self._drag_origin
                self.move(position + event.globalPosition().toPoint() - origin)
                return True
            if event.type() == QEvent.MouseButtonRelease and self._drag_origin:
                self._drag_origin = None
                self.fit_to_screen()
                return True
        return super().eventFilter(watched, event)

    def keyPressEvent(self, event):
        if event.key() == Qt.Key_Escape:
            self.close()
            event.accept()
        else:
            super().keyPressEvent(event)

    def hideEvent(self, event):
        self._drag_origin = None
        self.hide_owned_popups()
        super().hideEvent(event)

    def resizeEvent(self, event):
        super().resizeEvent(event)
        if hasattr(self, "result_label"):
            self._fit_result_font()
```

```markdown
## 계산 기준 (출처 확인일 2026-09-27)

- 모든 모드의 절댓값 상한은 1경(10¹⁶) 미만이다. 정수는 `int`, 환산은 `Decimal`만 쓴다. 반올림은 절댓값 기준 `ROUND_HALF_UP`이며 표시할 때만 적용한다. 원본 값과 표의 정확한 값은 바꾸지 않는다.

  - 근거는 「행정업무의 운영 및 혁신에 관한 규정 시행규칙」 제2조다. 금액은 아라비아 숫자로 쓰되 숫자 다음에 괄호를 하고 한글로 적는다. 예: `금113,560원(금일십일만삼천오백육십원)`.
  - 1원 이상 1경 미만의 정수만 받는다. 모든 자리에 '일'을 적고(일십·일백·일천·일만), 0인 자리와 묶음은 생략한다.
  - 금액 한글은 변조 방지 관례에 따라 공백 없이 붙여 쓴다([국립국어원 답변](https://korean.go.kr/front/onlineQna/onlineQnaView.do?mn_id=&qna_seq=312190&pageIndex=1)).
- **큰 수 읽기**
  - 억·만 표기는 한글 맞춤법 제44항 예시(`12억 3456만 7898`)처럼 묶음 안에 쉼표를 넣지 않는다.
  - 한글 읽기는 만 단위로 띄어 쓴다. 십·백·천 앞의 '일'과 만 묶음의 '일'은 생략하고(`만`, `십일만`), `일억`·`일조`는 유지한다. 0은 `영`, 음수는 `마이너스`다.

  - 만 단위까지·억 단위(소수 1자리) 표시는 반올림 값으로 표기와 읽기를 함께 만든다. 값이 바뀌면 `약`과 원래 값을 표시한다.
```

```python
import hashlib
import json
from pathlib import Path
import sys
import types

ROOT = Path(__file__).resolve().parents[3]
sys.path.insert(0, str(ROOT))
from PyInstaller.archive.readers import CArchiveReader
from app_info import app_exe_name

run = (ROOT / sys.argv[1]).resolve()
assert run.is_relative_to(ROOT / "output" / "harness")
exe = run / "dist" / app_exe_name()
archive = CArchiveReader(str(exe))
pyz = archive.open_embedded_archive("PYZ.pyz")


def normalized(code):
    return code.replace(co_filename="", co_consts=tuple(
        normalized(c) if isinstance(c, types.CodeType) else c for c in code.co_consts))


def digest_file(path):
    with open(path, "rb") as stream:
        return hashlib.file_digest(stream, "sha256").hexdigest().upper()


report = {"exe": str(exe), "bytes": exe.stat().st_size, "sha256": digest_file(exe), "modules": {}, "files": {}}
for name in ("money_notation", "ui_money_notation", "ui_mini_apps", "ui_main", "ui_date_time_calculator",
             "ui_unit_converter", "ui_converter_combo", "app_info"):
    source = ROOT / (name + ".py")
    with open(source, encoding="utf-8") as stream:
        expected = compile(stream.read(), str(source), "exec", optimize=0)
    matched = normalized(pyz.extract(name)) == normalized(expected)
    report["modules"][name] = {"matches_compiled_source": matched, "source_sha256": digest_file(source)}
    assert matched, name
names = ["PySide6/Qt6Core.dll", "PySide6/Qt6Gui.dll", "PySide6/Qt6Widgets.dll", "PySide6/Qt6Svg.dll"] + [
    f"resources/icons/mini_apps/{icon}.svg"
    for icon in ("launcher", "unit_converter", "date_time", "money_notation", "upcoming")]
toc = {key.replace("\\", "/"): key for key in archive.toc}
for name in names:
    actual = archive.extract(toc[name])
    source = ROOT / ".venv/Lib/site-packages" / name if name.startswith("PySide6/") else ROOT / name
    sha256 = hashlib.sha256(actual).hexdigest().upper()
    report["files"][name] = {"matches_source": sha256 == digest_file(source), "sha256": sha256}
    assert report["files"][name]["matches_source"], name
removed = [key for key in toc if key.endswith("unit_converter_tile.png") or key == "resources/icons/date_time.svg"]
report["removed_resources_absent"] = not removed
assert not removed, removed
with open(run / "bundle-verification.json", "w", encoding="utf-8") as stream:
    json.dump(report, stream, ensure_ascii=False, indent=2)
print(json.dumps(report, ensure_ascii=False, indent=2))
```
