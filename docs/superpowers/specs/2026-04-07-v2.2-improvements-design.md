# v2.2 Design Spec

**Date**: 2026-04-07
**Version**: v2.1 → v2.2

## Overview

세 가지 개선사항을 적용하여 v2.2를 릴리스한다.

1. 일정 더블클릭 재수정 불가 버그 수정
2. 스티키 노트/D-Day 색상 팔레트 변경 및 투명도 0%
3. D-Day 팝업 Enter 키 동작 수정

---

## 1. 일정 더블클릭 재수정 버그 수정

### 파일

- `ui_main.py` — `_on_edit_schedule` 메서드

### 원인

`_finish_edit` 클로저에서 `layout.removeWidget(edit)` 호출 시 `focusOutEvent`가 재트리거되어 재진입 발생. `focusOutEvent` monkey-patch가 `super()`를 호출하지 않아 Qt 내부 포커스 상태 불일치.

### 변경 내용

- `_finish_edit` 진입 시 즉시 `self._editing_item = None`으로 설정하여 재진입 차단
- `focusOutEvent` lambda에서 `QLineEdit.focusOutEvent(edit, e)` 호출 추가

### 변경 범위

`_on_edit_schedule` 메서드 내부 약 5줄 수정. 외부 인터페이스 변경 없음.

## 2. 색상 팔레트 변경

### 파일

- `ui_sticky.py` — `STICKY_COLORS`, `StickyNoteWindow._apply_color`
- `ui_dday.py` — `DDayWidgetWindow._apply_color`
- `database.py` — `DEFAULT_STICKY_COLOR`, `DEFAULT_DDAY_COLOR`

### 변경 내용

#### 색상값 교체 (`ui_sticky.py`)

| Index | Before | After |
|---|---|---|
| 0 | `("#FFFDD2", "노랑")` | `("#FFFA8E", "")` |
| 1 | `("#D6FFE8", "민트")` | `("#D0FFF1", "")` |
| 2 | `("#E8D6FF", "보라")` | `("#FFD8FB", "")` |
| 3 | `("#D6EEFF", "하늘")` | `("#C4D5FF", "")` |

- 이름을 빈 문자열로 설정하여 `_ColorGridPopup`의 `setToolTip(name)` 호출 시 tooltip 미표시

#### 투명도 0% (완전 불투명)

- `ui_sticky.py` `StickyNoteWindow._apply_color`: `rgba({r}, {g}, {b}, 220)` → `rgba({r}, {g}, {b}, 255)`
- `ui_dday.py` `DDayWidgetWindow._apply_color`: `rgba({r}, {g}, {b}, 220)` → `rgba({r}, {g}, {b}, 255)`

#### 기본 색상 상수 (`database.py`)

- `DEFAULT_STICKY_COLOR`: `"#FFFDD2"` → `"#FFFA8E"`
- `DEFAULT_DDAY_COLOR`: `"#D6EEFF"` → `"#C4D5FF"`

### 기존 데이터 보존

- DB에 저장된 기존 노트/위젯의 색상값은 변경하지 않음
- DB 스키마의 `DEFAULT` 절은 Python 코드에서 색상을 명시적으로 전달하므로 변경 불필요
- 스키마 변경 없음 (마이그레이션 불필요)

## 3. D-Day 팝업 Enter 키 수정

### 파일

- `ui_dday.py` — `DDayCreateDialog.__init__`, `DDayWidgetWindow._on_close`

### 원인

QDialog 내에서 확인/삭제 버튼에 `setDefault(True)`가 없어 Enter 키가 `autoDefault` 속성이 켜진 첫 번째 버튼(취소)을 활성화함.

### 변경 내용

- `DDayCreateDialog`: `ok_btn.setDefault(True)`, `cancel_btn.setAutoDefault(False)`
- `_on_close` 삭제 확인 다이얼로그: `del_btn.setDefault(True)`, `cancel_btn.setAutoDefault(False)`
