## 1. 배경과 목표

- 미니앱 주머니에는 개발자 제공 앱 2개(단위 환산기, 날짜·시간 계산기)와 `곧 출시 예정` 칸 2개가 있다. 사용자는 현재 주머니가 투박하다고 평가했다.
- 현재 주머니의 문제는 네 가지다.
  - 광택 3D 생성 PNG와 평면 선 아이콘의 스타일이 섞여 있다.
  - 모든 칸이 같은 연파랑 배경과 테두리를 반복해 무겁다.
  - 점선 예정 칸이 절반을 차지한다.
  - 머리부의 색 띠와 테두리 닫기 버튼, 11px 굵은 글씨가 답답하다.
- 이번 결정은 두 가지다.
  - 세 번째 미니앱으로 **금액·숫자 표기 도우미**(공문서 금액 한글 병기, 억·만 읽기, 금액 단위 환산)를 추가한다.
  - 주머니를 **A안 앱 런처**(테두리 없는 타일, 앱별 색 아이콘)로 바꾼다.
- 목표는 예산·회계·계약 업무의 금액 표기 오류를 줄이고, 주머니를 가볍고 앱끼리 구분되는 모양으로 바꾸는 것이다.

### 4.4 유지하는 동작 계약

- `pocket_position()`의 오른쪽 우선, 왼쪽 대체, 작업 영역 보정, 12px 간격을 유지한다.
- 재클릭, 바깥 클릭, 그림자 여백 클릭, Esc, 닫기로 닫힌다. 원래 버튼으로 클릭을 재전달하지 않는다(`WA_NoMouseReplay`).
- 열 때 닫기 버튼에 포커스를 둔다. Tab으로 이동하고 Space·Enter로 실행한다. 닫을 때 이전 포커스를 복원한다.
- 준비 중 칸은 클릭, 키보드 실행, Tab 이동을 막는다. 실제 앱이 추가되면 순서대로 대체한다. 앱이 5개 이상이면 2열 세로 스크롤이다.
- 일정 편집 저장에 실패하면 열기를 보류한다. 잠금, 트레이, 사이드바 숨김, 크기·화면 변경, 초기화, 종료 때 정리한다. 열림 상태는 저장하지 않는다.

## 5. 2단계: 금액·숫자 표기 도우미

### 5.1 계산 모듈 (`money_notation.py`, Qt·DB 접근 없음)

```python
LIMIT = 10**16                      # 1경. 모든 모드의 절댓값 상한(미만)
MONEY_UNITS = (("won", "원", 1), ("k", "천원", 10**3), ("m", "백만원", 10**6),
               ("eok", "억원", 10**8), ("jo", "조원", 10**12))

class NotationError(ValueError): ...           # 사용자에게 보여 줄 한국어 메시지

def parse_integer(text: str) -> int              # 5.2
def parse_decimal(text: str) -> Decimal          # 5.2
def official_hangul(n: int) -> str               # 5.3, 1 ≤ n < LIMIT
def official_amount(n: int) -> OfficialAmount    # digits, hangul, text
def group_notation(n: int) -> str                # 5.4 '12억 3456만 7898'
def reading_hangul(n: int) -> str                # 5.4 '십이억 삼천사백오십육만 칠천팔백구십팔'
def round_half_up(n: int, unit: int) -> int      # 절댓값 사사오입, 부호 유지
def read_number(n: int, scope: str, unit_text: str) -> Reading   # scope: all/man/eok
def convert_money(value: Decimal, src: str) -> dict[str, Decimal]  # 5.5 정확 값
def format_decimal(value: Decimal, digits: int | None) -> str      # 5.5 표시 전용
```

- 금액과 정수는 `int`, 환산은 `decimal.Decimal`만 쓴다. `float`는 쓰지 않는다.
- 반올림은 `ROUND_HALF_UP`을 절댓값에 적용한다. Python 내장 `round()`의 은행가 반올림은 쓰지 않는다.
- 함수는 입력을 바꾸지 않는 순수 함수이며 결과는 불변 dataclass로 돌려준다.

### 5.2 입력 검증

- 앞뒤 공백만 제거한다. 부호는 맨 앞의 `-` 또는 `−`(U+2212)만 받는다.
- 정수 본문은 `\d+` 또는 `\d{1,3}(,\d{3})+`이다(ASCII 숫자). 쉼표 묶음이 틀린 `1,2,3`, 내부 공백, 전각 숫자, 문자는 거부한다.
- 소수 본문은 정수 본문 뒤의 `.\d{1,6}`이다(소수 6자리까지). 단위 환산에만 허용한다.
- 잘못된 값은 보정하지 않는다. `NotationError` 메시지를 오류 줄에 표시하고, 결과는 `—`로 둔다. 복사, 기록, 복사 미리보기는 모두 무효화한다.

| 경우 | 메시지 |
|---|---|
| 빈 값 | `값을 입력하세요.` |
| 형식 오류 | `숫자와 세 자리 쉼표만 입력할 수 있습니다.` |
| 정수 모드의 소수 | `정수만 입력할 수 있습니다.` |
| 단위 환산의 소수 7자리 이상 | `소수는 6자리까지 입력할 수 있습니다.` |
| 큰 수 읽기의 단위 9자 이상 | `단위는 8자까지 입력할 수 있습니다.` (입력 칸 최대 길이 8로 평소에는 막힘) |
| 금액 0 이하 또는 1경 이상 | `금액은 1원 이상 1경 미만이어야 합니다.` |
| 큰 수·환산 결과의 절댓값 1경 이상 | `절댓값 1경 미만까지 지원합니다.` |

### 5.3 ① 금액 표기

- 근거는 「행정업무의 운영 및 혁신에 관한 규정 시행규칙」 제2조다. 금액은 아라비아 숫자로 쓰되 숫자 다음에 괄호를 하고 한글로 적는다. 예: `금113,560원(금일십일만삼천오백육십원)`.
- 한글은 네 자리 묶음마다 천·백·십·일 자리를 읽는다.
  - **모든 자리에 '일'을 적는다.** 예: 일십, 일백, 일천, 일만, 일억.
  - 0인 자리와 0인 묶음(만·억·조)은 생략한다.
  - 공백 없이 붙여 쓴다. 금액은 변조를 막기 위해 붙여 쓰는 것이 관례다(국립국어원 답변).
- 결과 카드
  - 주 결과: `금113,560원`
  - 보조: `(금일십일만삼천오백육십원)` 14px 굵게
  - 주석: `읽기: 십일만 삼천오백육십 원`(5.4 읽기 규칙)
- 복사 형식

| 형식 | 예 |
|---|---|
| 공문서 병기 | `금113,560원(금일십일만삼천오백육십원)` |
| 한글만 | `금일십일만삼천오백육십원` |
| 숫자만 | `113,560` |

### 5.4 ② 큰 수 읽기

- **억·만 표기**
  - 한글 맞춤법 제44항 예시 형식(`12억 3456만 7898`)을 따른다. 묶음 안에는 쉼표를 넣지 않는다(승인 시안의 `3,450만`에서 변경).
  - 0인 묶음은 생략한다(`10억`, `1만`, `5`). 음수는 `−`, 0은 `0`이다.
- **한글 읽기**
  - 만 단위로 띄어 쓴다(제44항).
  - 십·백·천 앞의 '일'은 생략하고, 만 묶음 값이 1이면 `만`으로 읽는다. 예: 10000 → `만`, 110000 → `십일만`.
  - 억·조 묶음 값 1은 `일억`, `일조`로 읽는다. 0은 `영`, 음수는 앞에 `마이너스`를 붙인다.
- **단위(선택)**
  - 최대 8자, 앞뒤 공백을 제거한다.
  - 아라비아 표기 뒤에는 붙이고(`12억 3456만원`), 한글 읽기 뒤에는 띄운다(`… 만 원`). 제43항이 근거다.
- **표시 범위**

| 범위 | 계산 | 주 결과 예 (1,234,567,890원) |
|---|---|---|
| 전체 자리 | 그대로 | `12억 3456만 7890원` |
| 만 단위까지(반올림) | `round_half_up(n, 10**4)` | `약 12억 3457만원` |
| 억 단위(소수 1자리) | `round_half_up(n, 10**7)`를 억으로 나눠 소수 1자리 | `약 12.3억원` |

- 반올림으로 값이 바뀌면 주 결과 앞에 `약`을 붙이고, 주석에 원래 값(`1,234,567,890원`)을 표시한다. 한글 읽기도 반올림된 값을 읽는다.
- 복사 형식은 억·만 표기, 한글 읽기, 숫자만 세 가지다. 숫자만은 원래 값을 쉼표 형식으로 복사하고, 음수 부호는 스프레드시트 호환을 위해 ASCII `-`를 쓴다.

### 5.5 ③ 금액 단위 환산

- 입력은 값(소수·음수 허용), 입력 단위, 결과 단위, 소수 자릿수(자동, 0, 1, 2, 3)다.
- 계산은 `원 = 값 × 배수`이고 각 단위 값은 `원 ÷ 배수`다. `Decimal`로 정확히 계산한다(10의 거듭제곱이므로 유한 소수).
- 5행 표에는 다섯 단위의 **정확한 값**을 쉼표 형식으로, 끝의 0을 제거해 표시한다. 결과 단위 행은 강조한다. 폭을 넘는 값은 말줄임하고 툴팁에 전체 값을 둔다.
- 주 결과는 결과 단위 값을 소수 자릿수에 맞춰 **표시할 때만** 반올림한다(ROUND_HALF_UP).
  - 자동은 정확한 값을 쓰되 소수 6자리를 넘으면 6자리에서 반올림한다.
  - 보조 줄은 `= 1,234,567천원`, 주석은 `표시만 소수 2자리 반올림 · 표는 정확한 값`이다.
- 음수는 `−`로 표시한다.
- 복사 형식

| 형식 | 예 |
|---|---|
| 결과 값 | `12.35억원` |
| 전체 단위 목록 | `원\t1,234,567,000` 등 5줄(정확한 값) |
