## 한 줄 요약

공휴일이 다가오면(첫날 3일 전부터 마지막 날까지) 기후노트가 그 날의 분위기 옷을 자동으로 입는다. 캘린더 머리줄, 오늘 칸, D-Day 커버, 스티키 머리띠, 집중 위젯 바탕이 공휴일 색과 장식으로 바뀌고, 집중 위젯의 토마토는 공휴일 모자를 쓴다. **화면에만 입히며 아무것도 저장하지 않는다.**

## 사용자 결정 (확정)

- 시안 B안 "옷 갈아입기"를 채택한다. A안(남색 유지 + 가장자리 장식)은 쓰지 않는다.
- 대상 공휴일은 13개다. 대체공휴일을 포함한다.
  - 신정, 설날, 삼일절, 노동절, 어린이날, 부처님오신날, 현충일, 제헌절, 광복절, 추석, 개천절, 한글날, 기독탄신일
- 날짜는 `holidays.py`의 자료만 쓴다. 음력 공휴일도 계산하지 않는다.
- 보이는 기간은 첫날 3일 전부터 당일까지다. 다음 날에는 사라진다.
- 겹치는 날의 규칙은 사용자가 맡겨 이 문서에서 정한다(아래 '판정 규칙').
- 집중(포모도로) 위젯의 토마토는 공휴일마다 모자를 쓴다. 크리스마스에는 산타 모자를 쓴다.
- 크리스마스이브(12/24)는 공휴일 자료에 없으므로 따로 넣지 않는다. 기독탄신일 3일 전 규칙으로 12/22부터 보인다.

## 설정 스위치 (사용자 확정 2026-11-01)

사용자가 테마를 끌 수 있게 설정창에 스위치를 둔다.

- 위치: 설정 → **화면 표시** 패널의 마지막 행 `음력 및 공휴일` 바로 아래에 `공휴일 테마` 행을 더한다. 기존 마지막 행에 구분선을 더하고 새 행은 구분선 없이 끝낸다.
- 컨트롤: 기존 `_make_switch()` 스위치. 툴팁 "공휴일 3일 전부터 캘린더와 위젯에 그날 분위기를 입힙니다."
- 저장: 새 `app_settings` 키 `holiday_theme_enabled`, 값 `"1"`/`"0"`. 키가 없으면 켜짐(`get_setting(..., "1")`)으로 본다. DB 버전을 올리거나 마이그레이션으로 키를 미리 넣지 않는다. 기존 키는 그대로 둔다. 다른 설정과 같이 Export/Import에 포함된다(구 EXE는 모르는 키를 무시한다).
- 동작: 끄면 즉시 모든 테마 색·장식·모자·인사말을 걷고 애니메이션 타이머를 멈춘다. 켜면 오늘 날짜로 다시 판정해 적용한다. 앱을 다시 켜도 상태를 유지한다.
- 창 크기는 **800×560 그대로**다. 실측 결과(실제 Qt 코드, 합성 데이터, 2026-11-01):
  - 지금 내용 높이 549px, 창 560px → 남는 높이 11px. 행 하나(41px)를 그냥 더하면 왼쪽 열이 506px가 되어 줄이 눌린다. 과거 버튼 겹침 회귀와 같은 원인이다.
  - 하단 바에 스위치를 넣으면 제작자 문구가 필요한 폭보다 2px 좁아져 잘린다.
  - 창을 600px로 키우면 1366×768·125% 노트북(작업 영역 약 574px)에서 화면을 넘는다.
  - 채택: **왼쪽 열(화면 표시·위젯·도구)의 40px 행을 36px로** 줄인다. `화면 위치`(60px)와 `캘린더 크기` 행은 그대로다. 오른쪽 열과 하단 바는 바꾸지 않는다. 이때 왼쪽 열은 자연 높이 478px로 하단 바 위에서 끝난다(9px 여유).
  - 확인 그림: [현재](2026-11-01-holiday-theme/settings-current.png), [변경안](2026-11-01-holiday-theme/settings-holiday-theme-row.png) — 둘 다 실제 `SettingsWindow`를 2배율로 렌더했다. 변경안은 소스를 고치지 않고 테스트 안에서 행을 더해 그렸다.

## 사용자에게 보이는 동작

### 언제 보이나

- 앱이 켜져 있는 동안 오늘 날짜로 판정한다. 시작할 때, 그리고 자정을 넘길 때 다시 판정한다.
  - 기존 자정 처리 지점: `MainCalendarWindow._check_day_rollover()`(보이는 중), `_sync_to_today_if_changed()`(트레이에서 다시 보일 때)
- 공휴일 묶음의 첫날 3일 전부터 마지막 날(대체공휴일 포함)까지 보인다.
  - 예: 설날 2027-02-06~02-09(대체) → 02-03부터 02-09까지
  - 예: 한글날 2027-10-09 + 10-11(대체) → 10-06부터 10-11까지. 사이의 일요일 10-10도 보인다.
- 인사말 한 줄(스케줄 머리 오른쪽)은 공휴일 묶음의 첫날~마지막 날에만 보인다. 3일 전 예고 기간에는 장식과 색만 보인다(구현자 재량이 아닌 이 문서의 결정).
- 공휴일 자료가 끝난 해(`holidays.holiday_last_year()` 이후)에는 테마가 나오지 않는다. 기존 자료 만료 안내(`holiday_notice.py`)는 그대로 둔다.
- 테마는 **오늘 날짜**로만 정한다. 사용자가 다른 달로 넘겨 보아도 머리줄 등은 오늘의 테마를 유지한다.
- 공휴일 칸 바탕·점은 지금 고른 테마 묶음의 날짜(당일·대체공휴일)에만 칠한다. 같은 달의 다른 공휴일은 기존처럼 빨간 글자만 쓴다.

### 무엇이 바뀌나

| 위치 | 테마 없음(현재) | 테마 적용 |
|---|---|---|
| 캘린더 머리줄 | `#01295F` 남색 | 공휴일 머리줄 색 + 장식 + 움직임 |
| 오늘 칸 (기본: 칸 채움, 중간·크게: 숫자 원) | `#01295F` | 공휴일 오늘 색 |
| 공휴일 칸(당일·대체공휴일, 오늘 제외) | 빨간 숫자·이름 | 그대로 + 연한 공휴일 바탕 + 오른쪽 위 6px 점(강조색) |
| 일정 머리 오른쪽 | 없음 | 인사말 11px 굵게, 강조색 (공휴일 당일에만) |
| D-Day 커버 | 사용자가 고른 커버색 | 공휴일 커버색 + 장식 (저장색은 그대로) |
| 스티키 머리띠(도구줄) | `STICKY_HEADER_COLORS` | 공휴일 무늬 띠 + 아이콘 색 변경. 본문 바탕색·글은 그대로 |
| 스티키 오른쪽 아래 | 없음 | 공휴일 스티커 56px, -6° 기울임 |
| 집중 위젯 바탕 | 흰→`#EEF6FF`→`#DDE8FF` | 흰→공휴일 연한색→공휴일 끝색 (`normal` 상태만) |
| 집중 위젯 토마토 | 기본 토마토 | 공휴일 모자 (접힌 상태·펼친 상태 모두) |

- 바꾸지 않는 것: 일정 3색, 메모 글과 서식, 체크박스, 집중 진행 고리·퍼센트의 토마토 빨강(`#FF5A45`), 요일 색, 일정 목록, 설정창, 최초 크기 선택 화면, 미니앱 창, 잠금 화면.
- 집중 위젯의 `complete`·`break` 상태 바탕은 기존 그대로 둔다.
- 현충일은 추모일이다. 움직임과 축제 장식이 없고, 조기와 흰 국화만 쓴다. 토마토는 모자 대신 흰 국화를 꽂는다. 인사말은 "희생하신 분들을 기억합니다".

### 크기별

- 기본·중간·크게 모두 같은 규칙과 색을 쓴다. 시안은 기본 크기만 그렸다.
- 중간·크게의 머리줄은 폭이 달라서, 장식 위치는 고정 px이 아니라 실제 버튼 묶음 사이의 빈 곳으로 정한다. 기본 크기 380px 머리줄 기준으로 빈 곳은 x 77~135, 245~290, 위 띠 y 0~20, 아래 띠 y 50~70이다.
- 크게 보기의 오른쪽 패널(D-Day 미니 카드, 스티키 패널, 집중 패널)도 같은 색 규칙을 따른다. 집중 패널(`ui_focus_panel.py`)에는 토마토 그림이 없으므로 바탕만 바꾼다.

### 하나만 고르기 (겹침)

오늘을 기간에 포함하는 묶음이 둘 이상이면 다음 순서로 하나만 고른다.

1. 진행 중(첫날 ≤ 오늘 ≤ 마지막 날)인 묶음
2. 진행 중이 없으면 첫날이 더 가까운 묶음
3. 그래도 같으면 연휴가 긴 묶음(마지막 날 - 첫날이 큰 쪽)
4. 그래도 같으면 위 표의 순서

### 함수 모양 (권장)

```python
@dataclass(frozen=True)
class HolidayThemeMatch:
    key: str            # 'christmas' 등
    first_day: date
    last_day: date
    in_holiday: bool    # 첫날~마지막 날이면 True (인사말 표시 여부)

def resolve_holiday_theme(today: date, holidays: Mapping[str, str]) -> HolidayThemeMatch | None: ...
```

`holidays`에는 `holidays.KOREAN_HOLIDAYS`를 넘긴다. 테스트에서는 작은 가짜 표를 넘긴다.

## 그리기·자원 규칙

- 장식은 `resources/holiday_themes/<키>/` 아래 SVG로 두고 `app_paths.resource_root()`로 찾는다. `__file__` 경로를 새로 쓰지 않는다.
- QtSvg Tiny 범위만 쓴다. 필터·`clipPath`·마스크·CSS·외부 참조·비트맵 삽입·`paint-order`는 Qt에서 그려지지 않는다(앱 아이콘에서 `clipPath`가 안 그려진 전례가 있다). 시안의 흰 테두리 스티커는 테두리 도형을 따로 그려 만든다. 그림자는 `QGraphicsDropShadowEffect`를 쓰거나 생략한다.
- 글자 장식(자모, '한' 도장, '한글' 도장, "헌법")은 SVG `<text>`가 아니라 QPainter로 맑은 고딕을 써서 그린다.
- 태극기는 시안에서 간략하게 그렸다. 구현할 때는 국기 규격(태극 문양 방향·괘 위치)에 맞춰 다시 그린다.
- 움직임은 `QVariantAnimation` 또는 `QTimer`로 구현한다. 초당 24프레임 이하로 하고, 창이 숨거나 잠기거나 트레이로 가거나 최소화되면 멈춘다. 다시 보일 때 이어 간다.
- Windows의 '애니메이션 효과' 끄기(`SPI_GETCLIENTAREAANIMATION`)가 꺼져 있으면 움직이지 않고 첫 장면 그대로 둔다.
- 데스크톱 상주 앱이다. 테마 움직임으로 늘어나는 CPU 사용량을 측정해 작업 기록에 남긴다(목표: 유휴 대비 1%p 이하).
- QSS 글꼴 크기는 정수 px만 쓴다.

## 바꾸지 않는 계약

- DB v19, Export v4, salt, 암호문, 기존 설정 키를 바꾸지 않는다. 테마 적용·해제는 DB에 쓰지 않는다.
  - 유일한 쓰기: 사용자가 설정의 `공휴일 테마` 스위치를 바꿀 때 `holiday_theme_enabled` 한 키를 쓴다.
- D-Day 저장색, 스티키 색·본문 HTML, 일정 본문·색, 집중 세션 기록을 바꾸지 않는다.
- 공휴일 데이터는 `holidays.py`와 `fetch_data.py` 경로만 쓴다. 임의로 계산하지 않는다.
- 런타임은 오프라인이다. 네트워크를 쓰지 않는다.
- 잠금·트레이·숨김·초기화·크기 전환 계약을 그대로 따른다. 테마 장식이 잠금 화면 위에 보이면 안 된다.
- Win+D 보호 동작(바탕화면 고정)과 창 위치 복원에 영향을 주지 않는다.

## 테스트와 검증

- `tests/test_holiday_theme.py`: 위 테스트 벡터 전부, 붙은 이름(`어린이날·부처님오신날`, `개천절·추석`), 이름 없는 대체공휴일 무시, 7일 묶음, 자료 끝 이후 없음, 겹침 규칙 1~4.
- 표시 전용 계약: 테마를 적용·해제·전환해도 `database`의 쓰기 함수가 호출되지 않음(D-Day `update_dday_widget`, 스티키 저장 등)을 확인한다.
- UI(offscreen): 기본·중간·크게 세 크기에서 테마 적용 → 해제 시 원래 색으로 돌아옴, 자정 넘김으로 테마가 바뀜, 숨김·잠금 시 애니메이션 타이머 정지, 현충일은 타이머가 없음.
- 모자 렌더: 접힌 38px·펼친 50px 토마토, 배율 100/125/150%에서 모자가 잘리지 않고 머리 위에 놓이는지 확인한다.
- 설정창: `SettingsWindow().layout().minimumSize().height() <= 560`을 단언하고, 왼쪽·오른쪽 열이 자연 높이(sizeHint) 그대로 배치되는지(눌리지 않는지) 확인한다. 렌더 이미지를 확대해 스위치·콤보가 행 구분선을 넘지 않는지 눈으로 본다. 스위치 끄기/켜기가 키 하나만 쓰고 화면에서 테마를 즉시 걷는지 확인한다. 테스트 통과만으로 레이아웃 무결을 판단하지 않는다(과거 회귀 교훈).
- 명령: UI 변경은 `quick --tests <관련 파일>`, 여러 화면 모듈을 건드리므로 마지막에 `full`, 배포 EXE는 `release`. 실행 ID와 `summary.md`를 작업 기록에 남긴다.
- 날짜 주입: 화면 코드는 오늘 날짜를 한 곳(예: `holiday_theme.current_match(today=None)`)에서만 얻는다. 테스트는 이 함수를 패치해 테마 기간의 날짜를 넣는다. 배포 EXE에 날짜를 바꾸는 숨은 옵션·환경 변수를 넣지 않는다.
- 수동 확인: 테스트 PC의 시스템 날짜를 테마 기간으로 바꾸거나, 개발 실행(`python main.py`)에서 위 함수를 패치한 실행 스크립트로 본다. 합성 데이터만 쓴다. 혼합 DPI, Win+D, 트레이 복귀, 한글 IME 입력 중 장식이 방해하지 않는지 본다.

## 이 문서에서 정한 것 (사용자 확인 전 내 판단)

- 여러 날 공휴일의 보이는 기간은 대체공휴일을 포함한 마지막 날까지로 했다.
- 겹침 규칙 1~4와 그 결과(2028년 개천절 미표시 포함)
- 인사말은 공휴일 당일에만, 3일 전 예고 기간에는 장식·색만 보여 준다.
- 공휴일 칸 표시는 13개 모두 같은 규칙(연한 바탕 + 6px 점)으로 통일했다. 시안의 일부 칸에 있던 개별 아이콘은 쓰지 않는다.
- 진행 고리·퍼센트는 토마토 빨강을 유지한다.
- 기본·중간·크게 모두 적용한다.
- Windows 애니메이션 끄기 설정을 따른다.
- 설정 스위치의 키 이름(`holiday_theme_enabled`), 기본값 켜짐, 위치(화면 표시 마지막), 왼쪽 열 행 36px로 자리 만들기.
