# D-Day 플로팅 위젯 가시성 개선 (그림자 + 헤어라인) — 설계

- 날짜: 2026-07-04
- 대상: `기후노트` (MyDesktopCalendar), v3.2 검증 단계
- 상태: 설계 승인 완료 → 구현 계획(writing-plans) 대기
- 관련 코드: `ui_dday.py`, (스펙 갱신) `AGENTS.md`, (테스트) `tests/`

## 1. 문제 (Problem)

D-Day 플로팅 위젯은 진한 커버색 단색 배경 + 흰 타이포의 **Cover Tint** 디자인이며,
현재 의도적으로 **테두리 없음 · 그림자 없음 · 플랫**이다.

바탕화면 색이 강하고(예: 코발트 블루) 커버색과 색상·명도가 가까운 경우
(특히 하늘색 커버 `#46679C` on 파란 배경) 카드 경계가 사라져 **위젯이 배경에 묻힌다.**
2026-07-04 실측 스크린샷(우측 모니터, 강한 파란 바탕화면)에서 파란 계열 D-Day 카드가
배경과 뭉개지는 현상 확인됨.

## 2. 목표 / 비목표 (Goals / Non-Goals)

**목표**
- **어떤 바탕화면에서도** D-Day 플로팅 위젯이 배경에서 또렷하게 떠 보이게 한다
  (밝은/어두운/사진/동일 계열 배경 모두).
- 현재 Cover Tint의 진한 단색 + 흰 타이포 정체성은 유지한다.
- 기존 데이터(위젯 좌표·색)와 기존 동작(드래그·자동정렬·투명도·Win+D 유지)을 보존한다.

**비목표**
- 미니 D-Day 카드(`ui_dday_panel.py`)는 **대상 아님**. `large` 모드 미니 패널은
  배경이 흰색(`#ddaySidePanel: #FFFFFF`)이라 진한 커버 카드가 이미 충분히 대비되어
  묻힘 문제가 없다. (통일감용 옅은 그림자는 추후 선택 사항.)
- 스티키·집중 위젯은 대상 아님.
- 새 설정 토글/사용자 옵션 추가 없음(항상 적용).

## 3. 설계 결정 (Decision)

**"플로팅 카드" 처리 = 소프트 드롭 섀도우(주) + 옅은 흰 헤어라인(보조).**

- **드롭 섀도우**: 배경색과 무관하게 카드를 깊이감으로 배경에서 떼어낸다.
  밝은/중간/동일 계열 배경을 커버한다.
- **옅은 흰 헤어라인**: 어두운(거의 검정) 배경에서 어두운 그림자가 묻힐 때
  가장자리 광택으로 분리를 보장한다. 밝은 배경에서는 거의 보이지 않아 무해하다.
- 두 요소의 합이 "어떤 바탕화면에서도"라는 목표를 충족한다.

### 대안과 기각 사유
- **테두리(단색 선)만**: 고정색 테두리는 배경이 그 색에 가까우면 테두리마저 묻힌다
  — 지금 문제의 재발. 목표(배경 무관)와 정면 충돌하여 기각.
- **창 크기 유지 + 카드를 안쪽으로 축소해 그림자 공간 확보**: 카드가 작아지거나
  텍스트가 가장자리에 붙어 미관 저하. 기각.
- **좌표 규약을 "카드 모서리"로 바꾸고 보정**: 자동정렬 공용 코드까지 손대야 하며
  위험 대비 이득이 없어 기각(아래 4.3 참조).

## 4. 상세 설계 (Detailed Design)

### 4.1 시각 처리 값 (초기값, 실측 스크린샷으로 최종 튜닝)
- 그림자: color `rgba(0,0,0,90)`, blurRadius `≈10`, offset `(0, 3)`.
- 헤어라인: 커버 가장자리 1px, `rgba(255,255,255,45)`.
  - 어색하면 alpha `0`으로 제거 가능(그림자만으로도 대부분 배경 커버).
- **불변식**: 그림자 여백 `M` ≥ `blurRadius + |offset.y|` 이어야 그림자가
  창 경계에서 잘리지 않는다. (초기값 14 ≥ 10 + 3.)

### 4.2 그림자 공간 확보 (핵심)
현재 창은 카드와 크기가 동일하다: `setFixedSize(WIDGET_WIDTH=220, DDAY_HEIGHT=95)`,
`outer.setContentsMargins(0,0,0,0)`. 창 밖으로 그림자가 번질 투명 여백이 없다.

→ **그림자 여백 `M`(초기값 14px)만큼 창을 키우고, 그 여백을 바깥 레이아웃 마진으로 둔다.**
- 창 크기: `(WIDGET_WIDTH + 2M) × (DDAY_HEIGHT + 2M)` = 초기값 248×123.
- `outer.setContentsMargins(M, M, M, M)`.
- `QGraphicsDropShadowEffect`를 `self.container`에 적용
  (라운드 18px 커버 모양을 따라 그림자가 그려짐).
- 카드 본체(220×95)와 내부 콘텐츠 마진(`14,10,11,11`)은 **불변**.

### 4.3 좌표 규약: "창 좌표" 그대로 유지 (보정 없음)
드래그(`mousePressEvent`/`mouseMoveEvent`/`mouseReleaseEvent`), 자동정렬
(`ui_main._on_arrange_sticky_notes`), 로드/복원(`move`)이 **모두 이미 창 좌표 기준**이며
DB `x_pos/y_pos`에도 창 좌표를 저장한다. 창을 키워도 이 규약을 그대로 두면
**드래그·자동정렬·DB·ui_main 코드를 한 줄도 바꾸지 않아도 된다**(단일 좌표계 일관성 유지).

**감수하는 유일한 부작용 (승인됨)**
- 기존 배치 위젯이 다음 실행 시 창 좌상단→카드 좌상단이 여백만큼 안쪽으로 들어가
  화면상 **1회성 `M`(≈14px) 이동**으로 보인다. DB 좌표값 자체는 보존되며,
  드래그 또는 자동정렬 1회로 정상화된다.
- 부수 효과(긍정): 화면 끝에 붙여도 그림자가 잘리지 않는 여백이 생기고,
  자동정렬 시 카드 사이에 그림자가 겹치지 않는 자연스러운 간격이 생긴다.

### 4.4 손대는 파일
- **`ui_dday.py`** (유일한 코드 변경):
  - `DDayWidgetWindow`: 창 크기 `+2M`, `outer.setContentsMargins(M,M,M,M)`,
    `QGraphicsDropShadowEffect` 적용, 헤어라인 QSS(`#ddayContainer` border 1px 반투명 흰색).
  - 그림자 여백 상수 `SHADOW_MARGIN`(모듈/클래스 상수) 정의.
- **`AGENTS.md`**: "D-Day Cover Tint(디자인)" 항목의 **"컨테이너는 테두리 없음"** 문구를
  "**그림자 + 옅은 흰 헤어라인으로 배경에서 분리(플로팅 위젯 한정)**"로 갱신.
  미니 카드는 종전대로 테두리 없음/흰 배경 이음새 규칙 유지임을 명시.
- **`tests/`**: 아래 5절.

### 4.5 보존 확인 (변경 없음)
- Win+D topmost 키퍼: 그림자는 창 내부 Qt 페인팅이라 `SetWindowPos(HWND_TOPMOST)`와 독립.
- 전체 투명도: `setWindowOpacity`는 창 전체(그림자 포함)에 적용 → 카드와 함께 자연스럽게 페이드.
- 5mm 스냅/좌표 저장/레거시 색 매핑(`dday_cover_color`): 영향 없음.
- 미니 D-Day 패널·DB·`ui_main`: 코드 변경 없음.

## 5. 테스트 (Testing)

순수 시각 변경이므로 데이터 왕복 테스트는 불필요. 대신 불변식/회귀 방지:
- `DDayWidgetWindow`의 창 크기 == `(WIDGET_WIDTH+2*SHADOW_MARGIN, DDAY_HEIGHT+2*SHADOW_MARGIN)`.
- 컨테이너에 `QGraphicsDropShadowEffect`(또는 그에 준하는 그림자)가 설정되어 있음.
- 헤어라인 alpha가 0이 아닐 때 `#ddayContainer` QSS에 반투명 흰 border가 존재함
  (또는 상수 기반 검증).
- 미니 카드(`DDayMiniCard`)에는 그림자 효과가 **없음**(스코프 경계 회귀 방지).
- 기존 `tests/test_ui_dday_panel.py` 및 D-Day 관련 테스트 전부 통과.

## 6. 최종 튜닝 노브 (구현 후 실측 스크린샷으로 확정)
