# v3.1 UI 개선 4종 — 설계 문서

- 작성일: 2026-06-11
- 대상 버전: v3.0 → v3.1
- 구현 주체: codex (단계별 계획서는 `docs/superpowers/plans/`에 별도 작성)

## 개요

사용자 요청 4건을 한 묶음으로 처리한다.

1. 집중 모드 위젯을 **1개만** 띄울 수 있게 개수 제한.
2. '크게(large)' 캘린더 모드에서 풀스크린 달력에 가려지는 **스티키 노트를 우측 패널에 편집 가능한 미니 카드로** 표시.
3. 설정창 섹션 헤더(`화면 표시`, `데이터` 등)가 회색 창 배경에서 잘 안 띄는 문제 → **대비를 키워 또렷하게**.
4. 왼쪽 바로가기 사이드바 슬롯을 **5개 → 6개**로 확장.

공통 원칙(`AGENTS.md` 준수):
- 기존 사용자 데이터 보존. 스키마는 `ALTER`/`INSERT OR IGNORE`만, `migrate()` 버전 증가.
- DB 접근은 `database.py`의 `_connection()` 경유. 직접 `sqlite3.connect()` 금지.
- 스티키 본문은 `security.py` 경유 암호화 유지(`update_sticky_note`가 이미 처리).
- QSS `font-size`는 정수 px만.
- 데이터 변경 기능에는 `tests/` 왕복 검증 추가.

## 기능 1 — 집중 위젯 1개 제한

### 현재 상태
- `ui_main.py` `_on_new_focus_widget` (≈L1909): `open_count >= 5`이면 InfoBar 경고 후 반환. 메시지 "집중 모드는 최대 5개까지 생성할 수 있습니다."
- `offset = open_count * 30`으로 신규 창 위치를 겹치지 않게 띄움.
- `_load_open_focus_widgets`는 `db.get_open_focus_widgets()`가 돌려주는 모든 열린 위젯을 로드.

### 변경
- 생성 제한: `>= 5` → `>= 1`. 메시지를 "집중 모드는 1개만 사용할 수 있습니다."로 변경.
- `offset`은 0이 되어도 무방(별도 수정 불필요).
- 로드 정합성: `_load_open_focus_widgets`에서 열린 위젯이 2개 이상이면 **첫 1개만** 창으로 띄우고, 나머지는 `db.update_focus_widget(id, is_open=0)`으로 닫힘 처리한다(세션 기록·데이터는 보존, 창만 안 띄움). 과거 버전에서 여러 개를 열어 둔 상태를 매끄럽게 수습하기 위함.

### 영향 범위
- `ui_main.py`만. DB 스키마 변경 없음.

### 검증
- `tests/test_ui_focus.py`(또는 신규): 1개 생성 후 2번째 생성 시도가 거부되는지. 로드 시 2개 이상이 들어와도 1개만 표시되고 나머지가 `is_open=0`이 되는지.

## 기능 2 — '크게' 모드 우측 패널 미니 스티키 (편집 가능)

### 배경 / 현재 구조
- 캘린더 스케일: `compact` / `medium` / `large` (`SETTING_CALENDAR_SCALE`). `expanded = scale != "compact"`.
- 확장 모드 레이아웃은 `[좌: 바로가기 사이드바 / 중앙: 큰 달력(헤더+캘린더 섹션) / 우: 일정 패널]`.
- 우측 일정 패널은 `_reparent_schedule_panel(expanded)`에서 `self._expanded_row`(QVBoxLayout)로 옮겨진다 (`ui_main.py` ≈L784).
- 스티키 노트는 독립 프레임리스 창(`StickyNoteWindow`)으로, `self._sticky_windows: {note_id: win}`에 보관. `large`에서 풀스크린 달력(화면−40px)이 이 창들을 덮어 가린다.

### 동작 모델 (선택 확정: 편집 가능 미니 스티키 / large 모드일 때만)
`large` 진입 시 플로팅 스티키 창을 **숨기고**, 우측 컬럼에 동일 노트들을 **편집 가능한 미니 카드**로 띄운다. `large`를 벗어나면 미니 카드 내용을 DB에 저장 → 플로팅 창에 재반영 → 플로팅 창 복원. 한 노트는 한 시점에 한 곳(가려진 창은 숨김·미편집)에서만 편집되므로 동기화 충돌이 없다.

표시 조건: **`scale == "large"`일 때만.** `medium`은 현행 유지(플로팅 창 그대로, 미니 패널 없음).

### 신규 모듈 `ui_sticky_panel.py`

#### `StickyMiniCard(QWidget)`
- 입력: `note_id`, `content`(HTML/plain), `color`.
- 구성: 상단 색상 스트립(노트 배경색 / `STICKY_HEADER_COLORS` 매핑 재사용) + 본문 `_TodoTextEdit`(ui_sticky에서 import → 체크박스 토글·dim+취소선 동작 그대로 상속).
  - `content.strip().startswith("<")`면 `setHtml`, 아니면 `setPlainText` (StickyNoteWindow와 동일 규칙).
- 자동 저장: `textChanged` → 2초 디바운스 → `db.update_sticky_note(note_id, content=self.text_edit.toHtml())`.
- 공개 API: `save()`(디바운스 무시 즉시 저장), `note_id` 속성.
- 카드 외형은 우측 일정 패널과 통일감 있게(흰 배경 카드 + 색상 스트립). 높이는 내용 기반 최소 높이 + 신축.

#### `StickySidePanel(QWidget)`
- 제목 라벨 "스티키 노트" + 스크롤 영역(`QScrollArea` 또는 qfluent `SmoothScrollArea`) 안에 `StickyMiniCard` 세로 스택.
- `reload()`: 기존 카드 제거 후 `db.get_open_sticky_notes()`로 카드 재구성. 노트가 없으면 "표시할 스티키 노트가 없습니다" 안내 라벨.
- `save_all()`: 모든 카드 `save()`.
- 스타일: 우측 일정 패널과 동일한 카드 톤(흰 배경, 1px 테두리, 라운드).

### `ui_main.py` 통합

상태 필드 추가: `self._sticky_side_panel = None`, `self._sticky_in_panel_mode = False`.

#### 우측 컬럼 배치
- `_expanded_row`(QVBoxLayout)에 [상: 일정 패널 / 하: 스티키 패널]을 **동일 stretch(1:1)로 스택**한다. (드래그 리사이즈가 필요한 QSplitter는 `_reparent_schedule_panel`의 패널 재부모화 로직과 얽혀 회귀 위험이 커서, 구현 안정성을 위해 단순 스택을 채택. 비율 조절은 후속 과제.)
- `large`가 아닐 땐 스티키 패널을 `_expanded_row`에서 제거(`removeWidget` + `setParent(None)` + `hide()`)해 일정 패널이 컬럼 전체를 차지한다.
- `_reparent_schedule_panel(expanded)`는 현행 유지(일정 패널을 `_expanded_row` 첫 위젯으로 추가). 스티키 패널 부착/제거는 신규 `_apply_sticky_side_panel(large)`가 전담.

#### 모드 전환 로직 (`_apply_calendar_scale` 또는 신규 `_apply_sticky_side_panel(large: bool)`)
- `large = (scale == "large")` 계산.
- **large 진입** (`not self._sticky_in_panel_mode and large`):
  1. 모든 플로팅 스티키: `win.save()` 후 `win.hide()`.
  2. `StickySidePanel` 없으면 생성, 있으면 `reload()`. splitter에 부착·표시.
  3. `self._sticky_in_panel_mode = True`.
- **large 이탈** (`self._sticky_in_panel_mode and not large`):
  1. `self._sticky_side_panel.save_all()`.
  2. 패널 splitter에서 숨김.
  3. 각 플로팅 창 내용 DB에서 재로드: `win.text_edit.setHtml(db에서 읽은 content)` 후 `win.show()`. (메인 창이 트레이로 숨겨진 상태가 아니면 표시)
  4. `self._sticky_in_panel_mode = False`.
- 호출 위치: `_apply_calendar_scale` 끝부분(스케일 반영 직후)에서 호출.

#### 신규 스티키 생성 시 (`_on_new_sticky_note`)
- 생성 후, `self._sticky_in_panel_mode`면 새 플로팅 창을 `hide()`하고 `self._sticky_side_panel.reload()`로 미니 카드에 노출. 아니면 현행대로 `show()`.

#### 기존 핸들러 가드 (회귀 방지)
- `toggle_visibility()` / `_minimize_to_tray()`: 패널 모드에서는 가려진 플로팅 스티키 창을 다시 `show()`하지 않는다(`if not self._sticky_in_panel_mode`). D-Day·집중 위젯은 현행 유지.
- `save_all_sticky_notes()`(종료 저장): 패널 모드면 `self._sticky_side_panel.save_all()`도 호출. (플로팅 창은 숨김 상태라 `if win.isVisible()` 가드로 자동 skip → 미니 카드 저장이 정본.)
- `_restore_sticky_note()`(휴지통 복구): 패널 모드면 복구된 창을 숨기고 `reload()`.

### 영향 범위
- 신규: `ui_sticky_panel.py`.
- 수정: `ui_main.py`(레이아웃·모드 전환·핸들러 가드), `ui_sticky.py`(`_TodoTextEdit`/색상 매핑 재사용을 위한 import 노출 — 이미 모듈 전역이라 추가 변경 거의 없음).
- DB 스키마 변경 없음(기존 `sticky_notes`·`update_sticky_note` 사용).

### 검증
- `tests/`: large 진입 시 플로팅 창 숨김 + 패널 카드 N개 생성, 카드 편집 → DB 반영, large 이탈 시 플로팅 창 내용이 DB값으로 복원되는 왕복 테스트. (pytest-qt)

### 미해결/주의
- 미니 카드는 배경색 변경·서식 버튼(B/색상) 같은 플로팅 창 전체 툴바를 제공하지 않는다(본문 편집 + 체크박스에 집중). 색상 변경 등 고급 편집은 compact/medium에서 플로팅 창으로 수행. (YAGNI)
- 미니 카드에서 노트 삭제(휴지통 이동)는 본 작업 범위에서 제외(읽기/본문편집까지). 필요 시 후속.

## 기능 3 — 설정 헤더 대비 강화

### 현재 상태
- `ui_settings.py` `_make_panel` (≈L211): `StrongBodyLabel`에 objectName `panelHeader`.
- QSS: `#panelHeader{font-size:12px;font-weight:800;color:#01295F;background:#EDF1F6;border-bottom:1px solid #D7DDE5;padding:6px 10px;}`
- 문제: 연한 파랑 배경(`#EDF1F6`) + 남색 글자가 회색 창 + 흰 카드 위에서 약하게 보임.

### 변경
- 헤더를 **꽉 찬 딥 네이비 바 + 흰 글자**로 변경해 대비를 키운다(색상 확정: `#01295F`).
  - QSS: `#panelHeader{background:#01295F;color:#FFFFFF;font-weight:800;font-size:12px;padding:6px 10px;border-top-left-radius:6px;border-top-right-radius:6px;}` (라운드 값은 `CardWidget` 코너에 맞춰 미세 조정 가능, 정수 px 유지).
  - 기존 `border-bottom`은 제거(꽉 찬 바라 불필요).

### 영향 범위
- `ui_settings.py` `_make_panel` QSS 한 곳. 레이아웃·크기(800x560 고정) 불변.

### 검증
- 시각 확인(스모크). 자동화 테스트는 불필요(스타일 문자열 단순 변경).

## 기능 4 — 바로가기 6칸

### 현재 상태
- `ShortcutSidebarWidget.__init__` (≈L616): `for i in range(1, 6)` → 슬롯 5개. 슬롯 간격 `setSpacing(14)`.
- `ShortcutSlot` 고정 크기 `64x82`.
- `load_shortcuts`는 `data["id"] - 1`을 인덱스로 슬롯에 매핑.
- DB 시드: `migrate()` v8 블록(≈L353)에서 `shortcuts` 행 1~5를 `INSERT OR IGNORE`.

### 변경
- 슬롯 수: `range(1, 6)` → `range(1, 7)` (6개).
- 세로 공간 확보: compact 사이드바(창 높이 660) 안에 6슬롯이 들어가도록 `setSpacing(14)` → `setSpacing(10)`으로 약간 축소. (6×82 + 5×10 + 제목/마진 ≈ 600 < 660, 안전 마진 확보)
- DB 마이그레이션 **v15** 신설:
  - `INSERT OR IGNORE INTO shortcuts (id, name, path) VALUES (6, '', '');`
  - `PRAGMA user_version = 15`.
  - 멱등(`INSERT OR IGNORE`), 기존 1~5 데이터 보존.

### 영향 범위
- `ui_main.py`(`ShortcutSidebarWidget`), `database.py`(`migrate()` v15 블록).

### 검증
- `tests/test_database.py`: 기존 v14 DB에서 `migrate()` 실행 후 `shortcuts`에 id=6 존재 + 1~5 값 보존. 두 번 실행해도 멱등.

## 문서 갱신

`AGENTS.md` 관련 제약 문구 갱신:
- 집중 모드: "최대 N개" → "1개 제한" 반영(있는 경우).
- 캘린더/스티키: large 모드의 우측 패널 미니 스티키 동작 추가.
- 설정 레이아웃: `panelHeader` 색상 설명 갱신.
- DB 마이그레이션: "현재 `user_version=14`" → `15`로, v14→v15(바로가기 6번째 시드) 추가.
- Module Map에 `ui_sticky_panel.py` 추가.
- `app_info.py` 버전 `v3.0` → `v3.1` 갱신 여부는 사용자 확인 후 반영(빌드/표시 단일 출처).
