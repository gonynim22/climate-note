# 미니앱 공용 창 틀 설계 (디자인 점검 5번, B안)

작성일: 2026-10-10 / 상태: 사용자 선택(B안 + 고른 메뉴 왼쪽 막대 없음), 바로 구현 지시

## 목표

미니앱 5개(단위 환산기, 날짜·시간 계산기, 금액·숫자 표기, 문서 형식 변환, 화면 글자 따기)가 한 앱처럼 보이도록 창 틀을 하나로 맞춘다. 다음 미니앱도 같은 틀을 가져다 쓴다. 계산·기능·창 크기·키보드·창 수명·데이터는 바꾸지 않는다.

- 사용자 결정: 시안 B(어두운 메뉴). 고른 메뉴의 왼쪽 막대(시안의 3px 띠)는 넣지 않고 지금처럼 선택 바탕만 칠한다. 계획서 작성 뒤 바로 구현.
- 시안: `output/design/miniapp-frame-20261010/frame-concepts.html`(gitignore).

## 공용 틀 (B안)

- **제목줄** `ui_mini_app_frame.MiniAppTitleBar`: 어두운 `#23252B` 바탕, 위 두 모서리 16px. 높이 48px(좁은 화면 40px). 왼쪽부터 앱 아이콘 22px(주머니와 같은 SVG) · 앱 이름 15px 굵게 `#F4F5F2` · 닫기 × 28px(`#C9CED8`, 테두리 없음, hover `#343740`, focus 테두리 `#90ACD0`, 툴팁 "닫기 (Esc)", 접근 이름 "<앱 이름> 닫기"). 제목줄과 그 안의 이름·아이콘을 잡고 끌면 창이 움직인다(기존 창별 끌기 처리 재사용).
- **왼쪽 메뉴**가 있는 앱(환산기·날짜·금액)은 메뉴도 같은 `#23252B`로 제목줄 아래에 이어 'ㄱ'자 틀이 된다. 메뉴 아래 왼쪽 모서리만 16px. 고른 메뉴는 지금 모양 그대로(날짜·금액 `#3C4657`, 환산기 분류별 색). 환산기 메뉴 맨 위의 "▪ 단위 환산" 글자는 제목줄로 옮겨 지운다.
- **메뉴 없는 앱**(문서 변환·글자 따기)은 어두운 제목줄 아래 바로 밝은 본문.
- **본문 바탕** `#FDFDFB`(글자 따기도 `#FFFFFF`에서 맞춘다). 모서리 16px·그림자·창 크기(환산기 440×580, 날짜·금액·문서 480×620, 글자 따기 460×560)는 그대로.
- **강조색**: 앱 색은 제목줄 아이콘에만 쓴다. 주 버튼·포커스·선택 색은 앱 파랑 `#2563EB`. 문서 변환의 보라 계열(버튼 hover/focus·변환 시작·표 머리·진행 막대·'HWP → HWPX' 제목·환경 문구)은 다른 미니앱과 같은 중립·파랑 값으로 바꾼다.
- **체크 색**: Qt 기본 체크박스는 Windows 강조색(측정 PC 청록)으로 칠해진다. `_apply_light_theme()`의 선택 색 팔레트에 `Accent` `#2563EB`를 더한다(7번 선택 색과 같은 원인, 같은 자리).

## 창별 적용

| 창 | 바뀌는 구조 | 유지하는 속성 |
|---|---|---|
| 단위 환산기 | 표면 = 제목줄 + (메뉴 \| 본문). 본문 머리줄은 분류 이름만(닫기 이동) | `title_label`은 분류 이름, `close_button`은 제목줄 닫기, `category_rail`, `surface` |
| 날짜·시간, 금액 | 기존 머리줄(52/40px)을 제목줄(48/40px)로 교체 | `header`·`title_label`·`close_button`·`rail`·`surface` |
| 문서 변환 | 표면 = 제목줄 + 내용(여백 18·12·18·16) | `header`·`title_label`·`surface`, 새 `close_button` |
| 화면 글자 따기 | 표면 = 제목줄 + 내용(여백 18·10·18·16) | `header`·`title_label`·`close_button`·`surface` |

`header`는 제목줄을 가리킨다(끌기·좁은 화면 높이 전환에 쓰는 기존 코드가 그대로 동작). 닫기 버튼은 기존과 같이 창의 eventFilter로 Enter 키 클릭을 받는다.

## 범위 밖

- 메뉴·본문 안 내용 배치, 8번(날짜·시간 체크박스 모양), 20·21번(빈 공간·끌어 놓기 안내), 미니앱 주머니.
- 버전 변경(v3.9a 유지)·빌드·push.

## 데이터와 계약

DB v17·Export v2·salt·설정 키·바로가기 6슬롯·미니앱 메모리 기록·창 수명(잠금/숨김/초기화) 불변. 화면 글자 따기는 핵심 모듈(`ui_mini_app_frame`)을 한 방향으로만 가져다 쓰므로 걷어내기 절차는 바뀌지 않는다.

## 검증

- 새 시험: 다섯 창 모두 제목줄이 표면 맨 위 전체 폭·48px·`#23252B` 픽셀, 아이콘이 비어 있지 않음, 제목 글자·닫기 툴팁·접근 이름, 닫기 클릭·Esc로 닫힘, 제목줄 끌기로 창 이동. 메뉴 앱은 메뉴 바탕도 `#23252B`, 메뉴 없는 앱은 본문 `#FDFDFB`. 문서 변환에 보라 값이 남지 않음. 테마 고정 뒤 팔레트 `Accent` `#2563EB`.
- 기존 시험(크기·무스크롤·경계·좁은 화면·배율·수명) 그대로 통과. 100/125/150% quick, full.
- 전/후 캡처를 시안 페이지 옆에 남긴다.
