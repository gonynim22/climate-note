# 날짜·시간 계산기 계약

v3.8b의 두 번째 개발자 제공 미니앱이다. [A안 계획](work/2026-09-24-date-time-miniapp-plan.md)을 구현하며 실제 검증과 산출물은 [구현 기록](work/2026-09-24-v3.8b-date-time-calculator.md)을 따른다.

## 계산 기준

- 같은 지역의 달력·시계 기준이다. 시간대 변환·DST·윤초·법정 수당·기관별 초과근무 인정 규정을 추정하지 않는다.
- 모든 기간 원본은 정수 초다. 시각은 24시간제 `H:MM`/`HH:MM:SS`, 날짜는 `YYYY-MM-DD`로 전체 입력을 검사한다. 잘못된 값은 보정하지 않고 오류를 표시하며 이전 결과와 복사/기록을 무효화한다.
- `12:00 → 18:59`는 419분·6시간 59분·25,140초다. `18:59:30`까지면 419분 30초를 그대로 표시한다. 분 숫자 복사는 최대 소수 12자리이며, 수학적 내림/올림과 동점에서 0에서 먼 쪽으로 반올림을 별도 선택한다. 복사 정책은 원본을 변경하지 않는다.
- 시간만 입력한 역순은 오류다. 사용자가 `다음 날 종료`를 켜야 자정을 넘긴다. 같은 시각은 0분이며 익일 선택 시 1,440분이다. 날짜를 포함하면 두 날짜와 시각을 직접 비교한다. 날짜 포함·휴게 0분의 일반 차이는 음수 결과를 허용한다.
- 휴게는 기본 0분, 수동 공제다. 음수·전체 구간 초과는 오류다. 근무 구간 합산은 역순을 허용하지 않는다. 여러 행은 각각의 입력 구간을 합하며 겹치는 구간을 자동 병합하지 않는다.
- `날짜 포함 → 시간 없이 날짜만 비교`는 경과 일수가 주 결과다. 양 끝을 포함하는 근무일 날짜 개수와 구분한다.
- 년·월은 기준 날짜의 달력 연산이다. 년×12+월을 한 번에 이동한 뒤 일·시간·분·초를 더하거나 뺀다. 대상 월에 원래 일자가 없으면 말일로 조정하고 표시한다. 2026-01-31+1개월=2026-02-28, 2024-02-29+1년=2025-02-28. 1개월=30일/1년=365일 고정 환산은 없다.
- 달력 차이는 오름차순으로 정렬한 두 시각 사이에서, 앞 시각에 한 번 적용해 뒤를 넘지 않는 최대 총 월수를 구한다. 총 월수를 년·월로 나누고 나머지 일·시간·분·초를 붙인다. 역순은 전체 부호로 표시한다. 월말 보정은 일반적으로 가역적이지 않다. 휴게 공제와 달력 차이는 구분해 후자를 공제 전 값으로 표시한다.
- 근무일은 기본 시작/종료일 포함, 토·일/공휴일 제외다. 포함일/제외 요일을 바꿀 수 있다. 주말과 공휴일은 합집합으로 제외한다. 긴 범위는 주 단위로 집계한다.
- 공휴일은 `holidays.KOREAN_HOLIDAYS`의 현재 2025–2027년 실제 자료만 사용한다. 자료가 없는 연도가 포함되면 공휴일 제외 계산을 보류한다. 공휴일 제외를 명시적으로 끈 경우 선택 요일만 제외한 결과로 표시한다. 음력 매핑의 2050년 범위를 공휴일 지원 범위로 오인하지 않는다.
- 날짜 범위는 1~9999년이다. UI 기간 항목은 0~999,999의 정수, 합산은 최대 24행이다. 기간 합산은 일·시간·분·초와 행별 더하기/빼기, 구간 합산은 각 행의 시작/종료 날짜·시각 및 휴게 분을 사용한다.

## UI와 상태

- A안의 어두운 왼쪽 메뉴 108px, 내용 480×620px, 기본 그림자 포함 528×668px를 사용한다. 입력·결과·오류·복사·최근 기록을 스크롤 없이 표시하며 시작/종료 날짜는 두 열로 배치한다. 좁거나 낮은 작업 영역에서는 그림자 여백을 줄인다. 높이 620px 미만에서는 중복 제목/상태 안내를 생략하고 보조 안내/결과 상세 주석은 툴팁으로 제공하며 여백을 압축한다. 총 분과 기간, 복사/최근·오류는 유지하며 전체 결과 복사는 상세 주석을 포함한다.
- 메뉴는 시간 차이·날짜 연산·근무일·시간 합산이다. 날짜는 연-월-일 직접 입력, 시각은 24시간제 직접 입력이다. 불명확한 자동 파싱이나 날짜 자동 넘김은 없다.
- 결과는 총 분을 크게, 일·시간·분·초 및 총 초를 보조 표시한다. 날짜 연산과 근무일은 해당 날짜/일수를 주 결과로 표시한다. 결과 글꼴은 실제 폭에 맞춰 줄이며 줄바꿈할 수 있다.
- 선택 목록은 기존 `ui_converter_combo.ConverterCombo`를 재사용하여 팝업 roll 깜박임 없이 동일한 28px 높이/목록 표현을 사용한다. 열린 목록의 Esc는 목록만 닫는다.
- 각 모드 입력과 합산 종류별 행을 기억한다. 최근 12개는 Enter 또는 기록 버튼으로 추가하며 같은 모드/입력/행을 중복 기록하지 않는다. 복원은 당시 조건과 행을 재계산하며 다른 합산 종류의 현재 입력을 지우지 않는다. 빈 합산의 0개 행도 그대로 복원한다.
- 시간 합산은 한 항목씩 표시하고 이전/다음·현재 번호/전체 개수로 전환한다. 숨긴 항목도 전체 합계와 유효성 검사에 포함한다. 오류에는 항목 번호를 표시하며 입력 중 자동 전환하지 않는다. 추가 시 새 항목, 삭제 시 같은 위치의 다음 항목 또는 이전 마지막 항목을 선택한다. 합산 종류별 선택 위치를 기억하고 최근 복원은 첫 항목으로 돌아간다. 선택 위치는 계산 기록의 중복 판정에 포함하지 않는다.
- 제목 드래그, X/Esc 숨김, Tab/Space/Enter, 결과 복사를 제공한다. 창을 닫았다 다시 열어도 입력·기록·위치는 실행 중 유지한다. 화면 변경은 작업 영역에 보정하며 숨겨 둔 창을 자동 표시하지 않는다.
- 주머니의 첫 행 오른쪽 타일은 번들 `resources/icons/date_time.svg`와 Qt 텍스트다. 좌상단 단위 환산기, 하단 비활성 예정 두 칸은 유지한다. 새 리소스는 `app_paths.resource_root()`로 찾는다.
- 메인이 창 하나를 소유한다. 일정 편집 저장 성공 후 실행하며 잠금/트레이/사이드바 숨김/본체 숨김 시 소유 팝업까지 닫는다. 잠금 시 비활성화하고 명시적 재실행 때 활성화한다. 초기화 성공 신호에서만 폐기하며 실패 시 기록을 보존한다. 정상 종료는 기존 일정/스티키 저장 성공 후 폐기한다.
- DB v17·Export v2·salt·기존 설정 키·6개 사용자 바로가기에는 변화가 없다. 입력·최근 기록·창 상태는 영속화하지 않으며 네트워크나 외부 로더를 사용하지 않는다.

## 구현과 검증

- `date_time_calculator.py`: Qt/DB 접근 없는 정수 초·달력·근무일 계산.
- `ui_date_time_calculator.py`: UI, 입력 검증 표시, 실행 중 기록과 창 소유 팝업.
- `tests/test_date_time_calculator.py`: 초/분·익일·윤년/월말·역순·공휴일·긴 범위·반올림.
- `tests/test_ui_date_time_calculator.py`: 실제 입력·복사·목록·기록·합산 행·배율/좁은 화면 렌더.
- `tests/test_date_time_integration.py`: 두 앱 실행·독립 상태·저장 실패·잠금/숨김·초기화·기존 DB/Export/salt 불변.

기준 참고: [Python datetime](https://docs.python.org/3.13/library/datetime.html#timedelta-objects), [Qt 월말 처리](https://doc.qt.io/qt-6/qdate.html#addMonths). 제품 동작의 정본은 위 명시적 계산 규칙과 회귀 테스트다.
